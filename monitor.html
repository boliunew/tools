添加监控

填好后点「去 GitHub 提交」，会打开一个已经帮你填好的页面，在那里点 Create 就完成了。

高级：只看页面的某一部分
自动找不到价格，或者整页内容变化太频繁时使用。
每 4 小时检查一次。有变化时，系统会在这个监控对应的 GitHub issue 下留言，GitHub 会通过 App 推送或邮件通知你。
删除监控：打开它的 issue，点 Close issue。
加载中…
很多大型购物网站（如 Amazon、Walmart）会拦截自动访问，可能读不到价格；小商店、官网、公告页一般没问题。
建议安装 GitHub App 并打开通知，这样能第一时间收到提醒。
