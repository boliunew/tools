⬇️ 下载 APK 📲 安装
  1. 点上面下载，装的时候允许「安装未知应用」
  2. 打开桌面上的「湖光 Lakeside 皮肤」
  3. 点「启动 Poweramp 并应用『湖光』皮肤」就生效了
⚠️ 自用皮肤的限制：Poweramp 只认证上架的皮肤，这个会显示 [unverified]，没有皮肤设置页，选上 48 小时后会自动换回默认皮肤，到时在 Poweramp 设置 → 外观 → 皮肤里重新选一下就行。
🖼️ 换底图
  1. 点下面按钮，在 GitHub 上传照片（手机相册直接选）
  2. 文件名写成 2_海边.jpg：数字是顺序，后面是显示的名字；想让竖屏往左/右偏，加 @40（宽度 40% 处为中心）
  3. 点 Commit，等 5 分钟自动重新编译，再下载上面的 APK 覆盖安装
  4. Poweramp → 设置 → 外观 → 皮肤，每张照片都是一个独立皮肤「湖光 · 名字」，点哪个用哪个
