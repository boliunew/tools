# 美国移民（二）：移民制度是怎么运作的，争论在哪里

## 一句话

**美国移民法的骨架是 1965 年定下的：以家庭团聚为主、职业移民为辅，每年给每个国家设上限；几十年没有大改，于是排队越来越长，争论越来越激烈。**

> 这是讲制度怎么运作的知识文章，**不是法律建议**。移民政策近年变化非常快，具体办理以 **USCIS（uscis.gov）** 和国务院签证公告为准，个案请咨询移民律师。

## 身份分几种

| 身份 | 是什么 | 能做什么 |
|---|---|---|
| **公民** | 出生在美国或归化入籍 | 投票、美国护照、为亲属申请移民、担任联邦公职 |
| **永久居民（绿卡）** | 合法长期居住 | 工作、居住、读书；大多数情况不能投票；长期离境可能失去身份；犯某些罪可能被遣返 |
| **非移民签证** | 有目的、有期限的停留 | 只能做签证允许的事：B（旅游商务）、F（学生）、H-1B（专业工作）、L（跨国公司调派）、O（杰出人才）、J（交流访问）等 |
| **难民 / 庇护** | 因种族、宗教、国籍、政治观点、特定社会群体身份在本国受迫害或有充分理由担心受迫害 | 获批一年后可申请绿卡 |
| **临时保护（TPS）、假释（parole）、DACA** | 介于合法和非法之间的临时安排 | 暂缓遣返、可以工作，但不是通往绿卡的路；随政策变化可能被取消 |
| **无证移民** | 非法入境，或签证过期后滞留 | 随时可能被遣返；没有工作许可；但孩子在美国出生就是公民 |

## 拿绿卡的四条主要路

1. **家庭移民**：美国公民的配偶、未成年子女、父母不受名额限制；其他亲属（成年子女、兄弟姐妹）有年度名额，**排期可能长达十几年到二十年以上**（取决于类别和国籍，菲律宾、墨西哥、印度、中国大陆排得最久）。
2. **职业移民**：EB-1（杰出人才、跨国高管）、EB-2（高学历、国家利益豁免 NIW）、EB-3（技术工人、普通工人）、EB-5（投资移民）。通常需要雇主担保和劳工证（PERM）。**每个国家每年最多占 7%**，所以印度、中国出生的申请人排期特别长。
3. **难民和庇护**：难民在海外申请；庇护在美国境内或入境时申请。难民年度上限由总统设定，不同政府之间差别巨大（从几千到十几万）。
4. **多元化签证（绿卡抽签）**：每年约 5 万个名额，给移民美国人数少的国家的人抽签。

每年新发的绿卡约 100 万张左右。

## 归化入籍

一般条件：
- 持绿卡满 **5 年**（和美国公民结婚并共同生活的，满 3 年）；
- 期间在美国实际居住足够时间；
- **良好品行**；
- 通过**英语测试**（读、写、说）和**公民测试**（美国历史和政府知识，口试）；
- 宣誓效忠。

公民测试的很多题目，其实就是[《美国政治是怎么运作的》](uw-politics-us-system.md)那篇里的内容。

## 执法机构

| 机构 | 管什么 |
|---|---|
| **USCIS**（公民及移民服务局） | 审批绿卡、入籍、工卡等申请 |
| **CBP**（海关和边境保护局） | 边境口岸和边境巡逻 |
| **ICE**（移民和海关执法局） | 境内执法、拘留、遣返 |
| **移民法庭（EOIR）** | 隶属司法部，裁决遣返和庇护案件；积压案件数以百万计 |
| **国务院** | 在海外使领馆发签证 |

## 主要争论

| 议题 | 一方的观点 | 另一方的观点 |
|---|---|---|
| **边境** | 边境失控，必须严格管控、建墙、快速遣返 | 边境问题源于中美洲的暴力和贫困，以及庇护审理积压，建墙解决不了 |
| **无证移民** | 违法就该遣返，否则是奖励违法、对排队的人不公平 | 很多人已经在美国生活工作几十年，有美国公民子女，大规模遣返代价巨大，应给合法化路径 |
| **庇护** | 很多人借庇护之名来打工，制度被滥用 | 庇护是国际义务，真正受迫害的人需要保护 |
| **技术移民** | 优先招揽人才，H-1B 和绿卡名额应扩大 | H-1B 被外包公司滥用，压低美国工人工资 |
| **家庭移民** | 应改为以技能为主的「积分制」（像加拿大、澳大利亚） | 家庭团聚是美国移民的传统，也有助于融合 |
| **出生公民权** | 应限制，以免「生育旅游」和鼓励非法移民 | 第 14 修正案写得很清楚；2026 年最高法院在 Trump v. Barbara 案中也这样裁定 |

**2025 年以来**，联邦政府大幅收紧移民政策：加强境内执法和遣返、提高部分签证费用和门槛、大幅降低难民接收上限、收紧庇护等。许多措施在法院里有诉讼，结果不一。政策细节随时在变，请以官方信息和新闻为准。

## 和其他国家比

- **加拿大、澳大利亚**：积分制为主，按年龄、学历、语言、工作经验打分，技术移民比例高。
- **欧洲**：多数国家移民制度较严，但通过欧盟内部自由流动和难民接纳也有大量移民。
- **日本、韩国**：传统上移民很少，近年因人口老龄化逐步放开外籍劳工。

## 常见误解

- **「排队等就能等到」**：很多人根本没有可以排的「队」：没有直系亲属、没有雇主担保、不符合难民条件，就几乎没有合法移民的途径。
- **「和美国人结婚就能马上拿绿卡」**：要审查婚姻真实性，先拿两年的有条件绿卡，再申请转正。
- **「绿卡就是永久的」**：长期离境、某些犯罪、欺诈都可能导致失去身份。
