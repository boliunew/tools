# PUA：从「搭讪术」到情感操控，怎么认出来、怎么脱身

> 这篇是帮你**认出模式、保护自己**的，不是教人怎么做。觉得自己陷在这种关系里、很痛苦，请找信得过的人或专业人士；在美国，随时可以打或发短信 **988**。

## 一句话

**中文里说的 PUA，就是在亲密关系或职场里，用一套「打压—奖励」的手法慢慢摧毁对方的自信，让对方觉得自己一无是处、只能依附于你。**

## 来龙去脉

- **英文原意**：PUA 是 Pick-Up Artist（搭讪艺术家）的缩写。上世纪 90 年代美国出现一批教男性「怎么搭讪女性」的课程和论坛，2005 年记者 Neil Strauss 的书《把妹达人》（*The Game*）让它流行起来。里面已经有不少带操纵性的技巧，比如故意贬低对方（negging）来打击自信。
- **到了中文网络**，这个词的意思变了：不再是「搭讪」，而是专指**恋爱中的精神控制**。2019 年一起北大学生在恋爱中长期遭受精神控制、最终离世的事件，让「PUA」在中国广为人知。
- **后来又有了「职场 PUA」**：领导用类似的手法打压员工，让员工自我怀疑、不敢离开、心甘情愿加班。

## 背后的心理机制

PUA 之所以「好用」，是因为它利用了几条人人都有的心理规律：

1. **间歇强化**：一会儿好得不得了，一会儿冷得像冰。心理学发现，**不定时的奖励比稳定的奖励更让人上瘾**（赌博也是这个原理）。被这样对待的人会拼命去追那个「好的时候」。
2. **先捧后踩**：开头猛烈示好（常被叫「爱情轰炸」），让你觉得遇到了真命天子；等你投入了，再开始挑剔、贬低。你会想回到开头那个状态，于是越来越顺从。
3. **自我价值被拆掉**：反复说你「这么差，除了我谁还要你」「你这样的人出去找不到工作」，时间长了你会信。
4. **孤立**：慢慢让你远离朋友家人，「他们不懂我们」「你朋友对你不安好心」。没人帮你核实现实，你就只剩下他的说法。
5. **内疚和服从测试**：让你为小事反复道歉、证明自己的爱或忠诚，要求一次比一次过分。
6. **煤气灯**：否认事实、说你想多了（见本库〈煤气灯操纵〉一篇）。

这些手法单独出现一两次，未必是 PUA；**成套出现、越来越重、让你越来越小**，才是要警惕的。

## 和正常恋爱有什么区别

| 正常的关系 | PUA 式的关系 |
|---|---|
| 吵架就事论事 | 吵架变成否定你这个人 |
| 你可以有自己的朋友和生活 | 你的社交圈越来越小 |
| 对方的好比较稳定 | 忽冷忽热，你总在猜他今天心情 |
| 你在关系里变得更自信 | 你越来越觉得自己不够好 |
| 分歧可以商量 | 只有他的标准，你要不停证明自己 |
| 想走就能走 | 想到离开就害怕、内疚，觉得没人会要你 |

## 职场 PUA 的常见样子

- 「你这点能力，在外面根本找不到工作，公司是在照顾你。」
- 永远说你做得不够好，但从不说哪里不好、怎么改；
- 公开批评，私下又说「我是为你好，严格要求才是看重你」；
- 用「格局」「狼性」「感恩」之类的话，让无偿加班、不合理要求显得理所当然；
- 绩效、晋升标准一直在变，你永远够不着。

**要分清**：严格要求、具体的批评，是正常管理；**只否定你这个人、标准模糊又不停变、让你害怕离开**，才是 PUA。

## 三个示例（虚构，综合了常见情况）

**① 先捧后踩**
阿杰刚认识女友时，天天接送、礼物不断，说她是「这辈子最懂我的人」。三个月后开始挑她穿着、说她朋友「档次低」；她一不顺他的意，他就冷战好几天，然后又突然温柔道歉。一年后，她几乎不再见朋友，每天先看他脸色再决定说什么。

**② 「除了我没人要你」**
小雨的男友常说「你脾气这么怪，也就我受得了你」。她想分手，男友说「你走出这个门试试，看谁还会对你好」。她开始相信自己真的很难被爱，一次次留下来。

**③ 职场**
老周的主管从来不给明确的要求，交上去的东西总说「不行，重做」，开会时说「有些人能力跟不上还不自知」。年终时说「本来想给你降级，是我替你争取的，你要懂得感恩」。老周不敢跳槽，觉得自己真的不行。

## 怎么脱身

1. **先相信自己的感觉**：总是不舒服、总在害怕、越来越不像自己，这本身就是信号，不用等对方「坏到够格」才算数。
2. **把朋友家人找回来**：恢复联系，跟他们说实话。外部的声音，是对抗孤立最有效的东西。
3. **记录**：对方说过的话、做过的事，写下来。它能帮你看清模式，不被「那次是我不对」反复拉回去。
4. **别想着「我能改变他」**：改变只能来自他自己。你可以表达你的界线，做不到的话就离开。
5. **离开时注意安全**：如果对方有威胁、跟踪、控制钱或证件，先悄悄做好准备（钱、证件、住处），找信得过的人陪同，必要时报警。美国全国家庭暴力热线：1-800-799-7233。
6. **职场**：要求书面的工作要求和反馈，保留记录；向人力资源或上级的上级反映；认真看看外面的机会，你的价值不由这一个领导说了算。
7. **找心理咨询**：被长期打压过的自信，靠自己很难一下恢复，咨询师能帮你把「他说的」和「真实的你」分开。

## 常见误解

- **「被 PUA 的都是傻」**：完全不对。它利用的是信任、感情和人人都有的心理规律，学历高、能力强的人一样会陷进去。
- **「只有男人 PUA 女人」**：不是。任何性别、任何关系里都可能出现。
- **「对方一冷淡就是 PUA」**：偶尔冷淡、吵架，是普通关系的一部分。要看**是不是成套、反复、越来越重**。
- **「离开了就好了」**：离开是第一步，自我价值的恢复往往要一段时间，这很正常。
