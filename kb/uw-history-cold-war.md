# 冷战：两种制度的四十年对抗

## 一句话

**冷战是美国和苏联两种制度——市场经济加选举民主，对计划经济加一党制——在全世界范围内的竞争，「冷」是因为两个超级大国怕核战争，从来没有直接打起来。**

## 来龙去脉

### 怎么开始的（1945–1949）

- 二战时美苏是盟友，战后很快分道扬镳：苏联在东欧扶持亲苏政权，丘吉尔 1946 年说欧洲落下了一道「铁幕」。
- **1947 年**：美国提出「杜鲁门主义」（援助抵抗共产主义的国家）和**马歇尔计划**（援助西欧重建）。「遏制」（containment）成为美国战略。
- **1948–1949 年**：苏联封锁西柏林，美英空运物资；**北约**成立（1949），德国分裂成东西两个国家；苏联试爆原子弹；中华人民共和国成立。
- **1955 年**：苏联和东欧国家成立华沙条约组织。

### 冷战的几个战场

| 领域 | 发生了什么 |
|---|---|
| 核军备 | 两国核弹头数量一度各有几万枚，形成「相互确保摧毁」（MAD）：谁先打，双方都会毁灭 |
| 代理人战争 | 朝鲜战争（1950–1953）、越南战争（美国大规模介入 1965–1973）、阿富汗战争（苏联 1979–1989）、非洲和拉美的多场内战 |
| 危机 | 古巴导弹危机（1962）：苏联在古巴部署导弹，世界离核战争最近的十三天，最后双方妥协撤除 |
| 柏林墙 | 1961 年东德修墙阻止人们逃往西方，成为冷战象征 |
| 太空 | 苏联 1957 年发射第一颗人造卫星、1961 年加加林第一个进入太空；美国 1969 年阿波罗 11 号登月 |
| 经济和宣传 | 谁的制度能让人民过得更好；电台广播、电影、奥运会、厨房辩论 |
| 情报 | 中情局和克格勃的间谍战、政变和秘密行动 |

### 中国的位置变化

- 1950 年代中苏结盟；1960 年代因意识形态和国家利益分歧**中苏分裂**，1969 年边境爆发冲突。
- **1971–1972 年**：基辛格秘密访华、尼克松访华，中美和解，形成美中对苏的格局。1979 年中美建交。
- 1978 年起中国改革开放，逐步走向市场经济。

### 怎么结束的（1985–1991）

- 苏联经济长期停滞，军费负担沉重，阿富汗战争消耗巨大，油价下跌。
- 戈尔巴乔夫 1985 年上台，推行「改革」和「公开性」，放松对东欧的控制。
- **1989 年**：东欧剧变，波兰、匈牙利、东德、捷克斯洛伐克等国共产党政权相继下台，11 月柏林墙倒塌。
- **1990 年**德国统一；**1991 年 12 月**苏联解体，分成 15 个国家。

## 冷战留下了什么

- **北约**不但没解散，还向东扩张到前华约国家——今天俄罗斯与西方矛盾的一个根源（对东扩的评价争论很大，见下文）。
- **朝鲜半岛分裂**至今，台海问题也与冷战格局有关。
- 美国成为唯一超级大国，「历史终结论」一度流行。
- 互联网、GPS、卫星等很多技术源自冷战时的军事研究。
- 很多国家（韩国、台湾、西班牙、智利等）在冷战时期是威权政府，后来民主化；也有很多国家的政变、独裁与冷战大国的支持有关。

## 关键概念

| 概念 | 意思 |
|---|---|
| 遏制（Containment） | 美国的战略：阻止共产主义扩张，而不是直接推翻苏联 |
| 相互确保摧毁（MAD） | 双方核武器都足以毁灭对方，所以谁也不敢先动手 |
| 代理人战争 | 大国不直接交战，而是支持其他国家或派别打仗 |
| 多米诺理论 | 认为一个国家倒向共产主义，周边国家会接连倒下（美国介入越南的理由之一） |
| 缓和（Détente） | 1970 年代美苏关系缓和、签军控条约的时期 |
| 不结盟运动 | 印度、印尼、埃及、南斯拉夫等国不站队任何阵营 |

## 不同的解释

- **冷战是谁挑起的？**
  - 「正统派」（西方早期观点）：苏联扩张主义是主因，美国是被迫回应。
  - 「修正派」（1960 年代起）：美国追求经济和军事霸权，同样咄咄逼人。
  - 「后修正派」（如约翰·刘易斯·加迪斯）：双方互不信任、安全困境互相加剧，苏联档案开放后加迪斯更强调斯大林的作用。
- **苏联为什么解体？** 经济制度失灵、军备竞赛拖垮、民族问题、戈尔巴乔夫改革失控、西方压力（里根强硬政策的作用有争论）——多数学者认为是内部因素为主。
- **北约东扩对不对？** 一方认为这是东欧国家自主选择的权利、带来了稳定；另一方（如米尔斯海默等现实主义者）认为东扩刺激了俄罗斯，为后来的冲突埋下伏笔。这个争论跟今天的俄乌战争直接相关。

## 常见误解

- **「冷战就是没打仗」**：只是美苏没直接开战，代理人战争死了几百万人。
- **「全世界都分成两边」**：很多国家不结盟，也有很多国家在两边之间摇摆、两头要援助。
- **「西方赢了是因为制度更好，这就是全部原因」**：制度差异很重要，但具体过程中领导人的选择、经济形势、偶然事件也起了很大作用。

- 核武器让冷战保持「冷」，那核武器是让世界更安全还是更危险了？
- 今天中美之间常被称为「新冷战」，跟美苏冷战有哪些像、哪些不像？（比如经济联系的程度）
