# 旅行的钱、安全和打包清单

一份出门前看一眼的清单：钱怎么带、怎么防偷防骗、东西丢了怎么办、行李收拾什么。

## 钱

- **带两张卡、分开放**：一张信用卡随身，一张备用放在酒店或另一个包里。一张被盗刷或者丢了，还有一张能用。
- **信用卡比借记卡安全**：被盗刷时信用卡的钱是银行的，争议期间不用你垫钱；借记卡是你自己账户里的钱直接没了。
- 出国用**没有外币交易手续费**的信用卡；刷卡时如果机器问你用美元还是当地货币付，**选当地货币**，选美元往往汇率更差。
- 带一点**现金**：小费、小摊、停车、只收现金的老店。
- 打开银行 App 的**消费提醒**，每笔刷卡都推送通知，有异常马上冻结卡。

## 小费（美国）

| 场合 | 一般给多少 |
|---|---|
| 餐厅坐下吃 | 税前金额的 15–20% |
| 打车 / Uber / Lyft | 10–15% |
| 酒店打扫 | 每晚 2–5 美元 |
| 搬行李 | 每件 1–2 美元 |
| 代客泊车 | 取车时 2–5 美元 |
| 外卖自取、咖啡店 | 随意，可以不给 |

> 有的账单已经自动加了服务费（大桌常见），看清楚别重复给。

## 安全

- **手机和钱包别放后裤袋**，人多的地方（地铁、景点、集市）包背在前面。
- 别在路边、停车场当场往后备箱放东西，车里什么都别留（防砸车窗）。
- **常见骗局**：
  - 有人过来热情地给你戴手环、递 CD、拍照，然后要钱。礼貌拒绝，继续走。
  - 「你的车好像漏油了 / 爆胎了」，趁你下车看时拿东西。
  - 打电话或短信说是银行、航空公司、酒店，要你报验证码或卡号。**挂掉，自己打官方电话核实**。
  - 公共 Wi-Fi 别登录网银。
- 晚上走路选人多、有灯的路；喝了酒别开车，叫车回去。
- 把**住址、紧急联系人**存在手机锁屏能看到的「医疗急救卡」里。
- 更多骗局和被骗后怎么办，看 [旅行防骗大全](travel-scams.md)。

## 证件和东西丢了怎么办

- 出发前把**护照、驾照、信用卡正反面**拍照，存在手机相册的隐藏相册和云端各一份。
- **信用卡丢了**：马上在 App 里冻结，打卡背面的电话挂失。
- **护照丢了**：先报警拿报案记录，再去最近的使领馆或护照中心补办。
- **手机丢了**：用「查找」功能定位、锁定、远程擦除；提前记住一个家人的电话号码。
- **行李丢了**：在航空公司柜台当场登记，拿到行李编号，保留购买必需品的收据。

## 旅行保险要不要买

- 很多信用卡自带**行程延误、行李延误、租车险**，订票时用这张卡付才有效，先查卡的权益说明。
- 出国一定确认**医疗保障**：很多美国医保在国外不管或者报销很少。可以买专门的境外旅行医疗险。
- 昂贵、不能退的行程（邮轮、跟团）可以考虑行程取消险。

## 打包清单

**证件和钱**
- [ ] 驾照（Real ID）/ 护照（出国确认还有 6 个月以上有效期）
- [ ] 信用卡两张、少量现金
- [ ] 保险卡、常用药的处方

**电子**
- [ ] 手机、充电器、充电宝（随身带，不能托运）
- [ ] 车载充电线、耳机
- [ ] 出国带转换插头

**衣服**
- [ ] 按天数准备，**洋葱式穿法**：T 恤 + 薄毛衣 + 防风外套
- [ ] 一双好走的鞋
- [ ] 去海边、山里多带一件保暖的

**洗漱和药**
- [ ] 牙刷牙膏、洗面奶、防晒霜（随身液体不超过 3.4 盎司）
- [ ] 常用药、创可贴、肠胃药、晕车药

**其他**
- [ ] 水瓶（过安检后装水）、零食
- [ ] 眼罩、耳塞（酒店和飞机上睡得好）
- [ ] 几个折叠购物袋（加州超市袋子要钱）
- [ ] 一个小锁、行李定位器
