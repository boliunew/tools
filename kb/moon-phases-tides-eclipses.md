# 月亮：月相、潮汐、日食和月食

## 月相：月亮自己不发光

月亮被太阳照亮的永远是朝着太阳的那一半。月亮绕地球转一圈，我们看到的「亮的那一半」的角度不断变化，就有了圆缺。

**月相不是地球的影子挡出来的。** 这是最常见的误解，地球的影子只在月食时才落到月亮上。

一个周期大约 **29.5 天**（朔望月），农历的一个月就是按这个来的：

| 月相 | 农历大约 | 什么时候在天上 |
|---|---|---|
| 🌑 新月（朔） | 初一 | 和太阳一起升落，看不见 |
| 🌒 蛾眉月 | 初三、初四 | 傍晚在西边低处，很快落下 |
| 🌓 上弦月 | 初七、初八 | 傍晚在南边高处，半夜落下 |
| 🌕 满月（望） | 十五、十六 | 日落时升起，整夜都在，日出时落下 |
| 🌗 下弦月 | 廿二、廿三 | 半夜升起，早上在南边高处 |
| 🌘 残月 | 廿六、廿七 | 黎明前在东边低处 |

**看星星挑新月前后**，月亮不在夜空里，天最黑。满月那几天，亮到连银河都看不见。

**小知识**：

- 傍晚的细月牙旁边，月亮暗的那部分隐约也能看到，叫**地照**（老话叫「新月抱旧月」）。那是地球反射的太阳光又照亮了月亮。
- 上弦月亮的是**右半边**，下弦月亮的是**左半边**。这是北半球的看法，在南半球正好反过来。

## 为什么月亮总是同一面朝着我们

月亮自转一圈的时间正好等于它绕地球公转一圈的时间，所以总是同一面对着地球。这叫**潮汐锁定**：几十亿年来，地球的引力把月亮的自转慢慢「刹」到和公转同步。

- 由于轨道有点椭圆、又有点倾斜，月亮会轻微「摇头」，所以从地球上前前后后总共能看到月面的大约 59%。
- 「月球背面」并不是一直黑着，它和正面一样有白天黑夜，只是我们永远看不到它。
- 月亮每年离地球远大约 **3.8 厘米**。用激光照射阿波罗留在月面上的反射镜，就能量出这个变化。

## 潮汐：为什么一天两次

月亮的引力拉海水，**离月亮近的一侧**被拉得多，**远的一侧**被拉得少。结果地球两边各鼓起一个「水包」。地球自转一天，大多数海边会经过两个水包，所以一天两次涨潮、两次落潮。

而且每天涨潮的时间都会推迟大约 50 分钟，因为月亮每天升起也晚这么多。

太阳也有潮汐作用，大约只有月亮的一半：

- **大潮**：新月和满月前后，太阳、月亮、地球排成一线，两者叠加，涨得最高、落得最低。去海边赶海、看潮池（tide pool）就挑这几天的低潮。
- **小潮**：上弦、下弦前后，两者互相抵消一部分，涨落最小。

## 日食和月食

- **日食**：月亮走到太阳和地球中间，影子落在地球上。只可能发生在**新月**。
- **月食**：地球走到太阳和月亮中间，影子落在月亮上。只可能发生在**满月**。

**那为什么不是每个月都有？** 因为月亮的轨道比地球的轨道斜了大约 **5°**。大多数月份，月亮从太阳或地球影子的上方、下方「错过」去了。只有当新月或满月正好赶上两个轨道的交点，才会有日月食。这样的机会一年大约两段，叫「食季」，每段一个多月。所以日食和月食常常相隔两个星期左右成对出现。

**看月食和看日食很不一样**：

| | 月食 | 日食 |
|---|---|---|
| 在哪能看 | 当时是晚上的半个地球都能看 | 只有月亮影子扫过的地方能看。全食带通常只有一两百公里宽 |
| 能持续多久 | 全食可以超过一小时，整个过程好几个小时 | 全食最长也就几分钟 |
| 安全吗 | 肉眼直接看，完全安全 | **千万不能直接看太阳**，必须用正规的日食眼镜（ISO 12312-2）。普通墨镜不行 |

**月食分三种**：

- **半影月食**：只碰到地球影子外圈的淡影，月亮只是稍微暗一点，肉眼几乎看不出来。
- **月偏食**：月亮的一部分进入本影，像被咬掉一块。
- **月全食**：整个月亮进入本影。这时月亮不会消失，而是变成**暗红色**，就是「血月」。

**为什么是红色**：太阳光穿过地球大气层时，蓝光被散射掉，剩下的红光被大气折射，拐进了地球的影子里。相当于全世界所有的日出日落一起照在月亮上。如果地球上刚有大火山爆发，大气里灰尘多，月全食就会更暗。

## 超级月亮和「月亮错觉」

- **超级月亮**：月亮的轨道是椭圆的。满月时如果正好靠近**近地点**，看起来比在远地点时大约大 14%、亮 30%。但不放在一起比，肉眼很难察觉。
- **月亮错觉**：刚升起的月亮看着特别大，到了头顶就变小了。其实大小一样，用手机拍下来量一下就知道。这是大脑的错觉：地平线附近有房子、树做参照，大脑就把月亮「看大」了。
