# 山火季、Santa Ana 风和空气质量

Upland 北边就是 San Gabriel 山和山脚的灌木区。每年秋冬，干热的 Santa Ana 风一刮，山火风险就上来了；就算火不在附近，烟也会顺风飘过来，把整个 Inland Empire 的空气搞得很差。这篇讲：怎么提前知道、怎么收到警报、要走时带什么、烟大时怎么保护自己、在户外上班有哪些规定。

> 灾情时以 **官方警报和消防部门** 的指示为准。下面的规定和网址以 SCE、San Bernardino County、Cal/OSHA 等官网当前说明为准。

## Santa Ana 风是什么、什么时候刮

- **成因**：内陆大盆地（Great Basin，内华达、犹他一带）出现高压，空气从高原往海边方向吹，翻过山、顺着山口和峡谷往下冲。往下冲的空气会被压缩变热、变干。
- **时间**：主要在 **10 月到次年 3 月**，秋天到初冬最危险，因为夏天刚过，草木最干，雨季还没来。
- **特点**：**风大、很干、气温反常地高**，湿度可能降到个位数。风从东北往西南吹，所以在 Upland，经常是从 Cajon Pass 和山那边吹下来。
- **为什么危险**：一点火星在这种风里能飞出很远，火势一晚上就能跑很多英里。2025 年 1 月洛杉矶那几场大火就是在强 Santa Ana 风里烧起来的。

日常影响也有：大风刮倒树枝、电线、围栏，高速上的**空箱拖车和厢式货车**容易被吹翻，15 号公路 Cajon Pass 一段经常对高侧面车辆发大风警告。在堆场上班的话，大风天要特别注意**空箱堆垛、开着门的拖车、松动的门和篷布**。

## 红旗警告（Red Flag Warning）

**Red Flag Warning** 是美国国家气象局（NWS）发的**火险天气警告**：意思是风大、空气干、植被干，三样凑在一起，一旦起火会烧得很快。

红旗警告期间：

- 不要做任何可能产生火星的事：割草机碰石头、拖着链条开车、在干草边停热车、户外烧烤、扔烟头。
- 把手机充满、车油加满，逃生包放在门口。
- 关注县里和市里的警报（下面说怎么注册）。
- 准备好可能被**预防性停电**。

## SCE 预防性停电（PSPS）

Upland 一带的电由 **Southern California Edison（SCE）** 供应。在大风、干燥、火险很高的时候，SCE 可能**主动切断部分线路的电**，防止电线被风刮断引起山火，这叫 **Public Safety Power Shutoff（PSPS）**。

- **一般会提前通知**：SCE 说通常会在可能停电**前最多 3 天**左右开始发通知，但天气变化快时也可能来不及提前很久。
- **账户在房东名下怎么办？** 合租的人常遇到这种情况：电费账户是房东或别的室友的，你收不到通知。SCE 有一个 **PSPS Address Alerts（地址提醒）**，**不需要是账户持有人**，填地址就能收短信 / 邮件，网址 **sce.com/pspsalerts**。
- **查停电**：SCE 的停电地图（sce.com/outagemap）或 MySCE App。
- **家里有人用电动医疗设备**：可以了解 SCE 的 Medical Baseline 项目（sce.com/mbl），并提前准备备用电源。

停电前准备：

- [ ] 手机、充电宝、手电全部充满
- [ ] 冰箱冷冻室多放几瓶冻水，停电时能多撑一阵；尽量少开冰箱门
- [ ] 车加满油（停电时加油站可能也没电）
- [ ] 知道车库门怎么**手动打开**（拉那根红绳）
- [ ] 不要在室内、车库里用发电机或烧炭取暖，会**一氧化碳中毒**

## 疏散：警报、分区和逃生包

### 先注册警报

| 渠道 | 是什么 | 怎么用 |
|---|---|---|
| **Wireless Emergency Alerts（WEA）** | 手机系统自带的紧急警报 | 不用注册，确认手机设置里政府/紧急警报是开着的 |
| **San Bernardino County TENS** | 县里的电话 / 短信紧急通知系统（Telephone Emergency Notification System），只发给受影响区域 | 通过 Smart911 注册手机号和地址（链接见文末），也可以打 211 请人帮忙 |
| **Ready SB County App** | 县里的应急准备 App | 手机应用商店搜索下载 |
| **Upland 市** | 市政府的紧急警报页面会说明本市用的通知方式 | 见文末 Upland 市链接 |

**县里的警报是「推给你登记的号码和地址」**。座机时代的自动登记覆盖不到你的手机，所以手机号要自己去注册一次。

### 疏散分区

南加州很多县和城市把辖区划成一个个**疏散分区（evacuation zone）**，发警报时直接说「某某分区立即撤离」。很多地方用的是 **Genasys Protect**（protect.genasys.com）：输入地址，就能看到自己属于哪个分区和当前状态。

> 我没能确认 San Bernardino County / Upland 是否全面使用 Genasys Protect 分区。从县里过去的山火通告看，他们常用**地名和道路范围**描述撤离区域（比如某山区社区、某条路以北）。建议：上 protect.genasys.com 查一下你的地址，**如果显示了分区编号，就记下来**；如果没有，就以县里 TENS 通知、消防部门公告里的地名和路名为准。

### 疏散的三个级别（各地说法相近）

| 级别 | 常见叫法 | 你该做什么 |
|---|---|---|
| 准备 | Evacuation **Warning** / Ready | 收拾逃生包，车头朝外停好，行动不便的人、宠物**现在就可以先走** |
| 立即撤离 | Evacuation **Order** / Go | **马上走**，别等看到火。按指定路线离开 |
| 原地避难 | Shelter in Place | 来不及走时，待在室内，关好门窗 |

县里也提醒：**听到警车「hi-lo」（高低交替）的警笛在街上响，就是该走了**。另外，**不要只依赖一种通知方式**，觉得不安全就先走。

### 逃生包（Go-bag）

山火撤离常常只有几分钟。按「5 个 P」想一想：**People（人和宠物）、Papers（证件）、Prescriptions（药和眼镜）、Pictures（无法替代的东西）、Personal computer（电脑、硬盘）**。

- [ ] 水和不用做饭的食物（至少 1–3 天）
- [ ] **N95 口罩**（每人好几个）
- [ ] 常用药、备用眼镜、急救包
- [ ] 证件原件或复印件：身份证件、护照、社安卡、保险单、租房合同；手机里再存一份加密备份
- [ ] 手机充电线、充电宝
- [ ] 现金（小面额）
- [ ] 换洗衣物、长袖长裤、结实的鞋
- [ ] 手电、收音机
- [ ] 宠物的笼子、牵绳、粮和水
- [ ] 电脑、存数据的硬盘（如果有交易程序或数据，放在一个能一把拎走的地方）

地震应急包和这里很多东西是重合的，见 [地震准备：南加州版](earthquake-prep.md)。

## 空气质量指数（AQI）每一级怎么做

**AQI（Air Quality Index）** 把空气里的污染物浓度换算成 0–500 的数字，越高越差。山火烟里最伤人的是 **PM2.5**（直径 2.5 微米以下的细颗粒），能深入肺部。

| AQI | 颜色 | 级别 | 一般人怎么做 |
|---|---|---|---|
| 0–50 | 绿 | Good（好） | 正常活动 |
| 51–100 | 黄 | Moderate（中等） | 对烟特别敏感的人减少长时间剧烈户外运动 |
| 101–150 | 橙 | Unhealthy for Sensitive Groups（对敏感人群不健康） | 老人、小孩、孕妇、有心肺疾病的人减少户外活动；其他人减少剧烈运动 |
| 151–200 | 红 | Unhealthy（不健康） | 所有人减少户外时间和剧烈运动；在户外考虑戴 N95；**Cal/OSHA 山火烟雾规定开始适用** |
| 201–300 | 紫 | Very Unhealthy（非常不健康） | 尽量待在室内、关好门窗、开空气净化；出门戴 N95 |
| 301+ | 褐红 | Hazardous（危险） | 尽量别出门；所有人都应避免户外活动 |

> 天气预报里常说「空气质量 AQI 多少」，要看清楚是**哪种污染物的 AQI**。山火时看 **PM2.5**；夏天下午常见的是**臭氧（ozone）**超标，Inland Empire 是全美臭氧最严重的地区之一，两者应对方式不完全一样（N95 能挡颗粒物，挡不住臭氧）。

## 去哪看空气质量

| 来源 | 特点 |
|---|---|
| **AirNow**（airnow.gov，美国环保署 EPA） | 官方监测站数据和预报。山火时用它的 **Fire and Smoke Map**（fire.airnow.gov），上面同时显示官方站、临时监测站、火点和烟羽 |
| **South Coast AQMD**（aqmd.gov，南海岸空气质量管理局） | Upland 所在的盆地地区归它管。有本地预报、空气质量警报、烟雾通告，也有 App |
| **PurpleAir** | 民间低成本传感器网络，密度高，能看到你家附近几条街的情况 |

**PurpleAir 的数字要打个折看**：EPA 研究发现，PurpleAir 传感器的原始数据**普遍偏高**，特别是烟大的时候。EPA 为此做了一个**修正公式**，AirNow 的 Fire and Smoke Map 上显示的 PurpleAir 点就是**修正过、做过质量检查**的。如果你直接上 PurpleAir 自己的地图看，记得在设置里选「**US EPA**」修正（或类似名字的转换选项），否则会看到偏吓人的数字。另外，传感器装在室内还是室外、旁边是不是有人烧烤，也会影响读数。

**最实用的办法**：手机上存一个 AirNow 或 AQMD 的 App 看「正式数字」，再用修正后的 PurpleAir 看「我家附近大概如何」。

## 烟大时怎么保护自己

### N95 口罩

- 要用 **NIOSH 认证**的 **N95**（或更高的 P100），外面印着 NIOSH 字样和认证号。普通外科口罩、布口罩**挡不住** PM2.5。
- **戴紧才有用**：两根带子一根在头顶、一根在脖子后面，按压鼻夹贴合鼻梁。吸气时口罩应该微微往里瘪，四周不漏风。
- **胡子会让口罩漏气**，效果打折扣。
- 带呼气阀的 N95 对自己一样有效（只是呼出的气不过滤）。
- 戴着觉得呼吸困难、头晕，就到室内摘下来。有心肺疾病的人戴之前最好问问医生。
- 口罩变脏、变形、带子松了就换。

### 室内：做一个干净房间

- 关好门窗。中央空调可以开，但要关掉**新风 / 外循环**；如果有条件，空调滤网换成 **MERV 13** 或更高。
- 选一个房间（比如卧室）作为「干净房间」，放一台 **HEPA 空气净化器**，大小要配房间面积。
- 不要在烟大的日子在室内**点蜡烛、烧香、煎炸、吸尘（无 HEPA 的吸尘器会扬尘）**，这些都在增加室内颗粒物。

### DIY：箱式风扇滤网（Corsi-Rosenthal Box）

买不到或买不起净化器时，这是个便宜又有效的方法：

1. 一台 **20 英寸箱式风扇**（box fan）
2. **4 片 20×20 英寸的 MERV 13 空调滤网**（有的人只用 1 片，效果差一些）
3. 宽胶带、一块纸板

做法：4 片滤网围成一个立方体（**滤网上的气流箭头都朝里**），用胶带粘牢，底部用纸板封住，风扇放在最上面、**往外吹**，四角漏缝处用纸板和胶带封好。这样空气从四面滤网吸进去、从风扇上方吹出去。

> 安全提醒：风扇用的是电机，别让它长期无人看管地开着，别用老旧、电线破损的风扇，别把它放在床上或靠近窗帘。

### 开车时

- 空调打到**内循环（recirculation）**，关窗。
- 车里的**空调滤芯（cabin air filter）**很久没换的话，烟季前换一个，有的型号有更好的过滤等级。
- 内循环时间太长车里会闷、二氧化碳升高、犯困，长途时**隔一阵短暂切换一下外循环**，或者在空气好一点的地方开窗换气。

## 在堆场户外上班：Cal/OSHA 的规定

在物流堆场的人大部分时间在户外，烟大、天热时，加州法律对雇主有明确要求。

### 山火烟雾：Title 8 §5141.1

根据 Cal/OSHA 的说明：

- **什么时候适用**：当 **PM2.5 的当前 AQI 达到 151 或以上**（「不健康」级别），并且可以合理预见员工会接触到山火烟雾时。
- **有例外**：比如在门窗关闭、空气经过过滤的室内或封闭驾驶室里工作，或者一个班次里接触烟雾累计**不到 1 小时**等。具体例外以条文为准。
- **雇主要做的**：
  1. **上班开始时和之后定期查 AQI**（可以用 AirNow、加州空气资源局、本地空气管理区等官方来源，或用符合要求的仪器自己测）。
  2. 用员工**听得懂的语言**告诉大家 AQI 和防护措施，并且**员工报告症状或问题不能被报复**。
  3. 按条文附录 B **培训**员工（烟雾对健康的影响、N95 怎么戴等）。
  4. 能做到的话，用**工程措施**把员工接触降到 AQI 151 以下，比如提供**有过滤空气的封闭空间**（关窗开内循环的驾驶室、过滤的休息室）。
  5. 做不到的话，**调整工作安排**：减少户外时间、调到烟小的区域、增加休息等。
  6. **提供 N95 等呼吸防护**：
     - **AQI 151–500**：雇主必须**免费提供**，员工**自愿使用**。
     - **AQI 超过 500**：员工**必须**佩戴呼吸防护，雇主要执行完整的呼吸防护计划。

如果烟很大、AQI 已经红了紫了，公司却没有任何说明、没发口罩，可以先问主管或安全负责人。也可以查 Cal/OSHA 网站上的说明，或向 Cal/OSHA 投诉。

### 高温：Title 8 §3395（户外）和 §3396（室内）

Inland Empire 夏秋都可能很热，Santa Ana 风天也会反常高温。Cal/OSHA 户外高温规定的几个要点：

| 要求 | 内容 |
|---|---|
| **水** | 雇主要免费提供干净、凉的饮用水，量要够**每人每小时至少 1 夸脱**（约 0.95 升），并鼓励多喝 |
| **阴凉处** | 气温超过 **80°F** 时，要有足够的阴凉处供休息；员工可以随时要求**降温休息**（cool-down rest） |
| **高温程序** | 气温达到 **95°F** 及以上，要加强观察员工状况、提醒喝水、班前开安全会、确保能随时联系到急救 |
| **适应期** | 新员工在高温环境的头 **14 天**要有人密切观察；热浪期间所有人都要加强观察 |
| **书面计划** | 雇主要有书面的高温疾病预防计划 |

在仓库、货柜里面干活的，加州还有**室内高温规定（§3396）**，室内温度达到 **82°F** 起就有相应要求。夏天集装箱、拖车厢里温度可能比外面高很多，进箱子干活要特别小心。

**中暑的信号**：头晕、头痛、恶心、大量出汗或突然不出汗、皮肤发红发烫、意识混乱。出现这些情况，马上到阴凉处、喝水、告诉主管；**意识不清就打 911**。

烟大加高温最难受：N95 戴着会更闷、更热，休息要更频繁，水要喝得更多。

## 一张检查清单

**烟季 / 风季开始前（9–10 月）**

- [ ] 注册 San Bernardino County TENS（Smart911）、SCE PSPS 地址提醒
- [ ] 手机装 AirNow 或 AQMD App，确认手机紧急警报开着
- [ ] 上 protect.genasys.com 查一下自己地址有没有分区编号
- [ ] 买一盒 NIOSH N95（家里、车里、工作柜子各放几个）
- [ ] 准备空气净化器或 DIY 箱式风扇滤网（多买几片 MERV 13 备用）
- [ ] 换车里空调滤芯
- [ ] 收拾好逃生包，放在门口附近
- [ ] 和室友说好：撤离时谁带什么、在哪会合、宠物谁管

**红旗警告 / Santa Ana 风天**

- [ ] 手机、充电宝充满，车加满油
- [ ] 看 AQI 和火情，留意县里警报
- [ ] 在堆场注意空箱、拖车门、篷布，大风时远离堆垛
