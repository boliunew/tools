# FBA 头程：从中国工厂到南加州的亚马逊仓

「头程」指的是从工厂到亚马逊仓这一段。美国西海岸的 FBA 货，绝大部分从洛杉矶港、长滩港上岸，再送进 Inland Empire 的亚马逊仓。所以这一带的拖车公司、海外仓、转运仓，天天都在做这件事。

## 全流程一览

1. **工厂备货**：按亚马逊货件**贴好 FNSKU 和箱标**。2026 年起亚马逊不再代贴，必须在到仓前做好。
2. **订舱、装柜**：
   - 整柜（FCL）：一个货主包一整柜。
   - 拼箱（LCL）：几家的货拼一柜，到了美国再拆开分。
3. **ISF 申报**：美国规定，货在国外港口**装船前至少 24 小时**要申报 ISF（俗称 10+2）。晚报、漏报会被罚款，每次最高 5,000 美元。
4. **海运到港**：快船两周左右，普船时间更长。到港后码头还可能排队，旺季尤其慢。
5. **清关**：
   - 需要报关行、海关保证金（bond），还要有一个**进口商（IOR）**。
   - **亚马逊不当进口商**，所以收货人不能直接写亚马逊。
   - 关税政策这两年变化很大，以报关行给的为准。
6. **提柜**：码头放行后，拖车公司约时间去码头提柜。流程见 [集装箱物流入门](container-logistics-101.md)。
7. **送进亚马逊仓**，有两条路：
   - **整柜直送**：柜子直接拉到亚马逊仓卸货。
   - **拆柜转运**：先拉到海外仓或转运仓，拆柜、分货、打托、贴托盘标，再用卡车（卡派）或快递（快递派）送进各个亚马逊仓。
8. **亚马逊签收、上架**：卸货签收只是第一步。货件状态变成「已完成接收」（Closed）、所有箱数核对上，才算真正入库。

## 整柜直送 vs 拆柜转运

| | 整柜直送 | 拆柜转运 |
|---|---|---|
| 适合 | 一柜只去一个亚马逊仓，单一或少量 SKU | 一柜货要去好几个亚马逊仓，或者混着几家的货 |
| 好处 | 少一次装卸，便宜、少出错 | 灵活：可以分批送、先存一部分、换标、修箱 |
| 麻烦 | 要拿到亚马逊仓的预约。不打托的「地板货」卸得慢、更难约 | 多一次装卸，多一份仓库费，多一次出错机会 |
| 常见去处 | 入库中转仓（IXD），如 ONT8、LGB8、SBD1 | 拆完后卡派或快递派到各仓 |

## 卡派 vs 快递派

| | 卡派（LTL / FTL） | 快递派（SPD） |
|---|---|---|
| 怎么送 | 卡车送整托盘 | UPS、FedEx 这些快递一箱一箱送 |
| 适合 | 箱数多、货重 | 箱数少、急、地址分散 |
| 要准备 | 托盘、托盘标、BOL、PRO 号、**亚马逊仓的预约** | 每箱一张快递面单，箱子不超过 50 磅 |
| 签收凭证 | 亚马逊签字的 BOL / POD | 每箱的快递签收记录 |
| 风险 | 预约难、等待卸货时间长 | 单箱丢件多，每箱都要能追踪 |

- **LTL**：零担，几家的托盘拼一辆车。
- **FTL**：整车，一辆车只装你的货。

## 亚马逊仓的预约：Carrier Central

卡车进亚马逊仓**必须提前预约**，约的是卸货的时间窗口。预约由**承运商**（拖车公司或卡车公司）在亚马逊的 **Carrier Central** 系统里做，卖家自己约不了。

1. **承运商先注册**：需要 SCAC 码、USDOT 号等资料。
2. **申请预约**：要提供货件的 Reference ID / PO、PRO 号、BOL 号，以及托盘数、是否地板货、车型。
3. **拿到 ISA 号**（预约号）：一定要**写在 BOL 上**。司机到闸口时要出示。
4. **按时到**：迟到、没去（no-show）、临时取消都会记承运商的缺陷。缺陷多了，账号会被限制甚至停用。
5. **铅封**：整车或整柜送货，铅封号要和 BOL 上写的一致，而且要符合 ISO 17712 标准。对不上可能被拒收。

旺季（大约 10–12 月）和仓库爆满时，预约可能要等一两个星期。这时候拆柜转运、先放在海外仓的好处就体现出来了。

## 南加州常见的亚马逊仓代码

亚马逊仓的代码大多是「附近机场代码 + 数字」：

- **ONT**：安大略机场
- **LGB**：长滩
- **SBD**：圣贝纳迪诺
- **SNA**：橙县
- **LAX**：洛杉矶

代码只是个名字，不代表仓库在那个城市。比如 LGB8 其实在 Rialto。

| 代码 | 城市 | 类型 |
|---|---|---|
| ONT8 | Moreno Valley | IXD（入库中转） |
| LGB8 | Rialto | IXD |
| SBD1 | Bloomington | IXD |
| LAX9 | Fontana | IXD |
| POC3 | Jurupa Valley | IXD |
| LGB3 | Eastvale | 小件（可分拣） |
| LGB7 | Rialto | 小件 |
| SBD6 | Ontario | 小件 |
| PSP1 | Beaumont | 小件 |
| ONT9 | Redlands | 大件（不可分拣） |
| LGB4 | Redlands | 大件 |
| LGB6 | Riverside | 大件 |
| SNA4 | Rialto | 大件 |
| SBD2 | San Bernardino | 大件 |
| LGB9 | Perris | 超大超重件 |
| ONT2 | San Bernardino | 服装鞋类等专门品类 |
| ONT6 | Moreno Valley | 服装鞋类等专门品类 |

> 这张表根据亚马逊 2025 年中公布的承运商仓库清单整理。仓库会新开、关闭、改用途，**送货一律以货件页面和预约系统里的地址为准**。

**几种仓的区别**：

- **IXD**（入库中转仓）：专门接收大批量入库货，再分配到全国各个仓。整柜、整车的 FBA 货常常先到这里。
- **小件仓**（Sortable）：放标准尺寸的小商品。
- **大件仓**（Non-sort）：放尺寸大的商品。
- **超大超重件仓**（XLFC）：放家具、大家电这类。

## 丢箱、少收怎么办

货件关闭后如果收到的数量比发的少，卖家可以在后台发起**货件差异调查**，让亚马逊查找或赔偿。成败取决于证据：

- **卡派**：亚马逊签字的 **BOL / POD**，上面有托盘数、箱数，最好还有铅封号。签收时如果有破损、少托，要让收货方在单子上注明。
- **快递派**：每一箱的签收追踪记录。
- **都需要**：
  - 装箱单（每箱装了什么、多少件）；
  - 出库前的照片，能看到箱数、托盘、箱标。拍法和验柜拍照一个道理，见 [集装箱物流入门](container-logistics-101.md) 最后一节。
- **有时限**：差异调查有提交期限。货件关闭后尽快对数，别拖。

> 每个环节都留证据：提柜时的 EIR，拆柜时的照片和箱数，出库时的 BOL。头程出问题，扯皮的时候拼的就是这些。
