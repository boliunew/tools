# 南加州野外的动植物风险

每周进山，迟早会遇到蛇、看到熊的脚印、蹭到毒橡树。好消息是：**这些东西里真正致命的事件非常少见**，大多数伤害来自「不认识」和「做错了处理」。这篇按「你多半会遇到 → 很少遇到」的顺序讲，每一项都说清楚怎么避开、出了事怎么办。

> 急救部分是一般性信息，不能代替培训，见 [野外急救基础](wilderness-first-aid.md)。任何人被蛇咬、出现呼吸困难或全身过敏，直接打 **911**。中毒咨询打 **Poison Help 1-800-222-1222**（全美通用，24 小时，加州会接到 California Poison Control）。

## 先看全局：风险排序

| 东西 | 遇到的可能 | 真正的危险程度 | 一句话 |
|---|---|---|---|
| **毒橡树 Poison oak** | 很高（溪谷、阴坡到处都是） | 低，但很难受，皮疹可以持续一两周以上 | 学会认，碰了尽快洗 |
| **响尾蛇** | 春夏秋常见 | 被咬是急症，但及时送医死亡极少 | 看脚下，别伸手，咬了打 911 |
| **蜜蜂 / 黄蜂** | 常见 | 一般低；**对蜂毒过敏的人或被群蜂攻击**时高 | 过敏的人随身带肾上腺素 |
| **仙人掌刺** | 沙漠里很常见 | 低，主要是疼和麻烦 | 带梳子和镊子 |
| **蜱虫** | 春天草丛里不少 | 南加州莱姆病很少见，但不是零 | 回来检查全身 |
| **郊狼 Coyote** | 常见（城边都有） | 对成人很低；对小狗、小猫是真风险 | 狗拴绳 |
| **黑熊** | Big Bear、San Gabriel 高处偶尔 | 低；主要问题是抢食物 | 食物别放帐篷里 |
| **美洲狮** | 极少亲眼看到 | 极低，但后果严重 | 别跑，变大，反击 |
| **蝎子 / 黑寡妇** | 偶尔 | 一般低；小孩和老人要重视 | 鞋子倒过来抖一抖 |

## 响尾蛇

### 什么时候、在哪

南加州常见的有 **Southern Pacific 响尾蛇**（山区和丘陵最常见）、**Red Diamond**（偏南和内陆）、**Speckled**（岩石多的地方），沙漠里还有 **Mojave 响尾蛇**和 **Sidewinder**。

- **春天到秋天**都活跃，**春季**出洞、交配，人也多，遇到的最多。
- 天热的中午它们躲在石头下、灌木根部的阴影里；**清晨、傍晚和夜里**更常在步道上横着晒地温。
- 冬天暖和的日子（20°C 上下）也会出来，别以为冬天就没有。
- **Mojave 响尾蛇**的毒液里有神经毒成分，咬的地方可能不怎么肿，但几小时后出现全身症状——**看起来不严重也要去医院**。

### 怎么避开

- 走在步道中间，**看清楚再落脚**；跨倒木、石头时先踩到上面看看另一边。
- **不往看不见的地方伸手**：攀石头、捡柴、坐下前先看。
- 听到「沙沙」或「哧哧」声：**先停下，找到蛇在哪**，再慢慢退开或绕行，保持至少 2 米（比蛇身长一倍以上）。不是所有蛇都会先摇尾巴。
- 不戳、不拍特写、不试图赶走它。很多咬伤发生在「想处理一下这条蛇」的时候。死蛇和砍下来的蛇头也能反射性咬人。
- 窄路、草深的地方别戴耳机；夜里走路一定开头灯。
- 高帮靴和长裤能挡住一部分咬伤。

### 被咬了：现在的正确做法

依据 CDC/NIOSH 的急救建议：

1. **离开蛇的攻击范围**，不要去抓它、打它。远远拍张照片有帮助，但不值得冒第二次被咬的险。
2. **马上打 911**，说清楚是响尾蛇咬伤和你的位置。真正的治疗是医院里的**抗蛇毒血清（antivenom）**，越早越好。**不要等症状出来再求救。**
3. **保持冷静，坐下或躺下**，被咬的肢体放在自然、舒服的位置，尽量少动。
4. **在肿起来之前摘掉戒指、手表、手镯**，松开紧的鞋和衣服。
5. 有条件就用肥皂和水洗一下伤口，盖上干净的干纱布。
6. 用笔在皮肤上**标出肿胀/疼痛的边缘，写上时间**，每 15–30 分钟标一次，给医生看进展。
7. **不要自己开车**——可能会头晕或晕倒。能让救援上来就别硬走；如果必须走出去，慢慢走、有人陪。

### 过时、有害的老办法——都别做

| 老办法 | 为什么不行 |
|---|---|
| 用刀割开伤口 | 增加出血和感染，对排毒没用 |
| 用嘴吸、用吸毒器吸 | 吸不出有意义的量，还会伤组织；吸毒器已被证明无效 |
| 绑止血带、勒紧绷带 | 把毒液困在局部，加重组织坏死，甚至导致截肢 |
| 冰敷、泡冷水 | 加重局部损伤 |
| 电击 | 无效，有害 |
| 喝酒、吃阿司匹林/布洛芬 | 影响凝血、掩盖症状 |

### 狗被咬

狗在草丛里乱嗅，被咬的比例比人高，多在**脸和前腿**。

- 尽量让它安静，**抱着或背着**走出去，别让它跑。
- 直接去**最近的 24 小时动物急诊**，路上先打电话确认他们有抗蛇毒血清。
- 同样不要割、吸、绑、冰敷。
- 市面上有「响尾蛇疫苗」，但**效果的证据有限**，打了也必须送医。要不要打问自己的兽医。
- 最有效的预防：**在有蛇的季节和路段拴短绳**。有些训犬机构做「避蛇训练」，可以了解一下。

## 美洲狮（Mountain lion / Cougar）

San Gabriel、San Bernardino、Santa Ana 山里都有美洲狮。你很可能一辈子在山里都看不到一只——它们看到你的次数远多于你看到它们。加州鱼类与野生动物局（CDFW）的数据是：**1890 年以来加州一共 6 起已知的致命袭击**。风险很低，但要知道怎么做。

**减少遇到的机会**

- 尽量别一个人走，尤其是**黄昏到清晨**——这是它们捕猎的时间。
- 边走边说话，别悄无声息地出现在拐角。
- **小孩放在视线内、伸手够得着的地方**，别让孩子跑在前面或落在后面。

**真的遇到了（加州州立公园 / CDFW 的建议）**

1. **别靠近**，给它留出离开的路。
2. **别跑**。跑会触发它追捕的本能。面对它，保持冷静。
3. **把自己变大**：举起手臂，张开外套，站高。把**小孩抱起来**，免得孩子惊慌乱跑。
4. **别蹲下、别弯腰**——那样看起来像猎物的体型。
5. 它靠近或表现出攻击性：**大声喊，扔石头、树枝**，但**别转身背对它**。
6. **被扑了就反击**：用登山杖、石头、拳头，打头和脸。尽量**保持站立**，护住头和脖子。**不要装死。**

看到美洲狮或很新的捕食痕迹（被拖走、用土和树叶盖住的鹿尸体），离开那片区域，告诉管理站。

## 黑熊

**加州现在只有黑熊**（州旗上的灰熊在 1920 年代就在加州灭绝了）。黑熊的毛色不一定是黑的，棕色、肉桂色都常见——**颜色不能用来区分种类**。Big Bear、Lake Arrowhead、Wrightwood、Crystal Lake、Mt Baldy 一带都有黑熊，偶尔还会下到山脚的居民区。

黑熊几乎不主动攻击人，真正的问题是**它们学会了从人那里找吃的**。

### 遇到熊（参照 NPS 和 San Bernardino 国家森林的建议）

- **别跑，别爬树**（黑熊会爬树，而且比你快）。
- 远远看到：绕开走，给它留路。
- 它注意到你了：**面对它，平静地说话**，慢慢挥手让它知道你是人；**站高、发出声音**，慢慢后退。
- 它冲过来：很多时候是**虚张声势的冲锋**，在最后停下或拐开。站住，别跑。
- **被黑熊攻击：不要装死，要反击**，打它的脸和鼻子，然后打 911。（「装死」是对付灰熊的办法，在加州用错了对象。）
- 带小熊的母熊、正在吃东西的熊最敏感，离远点。

### 食物怎么放

San Bernardino 国家森林的规定很直白：

- **食物、垃圾、牙膏、防晒霜、驱虫剂等一切有味道的东西都不能放在帐篷里，也不能放在桌上过夜。**
- 营地有**防熊储物箱（bear box）**就用，用完扣好。
- 没有的话：放进**密封容器，锁在车的后备箱**里；没有后备箱的车用毯子盖住，关窗锁车。
- 垃圾吃完就扔进**防熊垃圾桶**。
- 故意喂熊在加州是违法的。

**熊罐（bear canister）**：Angeles 和 San Bernardino 国家森林目前**没有像内华达山脉那样普遍强制要求**熊罐，但去 **Mt Whitney、Inyo 国家森林、Sequoia/Kings Canyon、Yosemite 的野营区**通常是强制的。在本地野营过夜，用熊罐也是最省心的办法。出发前查一下该地区的最新规定。

## 郊狼（Coyote）

城边的公园、Claremont Hills、Etiwanda 都很常见，白天也会看到。

- 对成年人的风险**非常低**。如果它靠得太近：站高、挥手、大声喊、跺脚、扔东西（这叫 hazing），让它保持怕人的习惯。**别喂。**
- 真正的风险是**小型犬和猫**。小狗一定拴短绳，傍晚和清晨尤其注意。
- 一只郊狼跟着你走一段，通常是在「护送」你离开它的窝附近，继续正常离开就好。

## 蜱虫与莱姆病

加州传播莱姆病的是**西部黑腿蜱（Western blacklegged tick）**。根据加州公共卫生部（CDPH），加州莱姆病风险较高的地区是**北部海岸、内华达山脉北段山麓、湾区和中部海岸**，而且大约三分之一的加州病例是在外州感染的。南加州病例少，但**不是零**，而且蜱虫还能传别的病。

- **季节**：冬末到初夏最多，草丛和灌木边缘的蜱虫爬在草尖上等着蹭到人。
- **预防**：走步道中间别蹭草；裤腿塞进袜子；皮肤和衣服用含 **20% 以上 DEET** 的驱虫剂；衣服和鞋可以用 **0.5% 的 permethrin**（**只喷衣物，不能喷皮肤**）。
- **回家**：尽快洗澡，**全身检查**（耳后、发际、腋下、腰带、膝盖后面、腹股沟），也查狗。衣服用烘干机高温烘 10 分钟能杀死蜱虫。

**取蜱虫（CDC 方法）**

1. 用细尖镊子**贴着皮肤夹住**蜱虫的头部。
2. **稳定、垂直地往外拔**，不要扭、不要猛拽。口器断在里面拔不出来就别挖，皮肤会自己排出来。
3. 洗干净叮咬处和手。蜱虫用胶带包起来或泡酒精处理，别用手指捏碎。

**别用的老办法**：凡士林、指甲油、打火机烧、酒精先泡——这些会刺激蜱虫，可能让它往你体内吐更多东西。蜱虫要吸附约 **24 小时以上**才可能传播莱姆病，所以**尽早取下**最重要。

之后几天到几周内出现**发烧、皮疹（尤其是扩散的红斑）**，去看医生，告诉医生被蜱虫叮过和在哪里。

## 毒橡树（Poison oak）

南加州山里**最可能让你难受一两周**的东西，不是蛇，是毒橡树。

### 怎么认

- **「Leaves of three, let it be」**：每片复叶有 **3 片小叶**，中间那片有明显的柄。叶子边缘有浅的波浪或锯齿，像橡树叶但更圆、更有光泽。
- **颜色随季节变**：春天新叶发红或嫩绿，夏天亮绿，**秋天变红、变橙**（很好看，很多人就是去摘才中招），**冬天叶子掉光**只剩光秃秃的枝条——**光枝条一样有毒**。
- 长成小灌木、一大丛，也会像藤一样爬在树上。溪边、阴坡、橡树林下最多（Ice House Canyon、Eaton Canyon、Sturtevant Falls 一带都很常见）。

### 碰到了怎么办

致敏的是叶、茎、根里的油 **urushiol**。它会沾在**衣服、鞋带、登山杖、背包、狗毛**上，之后再摸到也会起疹子。

1. **越快洗越好**：用**洗洁精、肥皂、专门的洗剂（如 Tecnu）或外用酒精**，配**大量水**冲洗皮肤，反复冲，别让洗剂干在皮肤上把油抹开。用凉水或温水，别用很烫的水。
2. **刷指甲缝**。
3. 衣服**单独用热水和洗衣液洗**。鞋、登山杖、工具用酒精或肥皂水擦，擦的时候戴一次性手套——urushiol 在物品上可以保持活性好几年。
4. **狗**蹭过毒橡树，它自己一般没事，但你摸它就会中招，给它洗个澡（戴手套）。
5. **绝对不要烧**疑似毒橡树的枝条——烟里的 urushiol 吸进肺里会引起严重的呼吸道反应。

### 起疹子以后

- 一般**接触后一两天到几天**出现，痒、红、起水泡。**水泡里的液体不会传染**，抓破了也不会让疹子扩散（扩散是因为身上或衣物上还有残留的油）。
- 止痒：凉的湿敷、炉甘石洗剂、氢化可的松药膏、燕麦浴；口服抗组胺药（如 Benadryl，会犯困）。破皮的地方别涂药膏。
- **去看医生**：疹子在**脸、眼睛周围、生殖器**，面积很大，或者肿得厉害。**呼吸困难、喉咙发紧 → 打 911**。

## 蜜蜂和黄蜂

南加州的野蜂里有不少是**非洲化蜜蜂（Africanized bees）**，单只的毒性和普通蜜蜂一样，但**保卫巢穴时会成群追很远**。

- 别靠近、别敲打蜂巢（树洞、石缝、废弃的箱子里）。听到很密的嗡嗡声、看到很多蜂进出，绕开。
- **被群蜂攻击**：**用衣服罩住头脸，立刻跑**，直线跑，跑进车里、建筑里或帐篷里关好。**别站着拍打，也别跳进水里**——它们会在水面等你出来换气。
- **拔刺**：尽快把留在皮肤上的刺弄掉。老说法是「只能用卡片刮，不能用手拔，否则会挤进更多毒液」；后来的研究认为**速度比方法重要**，用指甲刮、用手指拔都行，关键是快。
- 被叮**超过 15 下**，或出现局部红肿以外的症状（荨麻疹、呼吸困难、头晕、呕吐），**马上就医**。
- **知道自己对蜂毒过敏的人**：每次出门都带**两支肾上腺素自动注射器**（如 EpiPen），并告诉同伴放在哪、怎么用。过敏性休克怎么处理见 [野外急救基础](wilderness-first-aid.md)。

## 仙人掌刺

Joshua Tree、Anza-Borrego 最常见的麻烦。

- **Cholla（跳跳仙人掌）**：一节一节，轻轻一碰就整节「跳」到你身上，倒钩刺很难拔。**别用手去抓那一节**——用**一把梳子**插到那节和皮肤之间，往外一挑。剩下的刺用镊子拔。
- **仙人掌（Prickly pear / Opuntia）** 除了大刺，还有一簇簇很细的小毛刺（glochids），镊子夹不住：用**胶带**粘，或者涂一层**白乳胶**，干了以后撕掉。
- 沙漠里穿**结实的鞋**（不穿凉鞋），给狗带上**镊子**，晚上营地里走路要开灯。
- 刺很深、在关节附近、或者几天后红肿发热，去看医生。

## 蝎子和黑寡妇

**蝎子**：南加州沙漠和干燥山坡都有。大多数加州的蝎子**蜇了像被黄蜂蜇一样疼**，局部处理就行：洗干净、冷敷、观察。毒性强的 **Arizona bark scorpion** 在加州也有记录，但主要分布在亚利桑那。**小孩、老人被蜇**，或者出现麻木扩散、肌肉抽动、眼球乱动、呼吸困难、流口水等全身症状，打 911。

**黑寡妇**：雌性黑亮，腹部下面有**红色沙漏**。加州大部分地区都有，躲在**柴堆、石头堆、户外厕所、储物箱**这类又暗又干又没人动的地方。大多数咬伤是搬东西时手伸进去被咬的。可能引起肌肉痉挛、腹痛，**死亡非常罕见**。洗干净、冷敷，打 Poison Help 1-800-222-1222 咨询；小孩、老人或症状严重就去急诊。

**预防**：营地里**鞋子穿之前倒过来抖一抖**，衣服和睡袋别敞着放在地上，捡柴、翻石头戴手套。

## 其他几件知道一下

- **地松鼠和跳蚤**：San Bernardino、San Gabriel 山区偶尔检测到带鼠疫的地松鼠，营地有时会因此临时关闭。**别喂、别摸松鼠**，在洞口附近别搭帐篷，狗用驱蚤药。
- **鹿鼠和汉坦病毒**：清扫长期关着的小屋、储物棚时，别干扫灰尘，先用消毒水喷湿再擦。
- **不认识的蘑菇和野果**：一律不吃。

## 出门前的小清单

- [ ] 长裤、结实的鞋（沙漠里也别穿凉鞋）
- [ ] 驱虫剂（DEET）；衣服按需用 permethrin 处理
- [ ] 小镊子、梳子（仙人掌）、几片酒精湿巾
- [ ] 一小瓶洗洁精或毒橡树洗剂、一副一次性手套
- [ ] 抗组胺药；对蜂毒/食物过敏的人带**两支**肾上腺素
- [ ] 头灯（傍晚、夜里看路）
- [ ] 狗：短牵引绳、它的水，知道最近的 24 小时动物急诊在哪
- [ ] 手机里存好 **911** 和 **Poison Help 1-800-222-1222**
