# 野外急救基础

城里出事，救护车十分钟就到；在 Ice House Canyon 里崴了脚、在 Joshua Tree 被石头划开一条口子，**救援可能要一两个小时以上**，头这段时间只能靠你和同伴。这篇讲最常见、最要紧的几种情况，按「先保命、再处理小伤」排列。

> **这篇不能代替培训。** 止血带、固定夹板、肾上腺素这些东西，看文字和亲手练过一遍完全是两回事。强烈建议上一次两天的 **野外急救（Wilderness First Aid, WFA）** 课，见文末。

## 第一步：停下来，先看现场

出事后最常见的错误是**冲上去救人，结果自己也成了伤员**。

1. **现场安全吗？** 还在落石吗？伤员是不是躺在冰坡、急流边、公路上？有没有蜂群、蛇？先确认**你自己**不会受伤。
2. **发生了什么？** 摔下来多高？撞到头了吗？被什么咬了？
3. **有几个人受伤？** 先处理不出声的那个——不出声可能是没意识。
4. **戴手套**（急救包里放两副丁腈手套）。

然后按这个顺序快速检查伤员：

| 顺序 | 看什么 | 有问题怎么办 |
|---|---|---|
| **大出血** | 喷血、涌血、衣服迅速被浸透 | **最优先**，马上压住（见下文） |
| **意识** | 叫他、拍肩膀，能回答吗？知道自己在哪吗？ | 没反应 → 打 911，检查呼吸 |
| **气道 / 呼吸** | 胸口有没有起伏、能不能说话 | 没有正常呼吸 → 打 911，开始 CPR |
| **全身检查** | 从头到脚摸一遍，问哪里疼 | 处理具体伤情 |
| **保暖** | 地面很冷、风大、衣服湿 | 垫东西隔地面、加衣服——伤员躺着不动，失温比你想的快 |

失温和中暑的处理见 [失温与中暑](hypothermia-heat-illness.md)。

## 什么时候必须叫救援

**直接打 911（或用卫星求救）**：

- 意识不清、叫不醒、昏迷过，哪怕只有几秒
- 呼吸困难、胸痛
- 控制不住的大出血，或用了止血带
- 过敏性休克（用了肾上腺素也要叫）
- 毒蛇咬伤
- 头部受伤后出现下面「危险信号」里的任何一条
- 从高处摔下后脖子或背疼、手脚麻木——**怀疑脊柱受伤，不要让他走，尽量别动他**
- 骨折或扭伤**自己走不出去**
- 严重失温、中暑（神志改变）

**可以考虑自己慢慢走出去**：脚踝扭伤还能负重、小伤口止住了血、水泡。但如果天快黑了、路还很长，**早点求救比摸黑硬走强**。

**怎么求救**：山里经常没信号。

- 先试 **911**。电话打不通时可以试着**发短信到 911**（Text-to-911，加州大部分地区已经支持；信号很弱时短信有时比电话容易发出去）。能打电话就优先打电话。
- **iPhone 14 及以后**和部分新款 Android 手机有**卫星紧急求救**。Garmin inReach 这类卫星通讯器更可靠。
- 报告**位置**（手机地图上的经纬度）、**伤情**、**人数**、**你们的装备**（能不能过夜）。
- 详细见 [迷路与求救](lost-navigation.md)。

## 大出血

严重的出血**几分钟内**就能致命，比任何别的伤都优先。美国外科医师学会的 **Stop the Bleed** 项目教的是三个动作：

### 1. 直接压迫（先做这个）

- 撕开或剪开衣服，**找到出血的确切位置**。
- 用纱布、干净的布（没有就用手）**直接、用力、持续地压在伤口上**，用两只手，身体压上去。
- **不要隔一会儿掀开看**——一掀开刚形成的血块就破了。纱布被浸透了，**在上面再加一层**继续压。
- 压至少几分钟，最好压到救援到。

### 2. 填塞伤口（深的伤口）

腿根、腋下、脖子这种**没法上止血带**的地方，又深又大的伤口：把纱布（有止血纱布更好）**一点一点塞进伤口深处**，直到塞满，然后在上面用力压至少 3 分钟。

### 3. 止血带（四肢的致命出血）

**用在**：手臂或腿上，直接压迫止不住的大出血，或者喷血、血流成股。

- 位置：伤口上方（靠近心脏的一侧）**约 5–8 厘米（2–3 英寸）**，**不要放在关节上**；如果在关节处，就放到关节上方。
- 一时找不到伤口在哪、或者光线差、情况混乱：放在**肢体最高处（腿根、腋下下方）**，也就是「high and tight」。
- 拉紧带子，**拧绞棒直到出血停止**，固定住绞棒。**会非常疼**，这是正常的，不是做错了。
- **记下时间**（写在止血带上或伤员额头上），告诉救援人员。
- 上了以后**不要自己松开**，交给医生处理。

**老观念 vs 现在**：以前教的是「止血带是最后手段，绑了肢体就保不住」。现在根据大量战场和民间创伤的经验，**对四肢致命性出血要早用、果断用**，正确使用的止血带在送医的几小时内很少导致截肢。

**买真的、练过的**：用三角巾和木棍临时绑的止血带经常拧不紧或松脱。建议买 **CAT** 或 **SOF-T** 这类经过验证的商用止血带（注意网上很多仿品），并且**在自己腿上练过几次**。

> 注意：**毒蛇咬伤绝对不能用止血带**，见 [南加州野外的动植物风险](socal-wildlife-plants.md)。

## 扭伤：从 RICE 到 PEACE & LOVE

徒步最常见的伤是**崴脚**。

**老办法 RICE**（Rest 休息、Ice 冰敷、Compression 加压、Elevation 抬高）是 1978 年提出的，几十年来是标准。后来连提出者本人都说冰敷可能延缓愈合。

**新框架 PEACE & LOVE**（2019 年发表在《英国运动医学杂志》）：

| 阶段 | 字母 | 意思 |
|---|---|---|
| **头几天 PEACE** | **P**rotect 保护 | 头 1–3 天少动受伤部位，但**不要长时间完全不动** |
| | **E**levate 抬高 | 抬到心脏以上，帮助消肿 |
| | **A**void anti-inflammatories 避免消炎 | 炎症是修复的一部分；**不建议常规吃布洛芬等消炎药，也对冰敷打了问号** |
| | **C**ompress 加压 | 弹力绷带或贴布，减轻肿胀 |
| | **E**ducate 了解 | 知道恢复要时间，别指望被动治疗 |
| **之后 LOVE** | **L**oad 负重 | 疼痛允许就**尽早开始正常活动** |
| | **O**ptimism 乐观 | 心态影响恢复 |
| | **V**ascularisation 血液循环 | 几天后做不疼的有氧运动（骑车、游泳） |
| | **E**xercise 锻炼 | 练平衡和力量，**降低再次崴脚** |

**在山里实际怎么做**：

1. 停下来，脱鞋看看。**能不能自己站起来走四步？**走不了、骨头某一点压着剧痛、明显变形 → 按骨折处理，考虑求救。
2. 能走：**用弹力绷带或贴布把脚踝固定住**，**鞋带系紧**（鞋本身就是很好的支撑），用登山杖分担重量，慢慢走出去。
3. 冰敷可以**短时间用来止痛**，但不是必须的，也别为了冰敷在冷天里停很久。
4. 回家后按 PEACE & LOVE 恢复。几天还不能负重、或者反复崴，去看医生。

## 骨折：简单固定

野外不需要你判断「是不是骨折」——**疼、肿、变形、不能用**，就按骨折处理。

- **原则**：固定**伤处上下两个关节**（小腿骨折要固定膝盖和脚踝）。
- **按发现时的姿势固定**，不要试图掰直（除非肢体已经没有血液循环，而且救援非常远——这需要培训）。
- **材料**：SAM 夹板（可塑形的铝芯泡沫板，强烈推荐放进急救包）、登山杖、防潮垫卷起来、硬纸板，用三角巾、绷带、衣服、胶带绑住。空隙用衣服填满。
- **固定前后检查「CSM」**：**C**irculation 循环（手指/脚趾是否温暖、颜色正常）、**S**ensation 感觉（能不能感觉到你在摸）、**M**otion 运动（能不能动手指脚趾）。固定后变差了，说明绑太紧，松一松。
- **开放性骨折**（骨头刺出皮肤）：止血、用干净的敷料盖住，**不要把骨头塞回去**，求救。
- **手臂**骨折：用三角巾吊起来，再绑一圈贴住身体，很多人能自己走出去。
- **腿**骨折：通常走不了，叫救援。

## 水泡

水泡是**最可以预防**的伤，也是最常毁掉一次徒步的伤。

- **一感到某处发热、摩擦（hot spot）就停下处理**，别等起泡。贴上胶带（Leukotape 之类的布基胶带很好用）或 moleskin。
- **小的、没破的水泡**：别挑，用中间挖了洞的 moleskin（甜甜圈形）垫一圈，减少压力。
- **大的、很疼、影响走路的**：洗干净，用消毒过的针从**边缘**扎个小口把液体放出来，**保留表皮**，盖上敷料或水泡贴。
- **已经破了的**：洗干净，涂点凡士林或抗生素药膏，盖上。
- 预防：合脚、磨合过的鞋，排汗袜子（不穿棉袜），见 [吃什么、背什么](outdoor-food-and-pack.md)。

## 擦伤、割伤的清洗

**冲洗**是防感染最重要的一步，比用什么消毒药水重要得多。

1. 先止血。
2. **用大量干净的水冲**——能喝的水就可以，**至少半升到一升**。用带压力的水流冲效果最好：注射器，或者在密封袋角上扎个小洞挤。
3. 把沙子、碎石、木屑弄出来（镊子）。
4. 涂一层**凡士林或抗生素药膏**，盖上敷料，每天换。

**老习惯 vs 现在**：双氧水、碘酒直接往伤口里倒、酒精擦伤口——这些会**伤害正常组织**，现在不推荐用来清洗伤口。碘伏可以擦**伤口周围**的皮肤。

**要去看医生**：伤口很深、裂开合不上、在脸上或关节上、被动物咬的、里面的脏东西弄不干净，或者几天后**红肿热痛扩散、流脓、发烧**。另外想一想：**破伤风疫苗**上次打是什么时候？成人每 10 年加强一次，脏伤口超过 5 年就该补。

## 过敏性休克（Anaphylaxis）

可以由蜂蜇、食物（坚果、海鲜）、药物引起。**几分钟内**就能危及生命。

**征兆**（常常不止一个系统）：

- 皮肤：全身荨麻疹、发红、嘴唇和眼睛肿
- 呼吸：喉咙发紧、声音嘶哑、喘、呼吸困难
- 循环：头晕、虚弱、脸色苍白、晕倒
- 肠胃：呕吐、腹痛

**处理**：

1. **立刻用肾上腺素**——这是唯一真正有效的急救药。**别犹豫**，不确定也打；打了没什么坏处，不打可能致命。
2. **打 911**，哪怕打完以后感觉好了（症状可能几小时后反弹）。
3. 姿势：**躺下抬高腿**；呼吸困难就让他坐起来；呕吐就侧躺。**别让他站起来走动。**
4. 5–15 分钟没有好转或又加重，**打第二支**（这就是为什么要带两支）。
5. 抗组胺药（Benadryl）可以缓解痒和荨麻疹，但**不能代替肾上腺素**。

**EpiPen 怎么用**（以说明书为准，各品牌略有不同）：

- 拔掉蓝色安全盖，**橙色一头朝下**（「Blue to the sky, orange to the thigh」）。
- 用力按在**大腿外侧中间**，**可以隔着裤子**。
- 听到「咔」一声后**保持约 3 秒**，然后拔出、揉一揉注射部位。
- 用过的笔交给救护人员。

2024 年起美国还有获批的**肾上腺素鼻喷剂**（neffy），不需要针头。有过敏史的人和医生商量带哪种。

**同伴的责任**：和有严重过敏的人一起出门，问清楚**药放在哪、怎么用**。

## 头部受伤：危险信号

在步道上摔倒磕到头、被落石砸到，很常见。大多数是轻微的，但**颅内出血可能几小时后才表现出来**。

**出现以下任何一条 → 打 911，立刻撤离**（参考 CDC 的脑震荡危险信号）：

- 昏迷过，哪怕很短
- **越来越困、叫不醒**
- **头疼越来越重**
- **反复呕吐**
- 说话含糊、糊涂、认不出人、行为异常、烦躁
- 一边瞳孔比另一边大
- 手脚无力、麻木、走路不稳
- 抽搐
- 耳朵或鼻子流出清水样液体或血

**没有这些信号的轻微磕碰**：停止当天的活动，有人陪着慢慢下山，**接下来 24 小时别让他一个人待着**，观察以上信号。

**摔得很重 + 脖子疼**：可能伤到颈椎。让他**保持不动**，用手稳住头，叫救援。除非有立刻的危险（落石、水），否则别搬动。

## 急救包清单

按一两个人、一天到两天一夜的行程准备。装在一个**防水、颜色显眼**的袋子里，**每次出发前检查**，用了就补。

**止血和伤口**

- [ ] 丁腈手套 2 副
- [ ] **止血带 1 个**（CAT 或 SOF-T，正品）
- [ ] 纱布卷 2 卷、大块敷料 / 创伤敷料 1–2 块（有止血纱布更好）
- [ ] 各种尺寸创可贴、纱布块
- [ ] 布基胶带（Leukotape 或运动胶带）
- [ ] 冲洗用的 10–20 ml 注射器（不带针）
- [ ] 小包凡士林或抗生素药膏、碘伏棉签

**扭伤和骨折**

- [ ] 弹力绷带 1 卷
- [ ] 三角巾 1–2 条
- [ ] SAM 夹板 1 块

**水泡和小问题**

- [ ] Moleskin 或水泡贴
- [ ] 小剪刀、细尖镊子、安全别针、消毒过的针
- [ ] 梳子（沙漠里拔仙人掌刺，见 [南加州野外的动植物风险](socal-wildlife-plants.md)）

**药品**（按自己的情况，过期的换掉）

- [ ] 止痛药：对乙酰氨基酚（Tylenol）、布洛芬
- [ ] 抗组胺药（Benadryl）
- [ ] 止泻药
- [ ] 电解质粉
- [ ] 个人常用药多带一天的量
- [ ] 有过敏史：**肾上腺素 2 支**

**其他**

- [ ] 应急保温毯（铝膜）
- [ ] 防水的小本子和笔（记时间、伤情、用药）
- [ ] 头灯（单独放，见 [十大必备与行程计划](ten-essentials-trip-plan.md)）
- [ ] 手机里装上 **Red Cross First Aid** App（离线也能看）

## 去哪上课

两天左右的 WFA 课程是最划算的投资，可以在模拟场景里亲手练这些操作。证书一般 **2 年**有效，到期重新上。几个常见、认可度高的机构：

| 机构 | 课程 | 说明 |
|---|---|---|
| **NOLS Wilderness Medicine** | Wilderness First Aid (WFA) | 16 小时，两到两天半；之后可以进阶 WFR（Wilderness First Responder） |
| **SOLO Wilderness Medicine** | Wilderness First Aid | 老牌野外医学学校，全美有合作开课点 |
| **American Red Cross** | Wilderness and Remote First Aid | 红十字会的野外版急救课，开课时间地点在官网查 |
| **Wilderness Medical Associates (WMA)** | Wilderness First Aid | 另一家常见的野外医学培训机构 |

南加州一年里有不少场次，REI、大学户外社团、Sierra Club 等经常合办，搜「Wilderness First Aid Los Angeles / Inland Empire」就能找到。顺便把 **CPR** 也学了。
