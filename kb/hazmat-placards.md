# 危险品标志怎么认：九大类、UN 编号和 ERG

在场子里看到柜子或拖车四面挂着菱形牌子，就说明里面装着危险品（hazmat）。牌子叫 **placard**，贴在单个包装箱上的小号版本叫 **label**。认得这些牌子，一是为了停放、挪柜时心里有数，二是万一出事，能第一时间告诉别人「里面是什么」。

## 九大类危险品

全世界用的是同一套联合国分类，美国的规定（49 CFR）基本照搬。牌子的**底部数字**就是类别号，看颜色和图案也能认个大概。

| 类别 | 是什么 | 牌子颜色 | 图案 | 常见例子 |
|---|---|---|---|---|
| **1** 爆炸品 | 炸药、烟花、弹药 | 橙色 | 爆炸的炸弹 | 烟花、雷管 |
| **2.1** 易燃气体 | | 红色 | 火焰 | 丙烷、打火机气 |
| **2.2** 非易燃无毒气体 | | 绿色 | 气瓶 | 氮气、二氧化碳、灭火器 |
| **2.3** 有毒气体 | | 白色 | 骷髅 | 氯气、氨（无水） |
| **3** 易燃液体 | | 红色 | 火焰 | 汽油、酒精、油漆、香水 |
| **4.1** 易燃固体 | | 红白竖条纹 | 火焰 | 火柴、硫磺 |
| **4.2** 易自燃物质 | | 上白下红 | 火焰 | 某些金属粉、浸油的布 |
| **4.3** 遇水危险 | 遇水放出易燃气体 | 蓝色 | 火焰 | 钠、电石 |
| **5.1** 氧化剂 | 帮助别的东西燃烧 | 黄色 | 圆圈上的火焰 | 硝酸铵、泳池消毒剂 |
| **5.2** 有机过氧化物 | | 上红下黄 | 火焰 | 某些树脂固化剂 |
| **6.1** 毒性物质 | | 白色 | 骷髅 | 农药、某些化工原料 |
| **6.2** 感染性物质 | | 白色 | 生物危害标志 | 医疗样本（一般只贴 label） |
| **7** 放射性物质 | | 上黄下白 | 三叶形辐射标志 | 医用同位素 |
| **8** 腐蚀品 | | 上白下黑 | 液体滴在手和金属上 | 硫酸、电池酸液、强碱清洁剂 |
| **9** 杂项危险品 | 不属于前八类但运输时有危险 | 上半部黑白竖条纹，下半部白 | 条纹 | 锂电池、干冰、部分磁性物质 |

几个容易混的：

- **红色火焰**有好几种（2.1、3、4.1、4.2），一定看底部数字。
- **白色骷髅**也有两种：2.3 是气体，6.1 是液体或固体。气体更危险，因为会飘散。
- 美国国内还有一块写着 **DANGEROUS** 的牌子，用在混装了好几种危险品的车上。

## UN 编号和橙色牌

类别只告诉你「哪一类危险」，**UN 编号**才告诉你「具体是什么东西」。它是联合国给每种危险品分配的四位数字。

UN 编号会出现在两个地方之一：

- 写在菱形牌子中间的白色区域里；
- 或者单独挂一块**橙色长方形牌子**，黑字写四位数。

槽罐车、罐式集装箱这类散装容器，以及同一种危险品装得很多的车，必须显示 UN 编号。一些常见的：

| UN 编号 | 是什么 |
|---|---|
| 1203 | 汽油 |
| 1202 | 柴油 |
| 1075 | 液化石油气 |
| 1170 | 乙醇 |
| 1263 | 油漆及相关材料 |
| 1993 | 未另列明的易燃液体 |
| 1830 | 硫酸 |
| 3480 / 3481 | 锂离子电池 / 装在设备里或和设备包在一起的锂离子电池 |
| 3090 / 3091 | 锂金属电池 / 装在设备里或和设备包在一起的锂金属电池 |

## 用 ERG 查编号

**ERG**（Emergency Response Guidebook，应急响应指南）是美国、加拿大、墨西哥政府联合出的小册子，大约四年更新一版，有免费的手机 App。它是给第一个到场的人用的，不需要化学知识也能看懂。

| 页的颜色 | 内容 | 怎么用 |
|---|---|---|
| **黄页** | 按 UN 编号排序 | 看到四位数字，就从这里查 |
| **蓝页** | 按物质英文名称排序 | 知道名字时查 |
| **橙页** | 编号 111–174 左右的应对指南 | 黄页、蓝页会告诉你看哪一页：有什么危险、要隔离多远、着火怎么办 |
| **绿页** | 有毒吸入性物质的初始隔离和防护距离 | 黄页、蓝页里被标亮的物质要再查这里 |

只看到牌子、看不清编号时，ERG 前面还有一张按牌子图案对应指南页的表，可以先按类别查个大概。

建议在手机上装好 ERG App，有事的时候不用找纸本。

## 什么时候必须挂牌

这里只说美国国内运输的**一般规则**，例外很多，实际以承运人和托运人的合规人员为准。

- **表 1 的危险品：不论多少，都要挂牌。**包括 1.1–1.3 类爆炸品、2.3 有毒气体、4.3 遇水危险、6.1 中吸入有毒的、贴黄色 III 级标签的放射性物质，以及部分温控的有机过氧化物。这些是最危险的。
- **表 2 的危险品：总毛重达到 1,001 磅（约 454 公斤）及以上，才要挂牌。**其他类别基本都在这张表里。
- **第 9 类**比较特殊：美国国内运输一般不要求挂第 9 类牌，但很多人照样挂。**从海外来的柜子**按国际海运规则（IMDG）走，第 9 类通常四面都有牌。
- **限量包装**（limited quantity）：上下黑色三角、中间白色的菱形标记，量小，一般不用挂 placard。

车辆和柜子挂牌时，**四个面都要挂**。牌子缺了、脏了看不清，或者柜子已经空了却还挂着牌，都应该报告。

## 锂电池为什么是第 9 类

锂电池本身不是易燃液体也不是爆炸物，但短路、挤压、进水、质量差时可能发生**热失控**：越来越热、冒烟、起火，而且一节着了会引燃旁边的。所以被归入第 9 类。

- 单个包装上常见两种标记：**第 9 类锂电池标签**（下半部有电池图案），或者**锂电池标记**（红色斜线边框的长方形，带电池图案）。
- 电动车、电动自行车、充电宝、电动工具、带电池的电子产品都可能在柜里。
- 危险信号：箱子**鼓包、发热、冒烟、有刺鼻的甜味或塑料烧焦味**。

## 堆场里遇到泄漏、怪味怎么办

先记住一句：**你的工作是远离和报告，不是处理。**

1. **立刻远离**：往**上风处**走，能往高处就往高处。不要从漏出的液体或烟雾中间穿过去。
2. **不要碰**：不碰液体、不开柜门、不挪柜子、不试图堵漏。
3. **不要用鼻子去确认**：有些毒气闻不到，有些闻一下就足以伤人。
4. **杜绝火源**：不抽烟，车头熄火，别在附近开关电器。
5. **报告**：马上告诉主管，严重的直接打 **911**。说清楚：
   - 位置（哪一排、哪个位置）；
   - 柜号或拖车号；
   - 牌子的类别和 UN 编号（用手机变焦**远远地拍**，不要走近去看）；
   - 看到了什么：液体、烟、火、气味、有没有人不舒服。
6. **拦住别人**：别让同事或司机靠近，等专业人员来。

**熏蒸柜**也要特别小心：有的进口柜在出发前做过熏蒸，柜门上会贴**熏蒸警告标志**（FUMIGATION WARNING / DANGER）。熏蒸气体可能有剧毒、无色无味。看到这种标志，**不要开门**，交给有资质的人通风处理。

> 这篇是给认标志用的入门介绍，不能代替公司的危险品培训和应急预案。真遇到情况，以现场主管、消防和公司流程为准。
