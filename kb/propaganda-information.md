# 宣传与信息：怎么识别，怎么自保

多数人对宣传的想象是"编造假消息"。但真正高明的宣传恰恰相反：**它可以句句是真话，靠挑选、排序、重复和情绪来塑造结论**。这篇先讲清楚宣传到底是什么、有哪些经典手法，再讲算法和 AI 给信息环境加了什么新变量，最后给一份普通人能长期执行的自保清单。

## 先澄清三个概念

- **宣传（propaganda）**：有组织地传播信息以影响公众态度与行为。它的关键特征不是真假，而是**目的性与单向性**——只让你看到对结论有利的那一面。政府、企业、团体、个人都可能做宣传。
- **虚假信息（disinformation）**：明知为假而故意传播。**错误信息（misinformation）**：不知为假而转发——多数人传播的其实是后者，这也是为什么"辟谣"效果有限：转发的人并不是在作恶。
- **审查与信息控制**：宣传是往信息池里"加料"，审查是"抽水"，两者常配套使用。判断一个信息环境，不光看它说了什么，也看它**不让说什么**。

还有一个容易被忽略的对称性：每个阵营都倾向于把对方的信息叫"宣传"、把自己的叫"事实发布"。识别宣传的框架必须对所有来源一视同仁，否则框架本身就成了宣传工具。

## 经典手法：一个世纪没怎么变

这些手法在两次世界大战期间就被系统总结过，今天仍然每天在用：

| 手法 | 做法 | 识别信号 |
|---|---|---|
| 贴标签 | 用情绪化称呼代替论证（"卖国贼""殖民者"） | 通篇是形容词，找不到具体事实 |
| 光辉联想 | 把主张与受爱戴的符号绑定（国旗、英雄、母亲） | 画面很燃，但与政策细节无关 |
| 诉諸恐惧/荣耀 | 先放大威胁，再给出唯一解法 | "再不行动就晚了"的紧迫感 |
| 假两难 | 只给两个选项，抹掉中间地带 | "不站我们就是站敌人" |
| 从众效应 | 宣称"所有人都支持" | 用声量冒充比例，见不到真实民调 |
| 断章取义 | 引用真实片段，剥离上下文 | 只有截图和金句，找不到原文链接 |
| 重复成真 | 同一说法高频重复 | 熟悉感被误认为可信度（心理学上的单纯曝光效应） |
| 消防栓策略 | 短时间内抛出大量互相矛盾的说法，不求你信哪个，只求你觉得"真相不可知" | 版本多到让人放弃核查——研究机构兰德公司称之为 firehose of falsehood |

注意最后一条：现代信息战的一个重要目标不是让你相信某个谎言，而是**让你谁都不信**。犬儒式的"全是宣传、没有真相"看起来清醒，实际上是放弃判断——这正是消防栓策略想要的结果。

## 算法时代：三个新变量

1. **分发逻辑变了**：过去由编辑决定头条，现在由 engagement（互动率）决定推送。情绪强烈的内容（愤怒、恐惧、优越感）天然互动更高，于是算法系统性放大最极端的那部分声音——不需要任何人下令，信息环境自动向极端倾斜。
2. **成本塌了**：水军、假账号、AI 生成的图文视频，把"制造声量"的成本压到接近零。深度伪造让"眼见为实"失效：一段视频是真的，需要额外证据，而不是默认成立。
3. **回音室与身份绑定**：信息消费变成身份表达——转发某条消息是在声明"我是哪边的人"。这时事实核查几乎无效，因为纠正事实会被听成攻击身份。

## 各国与各方怎么做（保持对称的视角）

- **国家级信息行动**：俄罗斯的机构化外宣与网络行动、美国及盟友的公共外交与"战略传播"、各国在战争中的战报发布，本质上是同一类工具的不同用法，区别在透明度与受约束程度。俄乌战争是社交媒体时代第一场全程直播的战争，案例见 [俄罗斯与乌克兰](russia-ukraine.md)。
- **商业宣传**：广告、公关、软文、"自来水"营销，手法与政治宣传完全同构，只是目标换成购买行为。识别训练完全可以先从商业软文练起——比如分清一篇"测评"到底收没收钱。
- **平台自身的立场**：推荐算法、限流与标注规则也是权力。判断平台时，别只看它封了谁，也要看它推了谁。

## 普通人自保清单（可执行版）

1. **情绪自检**：一条消息让你瞬间愤怒或狂喜，先停 30 秒。情绪峰值就是传播设计的靶心，越上头越要慢。
2. **横向阅读（lateral reading）**：不要在原页面里深挖（那是设计好的漏斗），而是新开标签页搜"这个说法 + 来源/争议"，看其他可靠来源怎么说。斯坦福的研究显示，专业事实核查员与普通人的核心差别就在这一步。
3. **找一级来源**：数据找统计机构原文，政策找文件原文，言论找完整视频而不是剪辑。找不到原文的"重磅消息"，默认降权。
4. **看谁在获益，但不止于此**："对谁有利"是线索不是结论——有利的说法也可能是真的。用它来决定"多查一步"，而不是决定信不信。
5. **等一等**：重大事件的最初 24 小时是错误信息密度最高的时段。"第一个版本"几乎总是不完整的。
6. **维护信息源组合**：刻意保留两三个立场不同但专业可靠的来源，让它们互相打架。你的目标不是找到"绝对中立"的来源（不存在），而是让自己的信息食谱不单一。
7. **转发前过一遍**：转发即背书。拿不准的，要么不转，要么注明"未经证实"。这一条对家庭群尤其重要。

> 目标不是变成什么都不信的人，而是把"信"变成一个分等级的动作：这条我核查过、这条大概率真、这条先存疑。宣传最怕的不是质疑一切的人，而是会分级的人。
