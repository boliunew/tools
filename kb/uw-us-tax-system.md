# 美国税制（一）：谁收税、收什么税、钱花到哪里

## 一句话

**联邦收你的工资税和所得税，州收所得税和销售税，市县收房产税；联邦的钱大部分花在养老、医疗、国防和还利息上。**

> 这篇讲制度和历史。自己怎么报税，看 [W-2 打工族报税入门](w2-tax-basics.md) 和 [投资账户与税](us-investment-accounts-tax.md)。文中数字以 2026 税年为准，每年都会调整。

## 三层税

| 层级 | 主要税种 | 加州 / 本地的例子 |
|---|---|---|
| **联邦** | 个人所得税、工资税（社保 + 医保）、公司所得税、关税、消费税（汽油、烟酒）、遗产税 | 联邦汽油税每加仑 18.4 美分 |
| **州** | 个人所得税（有些州没有）、销售税、公司税、汽油税 | 加州个人所得税 1%–12.3%，百万以上收入再加 1%；销售税基础 7.25% |
| **地方（县、市、学区）** | 房产税、地方销售税附加 | Upland 所在的圣贝纳迪诺县，销售税合计约 7.75%；房产税在 1978 年 13 号提案之后大约是购入价的 1% 左右，每年评估值最多涨 2% |

**没有州所得税的州**：德州、佛州、内华达、华盛顿、田纳西、南达科他、怀俄明、阿拉斯加、新罕布什尔（只是不征工资收入税）。它们通常靠更高的销售税或房产税补回来。

## 联邦个人所得税：累进制

- **累进**：收入分段，每一段按不同税率。2026 税年的七档税率是 **10%、12%、22%、24%、32%、35%、37%**。
- 只有超过某个门槛的那一部分按更高税率算，所以**涨工资不会让你到手更少**，这是常见误解。
- **标准扣除**（2026 税年）：单身 16,100 美元、夫妻合报 32,200 美元、户主 24,150 美元。收入减去扣除才是应税收入。
- **边际税率**（最后一块钱的税率）和**平均税率**（总税 ÷ 总收入）不同，平均税率总是低得多。
- **抵免（credit）比扣除（deduction）值钱**：扣除是减少应税收入，抵免是直接减少税款，比如儿童税收抵免（2026 年每个孩子 2,200 美元）、劳动所得抵免（EITC）。

## 工资税：社保和医保

| 项目 | 员工付 | 雇主付 | 说明 |
|---|---|---|---|
| 社会保障（Social Security） | 6.2% | 6.2% | 只对工资的前 184,500 美元征收（2026 年） |
| 联邦医保（Medicare） | 1.45% | 1.45% | 没有上限；高收入者加 0.9% |
| 合计（FICA） | **7.65%** | 7.65% | 自雇者两边都要付，共 15.3% |

对多数中低收入家庭来说，**工资税比所得税交得还多**。

## 钱从哪里来、到哪里去（联邦，近年大致比例）

| 收入来源 | 约占 |
|---|---|
| 个人所得税 | 约一半 |
| 工资税 | 约三分之一 |
| 公司所得税 | 约十分之一 |
| 关税、消费税、其他 | 其余（2025 年后关税收入明显上升） |

| 支出 | 约占 |
|---|---|
| 社会保障（养老金） | 约五分之一 |
| 医疗（Medicare、Medicaid、平价医保补贴） | 约四分之一 |
| 国防 | 约八分之一 |
| 国债利息 | 已超过国防开支 |
| 其他（教育、交通、科研、退伍军人、食品券……） | 其余 |

联邦政府几乎每年都有**赤字**（支出大于收入），由借钱弥补；公众持有的国债已经和一年的 GDP 规模相当。

## 历史上的几个关键节点

| 年份 | 事件 |
|---|---|
| 1789–1913 | 联邦主要靠关税和消费税；内战时短暂征过所得税 |
| 1913 | **第 16 修正案**允许联邦征收所得税，最初只有很少的富人要交 |
| 1935 | 《社会保障法》，开始征工资税 |
| 1943 | 二战期间开始**工资预扣**，所得税变成「大众税」 |
| 1944–1963 | 最高边际税率 91%–94%（但适用的人极少，扣除和漏洞很多） |
| 1981、1986 | 里根减税和**1986 年税改**：最高税率降到 28%，同时取消大量漏洞 |
| 1993 | 克林顿提高最高税率到 39.6% |
| 2001、2003 | 小布什减税 |
| 2017 | **《减税与就业法》（TCJA）**：公司税从 35% 降到 21%，个人税率普遍下调，标准扣除翻倍，州和地方税（SALT）扣除上限 1 万美元 |
| 2025 | **《大而美法案》（OBBBA）**：把 2017 年的个人税率永久化；SALT 上限提高到 4 万美元左右（2025–2029，高收入递减）；临时新增小费、加班费、65 岁以上老人的扣除等 |

## 常见误解

- **「进了高一档税率，所有收入都按高税率扣」**：只有超出部分按高税率。
- **「退税多说明交税少」**：退税只是今年多预扣了，年底退回而已。
- **「美国税负很重」**：以税收占 GDP 比例看，美国（约 25%，含各级政府）低于大多数发达国家（经合组织平均约 34%，北欧 40% 以上），主要差在美国没有增值税、社会保险税较低。
- **「公司不交税」**：法定税率是 21%，但很多大公司通过各种抵免和扣除，实际税率低得多；这是政策争论的焦点之一。
