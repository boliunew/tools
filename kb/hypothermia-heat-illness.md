# 失温和中暑

南加州户外的两个极端，经常在同一个周末出现：Upland 城里 35°C，Baldy 山顶下午一场雷雨加大风，气温掉到 5°C；或者冬天在山上冻了一天，下一周去 Joshua Tree 被晒到头晕。这篇讲身体太冷和太热时的征兆、处理，以及怎么避免。

> 这篇是一般性的知识，**不能代替野外急救培训**（比如 Wilderness First Aid / WFA 课程）。出现意识改变、昏迷、抽搐等严重症状，立刻打 911。更多急救内容见 [野外急救](wilderness-first-aid.md)。

## 第一部分：失温

**失温**（hypothermia）是核心体温降到约 35°C 以下。很多人以为只有冰天雪地才会失温，其实最常见的情景是 **10°C 左右、又湿又有风**的天气——人没有准备，衣服湿了，风一吹，热量流失得极快。

### 为什么南加州山上夏天也会失温

- **海拔**：大致每升高 1,000 米，气温降约 6°C。山脚 30°C 时，3,000 米的 Baldy 山顶可能只有十几度，有风时体感更低。
- **午后雷暴**：夏天（特别是 7–9 月季风期）山上下午常有雷阵雨，可能带冰雹，气温十几分钟内掉十几度。详见 [山地天气](mountain-weather-dangers.md)。
- **汗湿 + 风**：爬坡时一身汗，到了山顶或山脊停下来休息，风一吹，湿衣服贴在身上，冷得特别快。**湿衣服的保温能力大幅下降，棉的尤其差。**
- **天黑**：迷路或受伤在山上过夜，夜里气温可能比白天低 15–20°C。
- **掉进水里**：过河滑倒、玩水，身体在水里失热比在空气中快得多。

### 早期征兆：「Umbles」

在美国户外圈，失温早期征兆常用四个押韵的词来记，统称 **umbles**：

| 英文 | 意思 | 表现 |
|---|---|---|
| **Stumbles** | 走路不稳 | 绊倒、步态笨拙、跟不上 |
| **Mumbles** | 说话含糊 | 口齿不清、反应慢、答非所问 |
| **Fumbles** | 手不灵 | 拉不开拉链、系不上鞋带、拿不住东西 |
| **Grumbles** | 情绪异常 | 烦躁、冷漠、不想说话、不想动 |

再加上：**一直在发抖**、皮肤苍白发冷、判断力下降。

**重要**：失温的人自己往往意识不到，判断力下降是失温的一部分。同伴之间要互相盯着。如果有人「突然变得很不对劲」，先想想是不是冷到了（还有可能是低血糖、脱水、高原反应）。

### 严重程度

现场一般**按表现判断**，不靠体温计（野外量不准）：

| 程度 | 表现 | 怎么做 |
|---|---|---|
| **冷应激**（还不算失温） | 觉得冷、发抖，但行动、说话正常 | 加衣服、吃东西、喝热饮，动起来 |
| **轻度** | 剧烈发抖，「umbles」出现，但还清醒 | 停下来全力保暖，见下文；30 分钟内没好转要考虑求援 |
| **中度** | **发抖减弱或停止**、意识明显变差、昏昏欲睡 | **急症**。打 911，**轻拿轻放**，平躺，全面隔热保暖，**不要喂吃喝** |
| **重度** | 失去意识，不再发抖 | 打 911，检查呼吸和脉搏（摸足 **1 分钟**，失温时可能非常微弱）；没有呼吸就开始 CPR |

**发抖停止不是好转的标志**——如果人没有回暖却不抖了，说明情况在恶化。

### 怎么处理（轻度）

1. **离开风和湿**：躲到石头背风处、树林里，或者搭起应急庇护（急救毯、雨衣、帐篷）。
2. **隔开地面**：坐在背包、防潮垫、树枝上，**地面吸热比空气快**。
3. **换掉湿衣服**：在能避风的地方就**换上干衣服**；条件不允许时，在湿衣服外面套上**防水层**（雨衣、垃圾袋、急救毯）挡住风和蒸发，再加保暖层。
4. **包住头和脖子**：戴帽子、围巾、兜帽。
5. **热源放在躯干**：如果有**大的**热水袋（例如灌了热水的水瓶，包一层布防烫），放在**腋下、胸口、后背**。小的暖宝宝（hand warmer）热量不够温暖核心，只适合放在手脚上。
6. **吃喝**：人**清醒、能正常吞咽**时，给**热的、甜的**饮料和高热量食物，为身体发抖产热提供燃料。不清醒的人**不要喂**，会呛到。
7. **用睡袋包裹**，必要时同伴贴身取暖。
8. **不要急着走**。体力和体温恢复前强行下山，可能让情况更糟。轻度失温的人回暖后，通常可以在有人陪同下慢慢走出去。

### 过时或错误的做法

| 以前常说的 | 现在的建议 |
|---|---|
| **搓手搓脚**取暖 | **不要**。可能伤到冻伤的组织，也可能让手脚里的冷血突然回流到心脏，导致核心体温进一步下降（「后降」，afterdrop），引起心律失常 |
| 喝**酒**暖身子 | **不要**。酒精让皮肤血管扩张，觉得暖和，实际上散热更快，还影响判断 |
| 把冻得很重的人**泡进热水里** | 野外**不要**。重度失温的人需要医院条件下复温；现场只做隔热、躯干加热、轻拿轻放 |
| 让失温的人**起来走动、跑跑跳跳**暖身 | 轻度失温、刚开始冷时适度活动可以；**中度以上**要**平躺、少动**，粗暴搬动可能诱发心律失常 |
| 「人没有脉搏就是死了」 | 失温的人脉搏、呼吸可能极其微弱。一直保暖、求救，**交给医疗人员判断** |

### 怎么预防

- **按洋葱式穿衣**：贴身排汗层（化纤或美利奴羊毛，**别穿棉的**）、保暖层（抓绒、羽绒）、防风防雨外层。
- **爬坡前减衣服**，宁可开始时有点冷，别出一身大汗。**停下来休息前先加衣服**。
- 永远带一件**保暖层 + 防风外套**，即使夏天。
- **吃够喝够**，身体需要燃料产热。
- 天气变坏、有人出现 umbles，**早点掉头**。见 [出门前：十大必备、行程计划和掉头时间](ten-essentials-trip-plan.md)。

## 第二部分：热衰竭和中暑

夏天的 Inland Empire 山脚、朝南的前山、Joshua Tree 和 Mojave 沙漠，是南加州热相关疾病最集中的地方。

### 热衰竭 vs 中暑

最关键的区别：**中暑（heat stroke）会影响大脑，人会意识混乱。** 热衰竭是警报，中暑是急症。

| | **热衰竭**（heat exhaustion） | **中暑 / 热射病**（heat stroke） |
|---|---|---|
| 意识 | **清醒**，能正常回答问题 | **混乱**、说话含糊、行为反常、抽搐、昏迷 |
| 皮肤 | 通常大量出汗，皮肤湿冷或温 | 很烫；**可能干，也可能还在大量出汗** |
| 其他 | 头痛、头晕、恶心、乏力、口渴、烦躁、尿少、体温升高 | 体温非常高；可能有热衰竭的所有症状 |
| 严重程度 | 需要马上处理，不处理可能发展成中暑 | **致命急症**，耽误治疗可能死亡 |

**一个常见误区**：「中暑的人不出汗」。现在 CDC 的说法是，中暑者的皮肤**可能干、也可能大量出汗**——尤其是运动中发生的中暑，人常常还在出汗。**判断的关键是意识状态**，不是有没有汗。

### 热衰竭怎么处理

1. **停止活动**，马上到**阴凉处**（树荫、大石头背阴面，实在没有就用急救毯或雨伞搭个遮阳）。
2. **松开、脱掉多余衣服**，包括鞋袜。
3. **降温**：用水打湿头、脸、脖子，用帽子扇风。
4. **小口多次喝凉水**，最好是**含电解质**的饮料，同时吃点咸的东西。
5. 休息到症状消失。**多数情况下，这一天就不该再往前走了**，等傍晚凉下来再下山，或者联系求援。
6. 症状加重、**呕吐喝不下水**、休息后不好转，或者**一旦出现意识混乱** → 按中暑处理，打 911。

### 中暑怎么处理：先降温

中暑时，**降温越快，结果越好**。现在急救医学的共识是：**先降温，同时求救**（体育医学里叫「cool first, transport second」，先降温、再转运）——不要等救援到了才开始。

1. **打 911**（没信号就发短信 911 或用卫星 SOS，见 [迷路了怎么办](lost-navigation.md)）。
2. **移到阴凉处**，脱掉外衣。
3. **立刻用一切办法降温**：
   - **最有效的是冷水浸泡**：如果旁边有溪水、水潭，在有人扶着、头露出水面的前提下，把身体泡进凉水里
   - 没有条件时：**把衣服和皮肤全部打湿**，持续用水浇，同时**大力扇风**（蒸发散热）
   - 有冰或冷敷包时，放在**脖子、腋下、腹股沟**，同时打湿全身
4. **不要喂水**给意识不清的人，会呛到。
5. 一直有人陪着，直到救援到达。

> 在野外一下子拿不出那么多水降温，这也是为什么沙漠和热天要多带水、**并且一开始就别让自己热到这个地步**。

### 热痉挛

大量出汗后小腿、腹部肌肉抽筋，通常是**盐和水分流失**的信号。停下休息，喝电解质饮料，吃咸的东西，轻轻拉伸。抽筋有时是热衰竭的前兆，别硬撑着继续走。

### 哪些人更容易出事

- 不习惯高温的人：**每年初夏第一波热浪**最危险，身体需要一到两周慢慢适应
- 前一晚没睡好、喝了酒、生病（发烧、腹泻）
- 体重较大、年纪大、有心脏病等慢性病
- 吃某些药物（如部分降压药、利尿剂、抗过敏药、精神类药物）——有长期用药的，问医生
- **小孩和狗**

## 沙漠徒步的规矩

Joshua Tree、Mojave、Anza-Borrego 这些地方冬春很美，夏天就是另一回事。

- **夏天避开白天**：Joshua Tree 国家公园建议夏天**不要在上午 10 点到下午 5 点之间徒步**，短途散步也要在**早上 9 点前**开始；**难度大的路线夏天或者天热时根本不要去**。
- **去冬春，不去夏天**：沙漠徒步的好季节大约是 **11 月到次年 4 月**。
- **水按「多」带**，加上电解质和咸的零食。见 [野外的水](water-in-the-wild.md)。
- **没有树荫**：长袖防晒衣、宽檐帽、太阳镜，比短袖更凉快，因为挡住了直晒。
- **地形容易迷路**：沙漠里的「步道」常常只是沙地上的脚印，岔路很多，看起来都一样。Joshua Tree 公园还特别提醒，**不要完全依赖众包的徒步 App**，信息可能误导。
- **手机信号差**，大片区域没有信号。
- **告诉别人行程**，回来后报平安。
- **不要因为车坏了就离开车**去徒步找救援。车是阴凉、是目标，搜救找车比找人容易得多。

## 多热就别出门

没有一个官方统一的「多少度禁止徒步」。下面是一个**个人可以参考的经验做法**，不是官方标准，按自己的体能和适应程度调整：

| 步道口预报最高温（约） | 建议 |
|---|---|
| 27°C（80°F）以下 | 正常出行，注意带水 |
| 27–32°C（80–90°F） | 早出发，中午前结束；选有树荫、海拔高的路线 |
| 32–38°C（90–100°F） | 只走短线，清晨走；或者**往高海拔去**（Big Bear、Baldy 高处） |
| 38°C（100°F）以上 | 低海拔和沙漠**别去**；改去高山或改天 |

另外看两个官方工具：

- **NWS 高温警报**：**Heat Advisory**（高温提示）和 **Extreme Heat Warning**（极端高温警告，2025 年起取代了以前的 Excessive Heat Warning 这个名字）。有警告的那天，低海拔户外活动就别安排了。
- **NWS HeatRisk**：按 0–4 级给出当天高温对健康的风险，weather.gov 上可以查，考虑了「对当地来说这个温度有多反常」。

记住：**预报的是阴凉处的气温**。在太阳直射、没有风的南向山坡上，体感和地面温度会高得多。

## 车里留水

两层意思：

1. **回程用的备用水**：车里常备**一大桶水**（几升）和电解质饮料、一点咸零食。从山上下来就能补，不用硬撑着开车去找便利店。车坏在沙漠公路上时，这桶水可能救命。热天车里的水会很烫，但仍然能喝、能用来浇身体降温。
2. **反过来**：**任何时候都不要把小孩、宠物留在车里**，哪怕几分钟、开着一点车窗。太阳下的车内温度会很快升到致命的程度。

## 一张清单

出发前：

- [ ] 看山上的预报：最低温、风、雷暴；看山下和沙漠的最高温、高温警告、HeatRisk
- [ ] 带保暖层 + 防风防雨外套（夏天也带）
- [ ] 带急救毯
- [ ] 水够，加电解质和咸零食
- [ ] 热天定好**早出发、早下山**；沙漠夏天不走长线
- [ ] 车里放一大桶水

在路上：

- [ ] 爬坡前减衣服，停下前加衣服
- [ ] 同伴之间盯着 **umbles** 和热衰竭的征兆
- [ ] 有人意识混乱 → 当成急症：太冷就全面保暖，太热就**立刻降温**，同时打 911
