# 国际贸易和关税：为什么国家之间要做买卖，关税到底谁付

## 一句话

**贸易让每个国家做自己相对最擅长的事，整体上大家都更富；但得益和受损的人不是同一批人，这正是贸易政治化的根源。**

## 来龙去脉

- **重商主义**（16–18 世纪）：一国的财富就是金银，要多出口少进口，用关税和殖民地保住顺差。
- **1776 年亚当·斯密**：财富是能生产的东西，不是金银；自由贸易让分工扩展到全世界。
- **1817 年大卫·李嘉图**：提出**比较优势**。英国和葡萄牙都生产布和葡萄酒，即使葡萄牙两样都比英国效率高，只要各自专做相对更擅长的、再交换，两国的总产量都会增加。
- **1930 年斯穆特—霍利关税法**：美国大幅提高关税，引发各国报复，世界贸易在大萧条期间萎缩约三分之二，成为经济学家反复提起的教训。
- **二战后**：关贸总协定（1947）、世贸组织（1995）持续降低关税；集装箱运输（1956 年起）大幅降低运费。
- **1990 年代—2000 年代**：北美自贸协定（1994）、中国加入世贸（2001）、全球供应链形成，一部 iPhone 的零件来自十几个国家。
- **2018 年以后**：中美贸易战、疫情暴露供应链脆弱、各国产业补贴（美国芯片法案等），全球化进入调整期。

## 关键概念

| 概念 | 意思 |
|---|---|
| **比较优势** | 不是看谁绝对更强，而是看谁做这件事放弃得更少（机会成本更低） |
| **贸易顺差 / 逆差** | 出口多于进口 / 进口多于出口。逆差不一定是「吃亏」，它和储蓄、投资、资本流入相关 |
| **关税** | 对进口商品征的税 |
| **配额** | 限制进口数量 |
| **补贴** | 政府给本国企业钱，让它们更有竞争力 |
| **自由贸易协定** | 几个国家之间互相降低关税，如美墨加协定（USMCA）、RCEP |
| **汇率** | 本币贬值让出口更便宜、进口更贵 |
| **供应链** | 从原料到成品经过的各个国家和企业 |

## 关税到底谁付？

- 关税是**进口商**在海关交给本国政府的。进口商可以：自己吸收（利润变少）、转嫁给消费者（涨价），或压外国供应商降价。
- 2018–2019 年美国对中国商品加征关税后，多项研究（包括美联储和学术界的研究）发现：**大部分成本由美国进口商和消费者承担**。
- 关税还有间接影响：本国用进口零件的企业成本上升；对方报复性关税打击本国出口（2018 年后美国大豆、农产品出口受影响，政府给农民发了补贴）。
- 关税的支持者说：它保护了本国就业和关键产业、是谈判筹码、能让制造业回流；代价值得付。

## 谁得益，谁受损

| 得益 | 受损 |
|---|---|
| 消费者：东西更便宜、选择更多 | 和进口竞争的行业的工人和企业 |
| 出口行业 | 产业集中的地方社区（工厂关闭影响整座城） |
| 发展中国家：靠出口实现工业化和脱贫（中国、韩国、越南、孟加拉） | |

经济学家戴维·奥托等人研究**「中国冲击」**：2000 年后来自中国的进口竞争，让美国部分制造业地区的就业和工资长期受损，工人很难转行或搬走。这比很多经济学家原先预想的更严重、更持久，也影响了美国政治。

## 不同的解释

- **主流贸易经济学**：自由贸易总体利大于弊，问题在于国内没有好好补偿和帮助受损的人（培训、社会保障）。
- **保护主义/经济民族主义**：工业是国家实力的基础，过度依赖外国是安全隐患；美国早期（汉密尔顿）、19 世纪德国（李斯特）、东亚经济体都用过关税和产业政策保护幼稚产业。
- **发展经济学的争论**：张夏准（《富国陷阱》）认为富国当年靠保护主义起家，却要求穷国开放，是「踢开梯子」；其他人则指出许多保护主义国家（如拉美进口替代时期）并不成功。
- **供应链安全派**：芯片、药品、稀土等关键产品，效率之外还要考虑可靠性，「友岸外包」「近岸外包」成为新思路。

## 常见误解

- **「贸易逆差就是国家亏钱」**：逆差反映的是一国花得比生产得多，同时有资金流入；美国长期逆差，也长期是全球资本最愿意去的地方。
- **「关税是外国人付的」**：主要是本国进口商和消费者付。
- **「贸易是一方赢一方输」**：自愿的交换通常双方都得益；但一国内部会有赢家和输家。
