# 出门前：十大必备、行程计划和掉头时间

搜救队接到的求助，很多不是因为出了大事，而是一连串小事凑在一起：出发晚了一点、水少带了一瓶、没带头灯、天黑了找不到路、手机没电。这篇讲出门前把这些小事堵住的固定流程——每周都出门的话，把它变成习惯，十分钟就能做完。

> 这篇讲准备和计划。真出了事怎么办，见 [迷路了怎么办](lost-navigation.md) 和 [野外急救](wilderness-first-aid.md)。

## 十大必备（Ten Essentials）

「十大必备」是 1930 年代西雅图的登山团体 The Mountaineers 定下来的清单，本意是：**万一要在野外意外过一夜、或者遇到突发情况，靠身上这些东西能撑过去。** 早年版本是十样具体物品（地图、指南针、火柴……），现在 REI 和 The Mountaineers 用的是更新后的「**系统**」版本：十个类别，每类具体带什么看行程长短和季节。

| # | 类别 | 南加州一日徒步的最低配置 | 说明 |
|---|---|---|---|
| 1 | **导航**（Navigation） | 手机 + 离线地图；长路线加纸质地图和指南针 | 手机会没电、会摔坏。走 Baldy、Cucamonga Peak 这类长线时，纸地图是备份 |
| 2 | **照明**（Headlamp） | 头灯 + 备用电池（或充满电） | 手机手电不算：耗电快，还占一只手。哪怕计划中午就回来也带 |
| 3 | **防晒**（Sun protection） | 帽子、太阳镜、防晒霜、唇膏；夏天加长袖防晒衣 | 南加州山上树荫少，海拔高紫外线更强。雪地还要防雪盲 |
| 4 | **急救**（First aid） | 小急救包：创可贴、纱布、胶带、水泡贴、止痛药、个人药品 | 会用比带多重要，见 [野外急救](wilderness-first-aid.md) |
| 5 | **刀具/工具**（Knife） | 小刀或多功能工具；一小卷胶带（缠在登山杖上） | 修鞋、剪纱布、切绳子 |
| 6 | **生火**（Fire） | 打火机 + 防水火柴 + 引火物 | 是**应急**用的，不是让你随便生火。南加州大部分地方平时禁止明火，见 [火](fire-and-campfire-rules.md) |
| 7 | **应急庇护**（Shelter） | 急救毯（铝箔）或应急睡袋（bivy） | 几十克重。意外过夜时挡风、保温 |
| 8 | **额外食物**（Extra food） | 比计划多一顿：能量棒、坚果 | 不需要做饭的东西 |
| 9 | **额外的水**（Extra water） | 比计划多带；长线加净水片或滤水器 | 见 [水](water-in-the-wild.md) |
| 10 | **额外衣物**（Extra clothes） | 一件保暖层 + 一件防风/防雨外套 | 山上下午起风、天黑降温很快，见 [失温和中暑](hypothermia-heat-illness.md) |

现在很多人会再加两样：**哨子**（求救比喊省力得多，很多背包胸带扣上自带）和**卫星通讯设备**（手机卫星 SOS 或 Garmin inReach 这类，见 [迷路了怎么办](lost-navigation.md)）。

### 怎么让它变成习惯

- **做一个固定的「必备小包」**：头灯、急救包、打火机、急救毯、哨子、小刀、胶带、净水片放进一个小收纳袋，平时就留在背包里，不拆出来用。每次出门只需要补水、补吃的、看天气加减衣服。
- **每季度检查一次**：头灯电池、急救包里的药是否过期、打火机还能不能打着。
- **短路线也带**。出事往往是在「就走一小时」的路线上，因为大家都没当回事。

### 按季节和地点加减

十个类别不变，里面装什么跟着季节走：

| 情况 | 额外加什么 | 可以减什么 |
|---|---|---|
| **夏天前山、低海拔** | 更多水和电解质、长袖防晒衣、宽檐帽、可以打湿的头巾 | 厚保暖层可以换成一件薄抓绒 |
| **夏天高山**（Baldy、San Gorgonio） | 防雨外套（午后雷雨）、薄手套 | — |
| **冬天高山** | **冰爪、冰镐**（并且会用）、厚保暖层、手套帽子、保温水壶、多一组头灯电池（冷天耗电快） | — |
| **沙漠**（Joshua Tree、Mojave） | 大量的水、信号镜、防晒全套；冬天夜里也冷，保暖层照带 | — |
| **山火后、大风天** | N95 口罩（烟大时）、护目镜 | — |
| **一个人走** | 卫星通讯设备、更详细的行程计划 | — |

更多吃什么、背包怎么装，见 [吃什么、背什么](outdoor-food-and-pack.md)。

## 行程计划：留给家人一份

一个人走尤其要做。没人知道你去了哪，搜救就不知道从哪找起——美国搜救界常说，一份清楚的行程计划能让搜索范围小很多。

### 计划里写什么

可以直接复制下面这段，发短信给家人或室友：

```
今天去：Ice House Canyon → Ice House Saddle（Mt Baldy 村往上）
路线：原路往返，不走岔路；如果状态好可能多走到 Cucamonga Peak
车：停在 Ice House Canyon 步道口停车场，车牌 XXXXXXX，银色 XX 车
出发：早上 7:00 开始走
预计下山：下午 2:00
最晚报警时间：晚上 6:00 还没联系上你 → 打 911
同行：一个人 / 和 XXX（电话 XXX）
衣着：红色外套，灰色背包
带了：3 升水、头灯、外套、急救包
```

几个要点：

- **路线写具体**：步道名、起点、往返还是环线、可能临时加的路段。
- **车停在哪、车牌**：搜救第一步通常是找车。
- **两个时间分开**：「预计下山」是你的计划；「**最晚报警时间**」是给对方的指令，留出几个小时的余量，免得只是走得慢就让人报警。
- **衣服颜色**：直升机和地面队找人时有用。
- **改了计划要告诉对方**。临时换路线又不说，计划就白写了。
- **下山后第一件事报平安**。别让对方在「最晚报警时间」后真去报警。

### 到点没消息，家人该怎么做

把这段也告诉家人：

1. 先打你的手机，发短信。山里没信号很正常，等半小时再试。
2. 过了「最晚报警时间」仍然联系不上，**打 911**，说清楚：人在哪个县的哪座山、哪条步道、什么时候出发、本来预计几点回、车停在哪、手机号。
3. 南加州的山地搜救由**县警长（Sheriff）**负责：Upland 北边的 Mt Baldy、Cucamonga 一带大多归 **San Bernardino County Sheriff**，往西的 Angeles 国家森林大部分归 **LA County Sheriff**。打 911 会被转到对应的单位，不需要自己判断。
4. 不要自己开车上山去找人。

## 看天气和步道开放

### 天气：看山上的，不看城里的

Upland 城里 25°C 晴天，Baldy 山顶可能 5°C 大风；城里下小雨，山上可能是雷暴或下雪。

- **NWS（weather.gov）点预报**：在 weather.gov 地图上**直接点你要去的山顶或步道**，会给出那个海拔的预报，比搜城市名准得多。南加州山区归 NWS **Los Angeles/Oxnard** 和 **San Diego** 两个预报办公室，Mt Baldy 在两者交界一带，点地图就行。
- 重点看：**最高/最低气温、风速和阵风、降水概率、雷暴**、有没有 **Red Flag Warning（红旗警告）**、**高温警告（Heat Advisory / Extreme Heat Warning）**、**冬季风暴警告**。
- 夏季午后山上容易起雷暴，冬天 Baldy 一带结冰，详见 [山地天气](mountain-weather-dangers.md)。
- 火灾季看风和空气质量，见 [山火季、Santa Ana 风和空气质量](wildfire-smoke-santa-ana.md)。

### 步道开放：南加州封路很常见

山火、暴雨冲毁、动物保护、季节性封闭，都可能让某条路关掉，**AllTrails 上的信息常常过时**。

| 去哪 | 查哪里 |
|---|---|
| Angeles 国家森林（Baldy、Ice House、Chantry Flat 等） | USFS Angeles National Forest 官网的 **Alerts & Notices** |
| San Bernardino 国家森林（Big Bear、Lytle Creek 等） | USFS San Bernardino National Forest 官网的 Alerts |
| Joshua Tree、Mojave 等国家公园/保护区 | NPS 公园官网的 **Alerts / Current Conditions** |
| 市县公园（Claremont Hills 等） | 各市、县公园官网 |
| 道路（Glendora Ridge Rd、Hwy 2、Mt Baldy Rd 等） | Caltrans **QuickMap**（网页和 App），或打 1-800-427-7623 |

另外看林务局的**火限令**（Fire Restrictions）——决定能不能用炉头、能不能生火。

### 停车证

Angeles 和 San Bernardino 国家森林很多步道口停车要挂 **Adventure Pass** 或 America the Beautiful 年票，见 [Upland 附近的徒步路线](socal-hiking-trails.md)。

## 手机：电量和离线地图

手机现在是导航、相机、求救工具三合一，所以它的电量就是你的安全余量。

### 出发前

- [ ] **前一晚充满**手机和充电宝（充电宝至少 10,000 mAh，带根线）
- [ ] **下载离线地图**：Gaia GPS、AllTrails、CalTopo 之类的离线下载多数要付费会员；Google 地图可以免费下载一块区域，但上面没有大部分山路，只能当底图
- [ ] **下载或标记路线**，起点、岔路口、水源、掉头点存成航点
- [ ] 检查**卫星 SOS** 是否可用、会不会用（见 [迷路了怎么办](lost-navigation.md)）
- [ ] 截图保存行程计划、停车位置

### 在山里省电

- **没信号的地方开飞行模式**。手机在没信号时会不停加大功率搜索基站，是最费电的情况。**GPS 在飞行模式下照样能用**，离线地图上的定位点还会走。
- 屏幕亮度调低，关掉不需要的后台 App 和蓝牙。
- 冷天把手机放在贴身口袋里，低温会让电池电量骤降甚至关机。
- 拍照很费电，长线时留意电量。
- 定个规矩：**电量剩一半时，不管走到哪都要开始考虑下山。**

## 掉头时间：到点就回

这是最容易被忽视、也最有用的一条。

### 什么是掉头时间

出发前定一个**固定的时刻**，比如「下午 1 点」：到这个时间，**不管有没有到山顶、离山顶还有多远，都掉头往回走。**

怎么算：

1. 估算下山需要多久。下山通常比上山快，但膝盖累了、天热、路滑时不一定。保守一点按上山时间的 2/3 到全部来算。
2. 从**天黑时间**（或者你想回到车上的时间）往前倒推，再留 **1 个小时以上余量**。
3. 得出的时间就是掉头时间。

例子：10 月某天，日落约 6:30 PM。你预计下山 3 小时，想在 5:30 之前回到车上（留 1 小时天光余量），那掉头时间最晚是 2:30 PM。考虑到可能慢，定在 **2:00 PM**。

> 冬天日落早得多（12 月南加州约 4:45 PM），同一条路线要早出发、早掉头。

### 不看时间也要掉头的情况

| 情况 | 为什么 |
|---|---|
| 天气变了：雷声、乌云往上堆、风突然变大 | 山顶和山脊是雷击最危险的地方 |
| 水喝掉了一半以上，还没到终点 | 回程的水不够 |
| 有人头晕、抽筋、走不动、明显变慢 | 后面只会更累 |
| 路况比预想差：结冰、落石、塌方、找不到路 | 没有冰爪就别上冰坡 |
| 电量剩一半 | 后面要靠它导航和求救 |
| 心里开始「再走一点就到了」地反复说服自己 | 这本身就是信号 |

### 为什么这么难做到

登山圈有个说法叫「**登顶狂热**」（summit fever）：离目标越近，越不愿意放弃，越容易低估风险。花了半天开车爬上来、山顶就在眼前，掉头确实心疼。办法只有一个：**在出发前、头脑清醒时就定好掉头时间和条件，到了就执行，不在现场重新商量。**山一直在那里，下周还能来。

## 一张出门前检查清单

- [ ] 路线定好：距离、爬升、预计用时、水源、出口
- [ ] 查了 **NWS 山上的点预报**、有没有警告
- [ ] 查了**步道和道路开放**、火限令
- [ ] **行程计划**发给家人，写清「最晚报警时间」
- [ ] 定好**掉头时间**，写在计划里
- [ ] 手机、充电宝**充满**，**离线地图**下载好
- [ ] 十大必备小包在背包里
- [ ] 水够（加上回程和余量）、吃的够
- [ ] 按天气加减衣服；鞋子合适
- [ ] 停车证挂好
- [ ] 下山后**报平安**
