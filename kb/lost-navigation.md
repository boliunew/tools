# 迷路了怎么办

在南加州山里迷路，常见的不是「走进原始森林找不到出口」，而是：在岔路口拐错、顺着动物踩出来的小路走偏、下山时天黑看不清步道、或者为了抄近路离开了步道。这篇讲发现不对劲以后，一步一步该怎么做。

> 这篇是一般性的安全知识，不能代替正规的导航和野外急救培训。出门前的准备见 [出门前：十大必备](ten-essentials-trip-plan.md)。

## 第一步：S.T.O.P.

一发现「这条路好像不对」，最重要的就是**马上停下来**。很多人迷路后越走越远，是因为不愿意承认走错了，想着「再往前走走看」。

| 字母 | 意思 | 具体做什么 |
|---|---|---|
| **S** — Stop | 停下 | 原地停住。坐下，喝口水，吃点东西。慌乱时做的决定最差 |
| **T** — Think | 想 | 最后一次确定在正确路上是什么时候、在哪？之后走了多久、往哪个方向？过了哪些岔路、溪沟、标志物？ |
| **O** — Observe | 观察 | 看手机定位；看四周地形：山脊、山谷、远处的城市、电塔、道路；看太阳在哪；看还剩多少水、多少电、离天黑多久 |
| **P** — Plan | 计划 | 根据上面的信息决定：原路退回、打电话求救、还是原地等待。定了再动 |

几条硬规矩：

- **能原路退回就原路退回**，退到最后一个确定的地点。别「抄近路」横切山坡——南加州的灌木丛（chaparral）密得根本穿不过去，很多人就是这样被困在峡谷里的。
- **不要往峡谷下面走**。「顺着水往下走就能出去」在南加州常常是错的：San Gabriel 的峡谷下游经常是瀑布和陡崖，很多搜救就是在峡谷里把人吊上来的。
- **天快黑了，就别再乱走**。在黑暗中走陌生地形，摔伤的风险比迷路大得多。

## 用手机定位：没信号也能用

很多人不知道：**手机的 GPS 定位不需要手机信号。** GPS 是接收卫星信号，跟有没有基站无关。没信号时不能做的是：下载地图、打电话、上网。所以关键是**提前下载离线地图**。

### 没信号时怎么用

- **离线地图 App**（Gaia GPS、AllTrails、CalTopo、onX Backcountry 等）：提前把区域下载好，没信号时打开，蓝点就是你的位置，能看到你离步道有多远。
- **Google 地图离线区域**：免费，能定位，但大部分山间小路没画出来。
- **看自己的坐标**：
  - **iPhone**：自带的「指南针」App 下方会显示经纬度；在地图 App 里点自己的蓝点也能看到。
  - **安卓**：Google 地图里长按你的蓝点附近（或点蓝点），会显示坐标；也可以装一个 GPS 坐标类 App。
- 把坐标**写下来或截图**。之后报警时，一组准确的经纬度比任何描述都有用。

### 省电

迷路后的手机电量，就是你求救的本钱。

- **开飞行模式**，然后单独打开定位（GPS 在飞行模式下仍然工作）。没信号时手机会拼命找基站，最费电。
- 屏幕调暗，关掉所有不需要的东西，只在需要看位置时才打开。
- 隔一段时间关掉飞行模式，**换个高一点、开阔一点的地方**试试有没有信号。山脊和山顶比峡谷容易有信号。

## 卫星求救：哪些手机能用

完全没有手机信号的地方，现在越来越多手机能直接**通过卫星发求救短信**。各家情况不一样，出门前一定要确认自己的手机能不能用、会不会用。

| 手机 | 卫星求救 | 说明 |
|---|---|---|
| **iPhone 14 及之后** | 有，内建 **Emergency SOS via Satellite** | 没信号时打 911 失败后，屏幕会提示改用卫星。需要对着开阔的天空。苹果在设置里提供**演示模式**，可以在家先练一次 |
| **Google Pixel 9 系列及之后的部分机型** | 有，内建 **Satellite SOS** | 由 Garmin Response 处理求救，用法类似 iPhone。具体支持型号以 Google 官方支持页为准 |
| **三星 Galaxy S25 系列（及更新机型）** | 有，但看运营商 | 2025 年初推出时只在 **Verizon** 上可用（Skylo 网络） |
| **三星 Galaxy S23 / S23 Ultra** | **没有手机内建的卫星 SOS 功能**，但可以用 T-Mobile 的卫星服务 | 见下面 |
| 其他较新的安卓手机 | 不一定 | 查手机厂商和运营商的说明 |

**Galaxy S23 怎么办？**

- S23 本身没有像 iPhone 那样的卫星 SOS 功能。
- 但 **T-Mobile 的 T-Satellite（用 Starlink 卫星）**支持 S23、S23+、S23 Ultra、S23 FE（在 2025 年 7 月公布的兼容名单上）。它让普通手机在没有基站的地方通过卫星发短信。
- **2025 年 11 月起，T-Mobile 的「卫星发短信给 911」（Text to 911 via satellite）对所有兼容手机免费开放，包括 AT&T 和 Verizon 用户**，但**需要先在 T-Mobile 网站上登记**，不是自动开通的。登记后，在没有信号的地方像平时一样发短信给 911 即可。完整的 T-Satellite 服务（给普通联系人发短信、少量数据）需要付费或特定套餐。
- 卫星短信可能**延迟、受限或不可用**，需要能看到天空，峡谷底和密林里效果差。
- 政策变动快，**出门前去 T-Mobile 官网核对自己的手机型号和登记状态**。

**专用卫星通讯设备**：经常一个人进山、或者走没信号的长线，可以考虑 **Garmin inReach** 这类设备（双向卫星短信、一键 SOS、可以让家人在网上看你的实时位置），需要按月订阅。它们的天线、电池比手机好，不依赖手机电量。

## 打 911，还是发短信给 911

- **能打电话就打电话**。电话最快，调度员能直接问你问题。
- **有一格信号也试试打**。在美国，911 电话可以通过任何运营商的基站接通，不一定是你自己运营商的。
- **信号很弱、电话打不通时，试试发短信给 911**（Text to 911）。短信需要的信号比通话少，有时能发出去。**LA County 全县（2017 年起）和 San Bernardino County（2015 年起）都支持**短信报警。官方口号是「**Call if you can, text if you can't**」（能打就打，打不了再发短信）。
- 发短信给 911 的注意事项：
  - 收件人只填 **911**，不要群发
  - **英文、简单句子，不用缩写和表情**，不能发照片
  - 第一条就写**位置**（经纬度）和**什么情况**，例如：`Lost hiker. 34.2510, -117.6360. Near Ice House Canyon trail. 1 person, not injured. Phone 30% battery.`
  - 漫游时不能用；如果所在地区不支持，你会收到一条退回短信，请你打电话

### 报警时说什么

1. **位置**：经纬度（最重要）、哪座山哪条步道、最后确认的地点
2. **人数和状况**：有没有人受伤、能不能走
3. **装备**：有没有水、头灯、保暖衣服
4. **手机号和电量**
5. 然后**按调度员的指示做**。通常他们会让你待在原地、保持电话畅通、节约电量。

## 指南针基础

手机坏了、没电了，指南针 + 纸地图是最后的备份。只带不会用没有意义——可以在家附近的公园先练。

### 认识指南针

一个基本的底板式指南针（baseplate compass）有：

- **磁针**：红色一端指向**磁北**
- **转盘**（bezel）：上面刻着 0–360 度
- **行进方向箭头**（direction of travel arrow）：在底板上，指向你要走的方向
- **定向箭头**（orienting arrow）：画在转盘里面的箭头

### 磁偏角

磁针指的是**磁北**，地图上的「上」是**真北**，两者不一样。在 Upland 一带，磁北大约在真北**偏东 11–12°**（磁偏角每年会慢慢变，以 NOAA 的磁偏角计算器为准）。短距离走一两公里影响不大，但走远了会偏得很多。有的指南针可以预设偏角，买的时候可以选这种。

### 最常用的两个操作

**1. 让地图和实地对上（地图定向）**

把指南针放在地图上，转动地图，让地图的北方和磁针（扣除偏角后）指同一个方向。这时地图上的山、山谷就和你眼前看到的方向一致了，很容易认出「那座山是地图上的哪座」。

**2. 走一个方向（取方位角）**

- 把指南针的行进方向箭头指向你想去的地方（或者在地图上从你的位置画向目标）
- 转动转盘，让定向箭头和磁针红端重合（「把红色放进小屋」，red in the shed）
- 读出方位角。之后举着指南针，保持磁针在定向箭头里，朝行进方向箭头走
- 每次选前方一个**参照物**（一棵树、一块石头）走过去，再选下一个

## 不用工具找方向

精度都不高，只能帮你判断大方向（比如「城市在南边，我应该往南」）。

### 太阳

- 太阳**东升西落**（准确说，夏天从东北偏东升起、西北偏西落下，冬天偏东南、西南）。
- 在南加州（北纬约 34°），**中午前后太阳在正南方**，影子指向正北。
- 记住：**Upland 和整个 Inland Empire 城区在 San Gabriel 山的南边。** 在前山迷路时，往南大方向一般是城市，但还是要走步道，不要直线下坡穿灌木。

### 影子棒法

1. 在平地上竖一根直棍，在影子尖端放一块小石头（标记 1）。
2. 等 15–20 分钟，在新的影子尖端放第二块石头（标记 2）。
3. 从标记 1 到标记 2 的连线，大致就是**西 → 东**方向（第一块是西）。
4. 和这条线垂直的方向就是南北。

### 北极星

- 找到**北斗七星**（大熊座的勺子），把勺口最外面两颗星连起来，往勺口开口的方向延长约 **5 倍**的距离，那颗不太亮但孤零零的星就是**北极星**。
- 北极星几乎正对**真北**，高度角大约等于你的纬度（南加州约 34°，大概是从地平线往上三分之一多一点）。
- 秋冬晚上北斗七星位置偏低，可以用另一边的**仙后座**（W 形）辅助。认星座可以参考 [南加州看星星](socal-stargazing.md)。

> 「苔藓长在树的北面」之类的说法很不可靠，别靠它。

## 求救信号

让别人发现你，比你找到别人容易得多。

| 方法 | 怎么做 | 说明 |
|---|---|---|
| **哨子** | **连吹三声**，停一下，再三声 | 国际通用的「三」表示求救。哨声比喊叫传得远得多，还省力气。背包胸带扣上常有哨子 |
| **喊** | 也是三声一组 | 很快就会喊哑，优先用哨子 |
| **手电/头灯** | 夜里**三下闪光**一组，或者 SOS（短短短、长长长、短短短） | 夜间直升机能从很远看到 |
| **信号镜** | 把太阳光反射到飞机、直升机或远处的人身上 | 晴天时几十公里外都能看到闪光。没有信号镜，手机屏幕、刀面、CD 也行，但效果差 |
| **颜色** | 把颜色鲜艳的外套、急救毯（铝箔面）铺在空地上 | 让空中更容易看到 |
| **地对空信号** | 用石头、树枝、衣服在空地上摆出大字，每笔至少**几米长**，和地面颜色反差要大 | 国际通用：**V** = 需要帮助；**X** = 需要医疗援助；**→** = 我往这个方向走了 |
| **烟/火** | 三堆火排成三角形是传统求救信号 | **在南加州干燥的山里极其危险**，可能引发山火，除非是真正的生死关头且周围没有可燃植被，否则不要做 |

听到直升机时：到**开阔处**，挥动颜色鲜艳的衣物，或者用信号镜。**双臂举成 Y 字**表示「是/需要帮助」，一只手举一只手放下（N 字形）表示「不需要」。

## 原地等待，还是自己走出去？

这是最难的判断。默认答案是：**如果有人知道你去了哪，就原地等。**

### 应该原地等的情况

- 你留了**行程计划**，到点会有人报警
- 已经联系上 911 / 卫星求救已发出，调度员让你**待在原地**
- 有人受伤、走不动
- 天黑了，或者天气很差（大雾、暴雨、下雪）
- 完全不知道自己在哪、该往哪走

原地等的时候：

- 待在**步道上或者开阔、容易被看到的地方**，不要躲进灌木或者峡谷底
- 找个避风的地方，坐在背包或垫子上，**别直接坐在冷地上**；穿上所有衣服，用急救毯
- 定时吹哨（比如每隔几分钟吹三声）
- 省水、省电，小口喝水，吃点东西保持体温
- 保持积极：搜救队一般会从你最后已知位置附近和步道沿线开始找

### 可以考虑自己走出去的情况

- **确切知道**回到步道或道路的路线（例如手机地图显示步道就在前面 200 米，中间地形平缓）
- 天还亮、身体状况好、水和电量够
- **没有人**知道你去了哪，等下去没人来

自己走的时候：

- **往「大东西」走**：步道、防火道（fire road）、道路、电力线下的巡线路。这些比漫无目的乱走安全得多
- **往高处、开阔处**看清地形，不要往峡谷底下走
- 沿途做记号（折树枝、摆石头），给可能的搜救留线索
- **每走一段就重新 S.T.O.P.**，发现不对立刻停下

## 给孩子的一句话：抱住一棵树

如果带孩子出门，教他们：**一旦找不到大人，就找一棵树抱住，待在原地，吹哨子。**「Hug-a-Tree」是美国搜救界长期教小孩的方法——孩子越乱跑越难找。给孩子的背包挂一个哨子。

## 一张清单

出门前：

- [ ] 离线地图下载好，路线存在手机里
- [ ] 知道怎么在手机上看自己的经纬度
- [ ] 确认手机的卫星 SOS 能不能用；S23 等没有内建功能的，考虑登记 T-Mobile 卫星 911 短信或带专用设备
- [ ] 带哨子，最好加一个小指南针
- [ ] 留下行程计划

发现迷路时：

- [ ] **停下**，坐下，喝水吃东西
- [ ] 看手机定位，记下坐标
- [ ] 能原路退回就退回；别下峡谷，别穿灌木抄近路
- [ ] 打 911；打不通就**发短信 911**；再不行用卫星
- [ ] 天黑、受伤、不确定 → 原地等，吹哨，保暖
