# 中国近代史（三）：1949 年以后

## 一句话

**前三十年在毛泽东领导下走计划经济和不断的政治运动，代价巨大；后四十多年转向市场经济，创造了人类历史上规模最大的快速增长，但政治体制基本延续。**

## 时间线

| 时期 | 主要事件 |
|---|---|
| 1949–1952 | 建国；**土地改革**，没收地主土地分给农民（过程中大批地主被杀）；**抗美援朝**（1950–1953） |
| 1953–1956 | 第一个五年计划，苏联援助建工业；农业、手工业、工商业**社会主义改造**：土地集体化，私营企业公私合营 |
| 1957 | 「百花齐放」后转为**反右运动**，数十万知识分子被打成右派 |
| 1958–1962 | **大跃进**、人民公社，大炼钢铁，浮夸风；接着是**大饥荒**，非正常死亡人数学界估计从一千五百万到四千五百万不等 |
| 1960 年代 | 中苏交恶；1964 年原子弹试爆成功 |
| 1966–1976 | **文化大革命**：红卫兵、批斗、「破四旧」、上山下乡；大量干部和知识分子受迫害，教育和经济受到严重冲击 |
| 1971–1972 | 中华人民共和国取代中华民国在联合国的席位；尼克松访华 |
| 1976 | 周恩来、毛泽东去世，「四人帮」被捕 |
| 1978 | 十一届三中全会，**改革开放**开始，邓小平成为实际领导人 |
| 1980 年代 | 农村家庭联产承包责任制；深圳等**经济特区**；乡镇企业兴起；1979 年起实行独生子女政策 |
| 1989 | 春夏之交北京等地爆发大规模学生和市民抗议，6 月 4 日军队在北京清场，造成大量平民死亡（具体人数至今无官方完整公布，各方估计从数百到数千） |
| 1992 | 邓小平**南巡**，确立「社会主义市场经济」 |
| 1997–1999 | 香港、澳门回归，实行「一国两制」 |
| 2001 | 加入**世贸组织**，出口爆发式增长 |
| 2008 | 北京奥运会；全球金融危机中推出大规模刺激 |
| 2010 | 经济总量超过日本，成为世界第二 |
| 2012 起 | 习近平任领导人：反腐运动、「一带一路」、强化党的领导；2018 年修宪取消国家主席任期限制；2020 年香港国安法 |
| 2020 年代 | 新冠疫情和「动态清零」（2022 年底结束）；房地产调整、人口开始下降（2022 年起）；中美在科技、贸易上的竞争加剧 |

## 改革开放为什么能成功

经济学家常提到的因素：

- **起点低、追赶空间大**，有大量从农村转移出来的劳动力（「人口红利」）。
- **渐进式改革**：「摸着石头过河」，价格双轨制、特区试点，先试再推广，避免了苏联式的剧烈震荡。
- **地方政府竞争**：地方官员的考核和经济增长挂钩，招商引资积极。
- **对外开放**：外资、技术和全球市场，加入世贸后成为「世界工厂」。
- **高储蓄、高投资、大规模基础设施建设**。
- **海外华人资本**：港台企业是早期外资主力。

代价和问题：环境污染、贫富差距和城乡差距扩大、户籍制度下农民工的权益、地方债务、房地产依赖、人口老龄化。

## 政治体制简述

- **中国共产党**领导一切，党的总书记是最高领导人，通常兼任国家主席和中央军委主席。
- 全国人民代表大会是名义上的最高权力机关；还有八个民主党派参加政治协商。
- 决策核心是中央政治局常委会。
- 支持者认为这种体制决策效率高、能长期规划、带来了稳定和发展；批评者认为它缺乏权力制衡、言论受限、少数民族和宗教政策（如新疆、西藏）引起严重的人权关切。不同立场的观察者对同样的事实评价差别很大。

## 台湾问题

- 1949 年国民政府迁台后，两岸分治。台湾 1987 年解除戒严，1990 年代民主化，1996 年起总统直选。
- 北京认为台湾是中国领土不可分割的一部分，主张和平统一但不放弃使用武力；台湾内部对统独、维持现状有不同看法，民调中「维持现状」长期是多数。
- 美国奉行「一个中国政策」（承认北京政府、认知北京的立场），同时依据《台湾关系法》向台湾出售防御性武器，保持「战略模糊」。
- 这是当今世界最可能引发大国冲突的热点之一。

## 不同的解释

- **中国官方的历史决议**（1981 年、2021 年）：肯定毛泽东的历史地位，承认大跃进和文化大革命是严重错误；改革开放是伟大转折。
- **西方和海外学者**：更多聚焦政治运动造成的人道灾难、改革中的社会代价和政治不自由；关于经济成功的原因有「市场化解释」和「国家主导解释」两派。
- **关于未来**：「中国崩溃论」和「中国必然超越美国论」过去都多次被证明过于简单；人口、债务、技术、外部环境是讨论的焦点。

## 常见误解

- **「改革开放前什么都没有」**：前三十年建立了工业基础、提高了识字率和人均寿命，但也有巨大的人为灾难。
- **「中国经济增长全靠廉价劳动力」**：劳动力只是一部分，基础设施、供应链集群、工程师、规模经济都很重要。
- **「中国人对政治的看法是一样的」**：不同年龄、地区、阶层的人看法差别很大。
