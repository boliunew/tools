# 天文入门：光年、星等，和怎么在天上找东西

看天文新闻、用观星 App，反复出现的就那么几个概念。这篇把它们一次讲清楚。

## 距离：光年和光速

**光年是距离，不是时间**：光走一年的距离，大约 9.46 万亿公里。光速约每秒 30 万公里，换成「光走多久」最好记：

| 从哪到哪 | 光要走 |
|---|---|
| 月亮 → 地球 | 约 1.3 秒 |
| 太阳 → 地球 | 约 8 分 20 秒 |
| 太阳 → 海王星 | 约 4 小时 |
| 离太阳最近的恒星（比邻星） | 约 4.2 年 |
| 银河系中心 | 约 2.6 万年 |
| 仙女座星系 | 约 250 万年 |

所以抬头看到的都是「过去」：今晚看到的太阳是 8 分钟前的太阳，仙女座星系的光出发时，地球上还没有现代人类。仙女座星系也是在暗处肉眼能看到的最远的东西，看起来是一小团模糊的光斑。

太阳系内部常用**天文单位**（AU）：1 AU 就是地日平均距离，约 1.5 亿公里。

## 亮度：星等

天文里的亮度叫**星等**（magnitude），规则有点反直觉：

- **数字越小越亮**，还能是负数。
- 每差 1 等，亮度差约 2.5 倍；差 5 等，正好差 100 倍。

| 天体 | 星等（约） |
|---|---|
| 太阳 | −26.7 |
| 满月 | −12.7 |
| 金星（最亮时） | −4.6 |
| 木星 | −2 到 −2.9 |
| 天狼星（夜空最亮的恒星） | −1.5 |
| 北极星 | +2.0 |
| 城市里肉眼能看到的极限 | 约 +3 |
| 很暗的野外肉眼极限 | 约 +6 |

在 Upland 这种城市里，肉眼只能看到 +3 等以内的星，一晚上也就几十颗。到了沙漠，能看到 +6 等，星星多出上百倍。这就是为什么要开车去暗的地方。

## 方向和高度：伸手就能量角度

天上的位置用两个数描述：

- **方位角**：从正北开始顺时针转，北 0°、东 90°、南 180°、西 270°。
- **高度角**：地平线是 0°，头顶正上方是 90°。

观星 App 说「木星在东南方、高 30°」，就是这个意思。

**手臂伸直，用手量角度**，对谁都差不多准：

| 手势（手臂伸直） | 大约多少度 |
|---|---|
| 小指的宽度 | 1°（正好能挡住月亮，月亮只有 0.5°） |
| 三根手指并拢 | 5° |
| 握拳 | 10° |
| 张开手掌（拇指尖到小指尖） | 20°–25° |

从地平线开始一拳一拳往上数，3 拳就是 30°。

## 找北极星

1. 先找**北斗七星**：在北边天空，像一把勺子。中国叫北斗，西方叫「大勺子」（Big Dipper），是大熊座的一部分。
2. 勺口最外侧的两颗星叫「指极星」。从勺底往勺口的方向连一条线，延长大约 **5 倍**两星的距离。
3. 那里一颗不算很亮、周围也没有更亮的星，就是**北极星**。

北极星有两个常见误解：

- **它不是最亮的星**，只有 2 等，排在五十名左右。它的特别之处是几乎正对着地轴，所以整晚都在原地不动，其他星星都绕着它转。
- **它的高度角等于你所在的纬度。** Upland 在北纬 34° 左右，北极星就在北方地平线上大约 34°，三拳半高。

秋冬季北斗七星傍晚贴着北方地平线，容易被房子和山挡住。这时可以用对面的**仙后座**（像一个 W）来找：北极星大约在北斗和仙后座的正中间。

## 为什么星星会闪，行星不闪

恒星离得太远，在天上只是一个点。点光源的光穿过晃动的大气，一会儿偏这边一会儿偏那边，看起来就在闪烁。行星离得近，在天上是一个很小的圆盘，各处的闪动互相抵消，所以光很稳。

**判断一个很亮的「星」是不是行星**：

- 光稳不怎么闪；
- 在黄道附近，也就是太阳和月亮走的那条线上；
- 比周围的星都亮，而且星图上「没有它」。

## 星星的颜色就是温度

仔细看，星星是有颜色的：

- 偏红的星表面温度只有三千多度，比如猎户座的**参宿四**；
- 黄白色的和太阳差不多，大约 5800 度；
- 蓝白色的能到一万度以上，比如猎户座的**参宿七**。

这和炉子烧红、烧白是一个道理。

## 每天提前 4 分钟

地球绕太阳转，所以同一颗星每晚升起的时间都比前一晚早大约 4 分钟，一个月就早 2 小时。这就是为什么季节不同，晚上看到的星座也不同：

- 冬天傍晚是猎户座；
- 夏天是天蝎座和银河中心。

全天一共划分了 88 个星座，是国际天文学联合会定的。中国古代有自己的一套星官，比如三垣二十八宿，有些名字现在还常用：牛郎星（河鼓二）、织女星（织女一）、天狼星、参宿、昴宿（昴星团）。
