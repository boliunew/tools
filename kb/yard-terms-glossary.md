# 码头与堆场术语中英对照

刚进场子最头疼的不是活儿，是听不懂：调度一句 "Pre-pull that MSCU, LFD's tomorrow, drop it on a pool chassis" 里面就藏了四个术语。这篇把常听到的词按主题列出来，每个配一句**现场真会这么说**的例句。

- 柜子本身、进口柜从码头到仓库的整个流程，见 [集装箱物流入门](container-logistics-101.md)。
- 各种车头、拖车、底盘长什么样，见 [卡车、拖车和底盘](truck-trailer-types.md)。
- 柜门上的 22G1、45R1 这些代码，见 [柜型代码怎么读](container-type-codes.md)。
- 码头本身（有哪些码头、预约、铁路），见 [洛杉矶 / 长滩港实用指南](la-lb-ports-guide.md)。

> 同一个词，不同公司叫法可能不一样，比如有的地方把 detention 和 per diem 混着用。听不准的时候直接问一句 "You mean per diem or demurrage?"，比猜强。

## 箱子与设备

| 英文 | 中文 | 一句话解释 | 现场例句 |
|---|---|---|---|
| Container / Box / Can | 集装箱、柜子 | 现场常简称 box 或 can | "That box goes back to the pier today." |
| 20 / 40 / 40 high cube / 45 | 20 尺 / 40 尺 / 40 尺高柜 / 45 尺 | 说尺寸就代指柜型 | "It's a forty high cube, not a standard." |
| Dry van | 干货拖车 | 53 尺封闭拖车，不是集装箱 | "Grab a dry van from row C." |
| Reefer | 冷柜、冷藏车 | 带制冷机的柜子或拖车 | "Reefer's set at minus ten, check the display." |
| Genset | 发电机组 | 挂在冷柜或底盘上的柴油发电机 | "Genset's out of fuel, plug that reefer in." |
| Chassis | 底盘、架子 | 放柜子的带轮钢架 | "No chassis at the pier, we got to bring our own." |
| Pool chassis | 公用池底盘 | 从底盘公司按天租的底盘 | "Put it on a DCLI pool chassis." |
| Tri-axle | 三轴底盘 | 多一根轴，拉重的 20 尺柜 | "That twenty is heavy, needs a tri-axle." |
| Flat rack | 框架柜 | 只有底板和两头端墙 | "Flat rack with a machine on it, use straps." |
| Open top | 开顶柜 | 顶上是篷布 | "Open top's tarp is ripped, take a picture." |
| Seal | 铅封 | 锁在柜门上的一次性封条，有编号 | "Seal number doesn't match the paperwork." |
| Twist lock | 扭锁 | 底盘四角卡住柜子的锁 | "Make sure all four twist locks are locked." |
| Landing gear | 支腿 | 拖车、底盘前面摇下来的两条腿 | "Crank the landing gear down before you pull out." |
| Fifth wheel | 第五轮、鞍座 | 车头后面挂拖车的圆盘 | "Check the fifth wheel's locked, tug test." |
| Yard dog / Hostler | 场内调车头 | 只在场子里挪车的小车头 | "Get the yard dog, move 4512 to door 12." |

## 进出闸与单据

| 英文 | 中文 | 一句话解释 | 现场例句 |
|---|---|---|---|
| In-gate / Out-gate | 进闸 / 出闸 | 进出码头或堆场大门的登记 | "He's at the out-gate now." |
| Gate check | 闸口检查 | 进出时看号、看封、看损 | "Do a gate check before you let him in." |
| Interchange | 交接 | 设备从一方交到另一方 | "Damage was noted at interchange." |
| EIR | 设备交接单 | 码头出闸、进闸时打的单子，记柜子和底盘状况 | "Send me the EIR, I need the time stamp." |
| TIR | 拖车交接单 | 和 EIR 差不多，多用在铁路场和拖车 | "The rail ramp gave him a TIR." |
| BOL / B/L | 提单 | 货的「身份证」：谁发、谁收、什么货 | "Driver needs a signed BOL before he leaves." |
| MBL / HBL | 船东提单 / 货代提单 | 船公司出的叫 master，货代出的叫 house | "Customs is holding it under the master." |
| POD | 签收单 | 收货方签字的提单或送货单，证明送到了 | "Upload the POD so we can bill." |
| PRO number | 运单号 | 卡车公司（尤其零担）给每票货的追踪号 | "Give me the PRO number, I'll track it." |
| Booking number | 订舱号 | 出口时船公司给的号，提空柜要用 | "Pick up an empty under booking 12345678." |
| Delivery order (DO) | 提货单、派车单 | 告诉拖车公司去哪儿提哪个柜、送到哪儿 | "We got the DO, container's not released yet." |
| Release | 放行 | 海关、船公司、码头都没问题了 | "It's released, go get it." |
| Hold | 扣留 | 海关、船公司或码头卡住不放 | "There's a customs hold on it." |
| Available | 可提 | 柜子已卸船、已放行、可以约 | "Box shows available on the terminal site." |
| Appointment / Appt | 预约 | 进码头提柜还柜要提前约时段 | "No appointment, no entry." |
| TWIC | 码头通行卡 | 联邦发的交通工人身份卡，进码头必须有 | "New driver doesn't have a TWIC yet." |
| Trouble ticket / Trouble window | 问题单 / 问题窗口 | 闸口出问题，司机被叫去窗口处理 | "He got sent to the trouble window." |
| Yard check | 盘场 | 把场子里的柜、车、底盘挨个对一遍 | "Yard check at 6, write down every unit." |

## 费用

费用的详细区别和 Pre-pull、Street turn 这类省钱做法，[集装箱物流入门](container-logistics-101.md) 里有一张表，这里只列词。

| 英文 | 中文 | 一句话解释 | 现场例句 |
|---|---|---|---|
| LFD (Last Free Day) | 最后免费日 | 码头免费存放的最后一天 | "LFD is Friday, pull it Thursday." |
| Free time | 免费期 | 不收钱的天数 | "We only get four days free time." |
| Demurrage | 码头滞期费 | 柜子过了 LFD 还在码头 | "We're paying demurrage on six boxes." |
| Per diem | 滞箱费（按天） | 柜子提出来以后超时没还 | "Per diem starts tomorrow, return that empty." |
| Detention | 滞箱费 / 压车费 | 两种意思：一是同 per diem；二是司机在仓库等太久的压车费 | "Driver waited three hours, bill detention." |
| Storage | 堆存费 | 柜子放在拖车公司场子里的费用 | "It's sitting in our yard, storage is adding up." |
| Chassis split | 底盘分离费 | 柜子和底盘不在一处，多跑一趟去拿底盘 | "That's a chassis split, add it to the invoice." |
| Chassis rental | 底盘租金 | 底盘按天收的钱 | "Chassis rental is on us after day five." |
| Dry run | 空跑费 | 去了却没提到或没送成 | "Terminal closed, that's a dry run." |
| Accessorial | 附加费 | 运费以外的各种杂费总称 | "Put all the accessorials on one line." |
| Fuel surcharge (FSC) | 燃油附加费 | 跟油价浮动的附加费 | "FSC went up this week." |
| Overweight fee | 超重费 | 重柜要特殊底盘或许可 | "Box is 44,000 pounds, overweight fee applies." |
| Lumper fee | 卸货工费 | 仓库雇外包工人卸货收的钱 | "Get a receipt for the lumper fee." |
| TMF / PierPass | 码头交通缓解费 | 洛杉矶 / 长滩码头按重柜收的费 | "TMF has to be paid before the box can go." |

## 运输与调度

| 英文 | 中文 | 一句话解释 | 现场例句 |
|---|---|---|---|
| Drayage / Dray | 港口短驳、拖柜 | 码头、铁路场和附近仓库之间的短途拖柜 | "We're a dray company, mostly port runs." |
| Bobtail | 单车头空跑 | 车头后面什么都不挂 | "He's coming back bobtail." |
| Deadhead | 空驶 | 不带货的里程，挂着空拖车也算 | "That's 60 miles deadhead, not worth it." |
| Live load | 现场装货 | 司机在旁边等着装完 | "It's a live load, two hours max." |
| Live unload | 现场卸货 | 司机等着卸完 | "Live unload at door 5." |
| Drop and hook | 甩挂 | 放下一个、挂上另一个就走 | "Drop and hook, the empty's in row D." |
| Drop / Drop-off | 甩柜 | 连柜带底盘放下，司机先走 | "Drop it and go, they'll unload tomorrow." |
| Pre-pull | 提前提柜 | 赶在 LFD 前先拉回自己场子 | "Pre-pull everything with LFD this week." |
| Empty return | 还空柜 | 卸空后还到指定码头或空柜场 | "Empty return to Pier 400, not TTI." |
| Dual transaction / Double move | 双向作业 | 一趟进码头既还柜又提柜 | "Book a dual, drop the empty, pick up the load." |
| Street turn | 空柜直转 | 进口空柜不还码头，直接给出口用 | "Line approved the street turn." |

| Cutoff / ERD | 截柜时间 / 最早进港日 | 出口重柜最晚、最早能进码头的时间 | "Cutoff is Wednesday noon, ERD Monday." |

| Overweight / OW | 超重 | 超过公路允许重量 | "It's OW, needs a permit." |

## 读音和容易听错的

| 写法 | 一般读成 | 注意 |
|---|---|---|
| Chassis | "CHA-see"（s 不发音） | 单复数写法一样 |
| Per diem | "per DEE-um" | 拉丁语，意思是「每天」 |
| Demurrage | "dee-MUR-ij" | 和 detention 常被说混 |
| Reefer | "REE-fer" | 不是 refer |
| TWIC | "twick" | 一个词读，不是逐个字母 |
| EIR | "E-I-R" | 逐个字母 |
| Hazmat | "HAZ-mat" | |
| LFD | "L-F-D" | 也有人直接说 "last free day" |

> 柜号在对讲机里报的时候，字母常用北约字母表：A = Alpha、B = Bravo、C = Charlie、D = Delta、E = Echo、M = Mike、S = Sierra、U = Uniform、Z = Zulu……比如 MSCU 读作 "Mike Sierra Charlie Uniform"。听到后报的数字，记得用 [校验位](iso-6346-check-digit.md) 核一下。
