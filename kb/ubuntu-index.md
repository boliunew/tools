# Ubuntu 系列总览

Ubuntu 是目前新手最友好的 Linux 发行版：装好就能用，软件多、教程多，出了问题基本都能搜到答案。这个系列是给刚搭好一台 Ubuntu 电脑的新手写的，目标不是把 Linux 讲全，而是让你**第一天就能顺手用起来，第一周敢自己装软件、连手机，一个月后能把这台电脑当成家里的小服务器**。

全系列以 **Ubuntu 24.04 LTS** 为准。LTS 是长期支持版，标准支持到 2029 年 4 月，装一次能安心用好几年；24.04 和上一个 LTS（22.04）有差别的地方，文章里会单独注明。

## 推荐的一条学习线

**第一天：先能用。**照着《装好之后先做的事》把更新、输入法、常用软件装好，再读《终端入门》把最常用的十几个命令过一遍。不用背，会查就行。

**第一周：开始折腾。**用《装软件的五种办法》装几个自己需要的软件，用《每天用得到的技巧》把快捷键和别名配上。每天用终端做一两件小事，手指记忆就是这样来的。

**第二周以后：连起来用。**《远程连接与局域网共享》让 Windows 笔记本和手机都能连上这台电脑传文件；《把 Ubuntu 当家里的小服务器》把它变成 24 小时开机的本地网站和文件服务。

**出问题时：**直接查《出问题了怎么办》，按症状找对应的排查步骤，不用从头读。

> 新手最容易踩的两个坑：一是跟着网上教程乱复制命令——每条命令先看懂是干什么的再执行，尤其是带 `sudo rm` 和 `curl | bash` 的；二是出了问题同时改好几个地方，改好了也不知道是哪一步起的作用。一次只改一个地方，改之前先备份原文件。

## 开始之前：需要准备什么

| 准备 | 说明 |
|---|---|
| 一台装好 Ubuntu 24.04 的电脑 | 桌面版就行，虚拟机也可以跟着练 |
| 能上网 | 装软件、更新系统都要联网 |
| 会打开终端 | 按 `Ctrl+Alt+T`，终端的具体用法见第二篇 |
| 记住自己的登录密码 | 带 `sudo` 的命令会要求输入 |

## 这个系列的写法约定

- **每个代码块就是一条命令**，点代码块右上角的复制按钮，粘贴到终端回车就能执行；少数几个块是一组必须连着执行的命令（比如写一个服务文件），也会放在一个块里。
- 命令里的 `用户名`、`192.168.1.100` 这类字样是占位符，执行前换成你自己的；`$USER` 会自动换成当前用户名，不用手动改。
- 命令前的 `sudo` 表示用管理员身份执行，第一次用会要求输登录密码，输入时屏幕上不显示任何字符，输完直接回车。
- 每篇末尾的「相关阅读」都链到系列里的其他篇和知识库已有的相关文章，读到不懂的概念可以顺着链过去。

## 几个先说清楚的概念

| 词 | 一句话 |
|---|---|
| 发行版 | Linux 内核 + 桌面 + 软件仓库打包成的完整系统，Ubuntu 是其中最流行的一个 |
| LTS | 长期支持版，5 年安全更新，适合不想频繁重装的人 |
| 桌面环境 | 你看到的窗口、菜单、任务栏，Ubuntu 默认是 GNOME |
| 终端 | 用文字命令操作电脑的窗口，是 Linux 的核心工作方式 |
| 软件包 | Ubuntu 里软件的安装单位，apt 就是管理软件包的工具 |
| root / sudo | root 是最高权限账号；sudo 是"用管理员身份执行这一条命令"，平时不要一直用 root |

## 学到什么程度算入门

| 会做的事 | 说明你已经 |
|---|---|
| 不看教程装软件、更新系统 | 会用 apt 和软件中心 |
| 用终端新建、移动、查找文件 | 掌握了基本命令 |
| 从 Windows 或手机连上这台电脑传文件 | 会用 SSH / Samba |
| 写一个开机自启服务并看懂它的日志 | 会用 systemd 和 journalctl |
| 磁盘满了、软件装不上能自己定位原因 | 有了排查思路 |

这个系列不讲 Linux 内核、不讲服务器运维的深水区，也不讲 Shell 脚本编程——那些是另一个层次的东西。入门之后想继续，顺着相关阅读里的[编程入门](programming-basics.md)往下走就行。
