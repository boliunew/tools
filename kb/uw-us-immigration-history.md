# 美国移民（一）：一个移民国家的历史

## 一句话

**美国几乎每一代人都在争论「移民是带来活力还是带来威胁」；被排斥的群体在下一代往往变成「美国人」，然后同样的争论又落到新来的人身上。**

## 时间线

| 时期 | 谁来了 | 发生了什么 |
|---|---|---|
| 1600–1800 | 英国、荷兰、德国等欧洲殖民者；约四十万非洲人被强迫贩运到北美（跨大西洋奴隶贸易总共约 1250 万人） | 美洲原住民被大规模驱逐、死于战争和疾病 |
| 1790 | | 第一部《归化法》：只有「自由白人」可以入籍 |
| 1840–1860 | **爱尔兰人**（马铃薯大饥荒）、**德国人** | 反天主教、反移民的「一无所知党」兴起 |
| 1848–1870 年代 | **华人**来加州淘金、修建**中央太平洋铁路**（铁路西段劳工大部分是华人） | 遭受歧视和暴力，如 1871 年洛杉矶唐人街屠杀 |
| 1868 | | 第 14 修正案：在美国出生的人是美国公民（**出生公民权**） |
| 1882 | | **《排华法案》**：第一部针对特定民族的移民禁令，1943 年才废除 |
| 1880–1920 | 约 2000 万人，主要是**意大利、波兰、俄罗斯犹太人、东欧人** | **埃利斯岛**（纽约，1892–1954）是主要入境口；西海岸有**天使岛**（旧金山湾，1910–1940），很多华人在这里被长期关押审问 |
| 1898 | | **黄金德案**（Wong Kim Ark）：最高法院裁定在美国出生的华人后代是美国公民 |
| 1924 | | **《移民法》（约翰逊—里德法）**：按 1890 年人口普查中各国籍比例分配配额，大幅限制南欧东欧移民，几乎完全禁止亚洲移民 |
| 1942–1945 | | 约 12 万**日裔美国人**被关进拘留营，其中三分之二是美国公民；1988 年美国政府正式道歉赔偿 |
| 1942–1964 | 墨西哥劳工 | **布拉塞罗计划**：数百万墨西哥人以季节性农工身份来美 |
| 1965 | | **《移民和国籍法》（哈特—塞勒法）**：取消国籍配额，改以**家庭团聚**和**职业技能**为主；之后来自亚洲、拉美的移民大量增加 |
| 1980 | | 《难民法》建立现代难民制度；越战后大量东南亚难民来美 |
| 1986 | | **《移民改革和控制法》**：约 300 万无证移民获得合法身份（「大赦」），同时规定雇用无证移民违法 |
| 1990 | | 设立 H-1B 等技术移民签证和**绿卡抽签**（多元化签证） |
| 2001 以后 | | 「9·11」后成立**国土安全部**，移民执法大大加强 |
| 2012 | | **DACA**：童年被带入境的无证移民（「追梦人」）可以暂缓遣返、获得工卡 |
| 2017 以后 | | 移民政策成为最激烈的政治议题之一：边境墙、旅行禁令、家庭分离、庇护规则、难民上限、大规模遣返等，政策随政府更替大幅摇摆 |
| 2026 | | 最高法院在 **Trump v. Barbara** 案中裁定，在美国出生的孩子即使父母无合法身份或只是暂时居留，也是美国公民，否定了限制出生公民权的行政命令 |

## 今天的移民人口

- 美国约有 **4500 万到 5000 万外国出生的居民**，约占人口的 14% 左右，接近 1890–1910 年代的历史高峰比例。
- 主要来源国：墨西哥、印度、中国、菲律宾、萨尔瓦多、越南、古巴、多米尼加等。
- **加州**是移民比例最高的州之一，约四分之一的居民在外国出生。
- 无证移民估计在一千万到一千四百万之间（不同机构估计差异较大）。

## 关键概念

| 概念 | 意思 |
|---|---|
| **大熔炉** | 移民融合成同一种「美国人」 |
| **沙拉碗 / 马赛克** | 各群体保留自己的文化，共同组成美国 |
| **本土主义（nativism）** | 优先保护「本地人」利益、敌视移民的思潮，美国历史上周期性出现 |
| **模范少数族裔** | 形容亚裔「成功」的刻板印象，常被批评掩盖了亚裔内部的差异和困难 |

## 不同的解释

- **移民对经济的影响**：多数经济学研究认为整体上移民促进增长、创新（大量美国科技公司的创始人是移民或移民二代），对本地工人工资的平均影响很小；但对低技能本地工人可能有一定冲击（博尔哈斯和卡德两位经济学家在这点上争论多年）。
- **移民和财政**：第一代移民可能花费更多公共服务（尤其是教育），第二代通常是净贡献者。
- **文化和认同**：一方担心大规模移民削弱共同的国家认同和法治；另一方认为每一代移民都曾被这样怀疑，最终都成了美国的一部分。
- **历史的评价**：《排华法案》、1924 年配额、日裔拘留营今天被普遍认为是不公正的；但如何从这些历史得出今天的政策结论，各方看法不同。

## 常见误解

- **「我的祖先是合法来的」**：1875 年以前联邦几乎没有移民限制，「合法」「非法」的概念很多是后来才有的。
- **「移民犯罪率更高」**：多数研究发现移民（包括无证移民）的犯罪率不高于、甚至低于本土出生的美国人；这一点在政治上仍有争议。
- **「移民都是穷人」**：美国的移民两极分化：既有大量低技能劳工，也有大量博士、工程师和医生。
