# 通货膨胀和利率：为什么东西越来越贵，美联储加息影响什么

## 一句话

**通货膨胀是「钱变得不值钱」；利率是「借钱的价格」。央行通过调利率来让经济不要太热（通胀）也不要太冷（失业）。**

## 通货膨胀

### 怎么量

- **CPI（消费者物价指数）**：一篮子日常消费品（食品、房租、汽油、医疗、交通等）的价格变化，美国劳工统计局每月公布。
- **核心 CPI / 核心 PCE**：去掉波动大的食品和能源，看底层趋势。美联储更常看 PCE。
- 通胀 3% 意味着：去年 100 美元买的东西，今年要 103 美元。

### 为什么会通胀

| 类型 | 原因 | 例子 |
|---|---|---|
| **需求拉动** | 大家想买的东西比能生产的多 | 疫情后刺激支票加上报复性消费 |
| **成本推动** | 生产成本上升，转嫁到价格上 | 1970 年代石油危机；2022 年能源价格飙升 |
| **货币过多** | 货币增长远快于经济增长 | 弗里德曼名言：「通货膨胀在任何时间任何地点都是一种货币现象」 |
| **预期自我实现** | 大家预期涨价，就提前要涨工资、提价 | 1970 年代美国的「工资—物价螺旋」 |

### 多少通胀算正常

- 大多数发达国家央行把目标定在 **2% 左右**。
- 为什么不是 0？轻微通胀给降息留空间，也让工资和价格调整更容易；**通货紧缩**（物价普遍下跌）更可怕：大家推迟消费、债务实际负担加重，日本 1990 年代后长期经历过。
- **恶性通胀**（每月涨 50% 以上）：魏玛德国 1923 年、津巴布韦 2008 年、委内瑞拉 2010 年代，通常和政府大量印钱弥补赤字有关。

### 谁吃亏、谁占便宜

- 吃亏：存现金的人、固定收入的人、工资涨得慢的人。
- 占便宜：欠固定利率债的人（比如 30 年固定房贷，通胀让实际还款负担变轻）、拥有房产和股票等资产的人（不一定，看情况）。

## 利率

### 央行怎么调

美联储设定**联邦基金利率**（银行之间隔夜借钱的利率）的目标范围，由**联邦公开市场委员会（FOMC）** 一年开 8 次会决定。这个利率会传导到：

```
联邦基金利率 ↑
  → 银行借钱成本 ↑
  → 房贷、车贷、信用卡利率 ↑，企业贷款更贵
  → 买房买车、投资、消费减少
  → 需求降温 → 通胀下降（但失业可能上升）
```

降息则反过来，用来刺激疲弱的经济。

### 其他工具

- **量化宽松（QE）**：央行买大量国债和其他债券，压低长期利率，2008 年金融危机和 2020 年疫情时大规模使用。
- **量化紧缩（QT）**：反过来，缩减持有的债券。
- **前瞻指引**：央行公开说未来打算怎么做，影响市场预期。

### 利率影响你生活的地方

| 利率上升时 | 利率下降时 |
|---|---|
| 新房贷、车贷月供更高 | 借钱便宜，可以考虑再融资 |
| 存款、货币基金、国债收益更高 | 存款利息变少 |
| 股市、尤其成长股常承压 | 股市常受提振 |
| 美元往往走强（外国资金流入） | 美元往往走弱 |
| 借美元的发展中国家压力大 | 新兴市场压力减轻 |

## 几个历史时刻

- **1970 年代美国「滞胀」**：高通胀加高失业，传统理论认为两者不会同时出现。
- **1979–1987 年沃尔克**：美联储主席沃尔克把利率提到近 20%，引发衰退和高失业，但打掉了通胀，此后几十年通胀温和。
- **2008 年金融危机后**：利率接近零多年，加上 QE。
- **2021–2023 年**：疫情后通胀一度超过 9%（1981 年以来最高），美联储快速加息到 5% 以上。

## 不同的解释

- **货币主义**（弗里德曼）：通胀主要由货币供应决定，央行应该稳住货币增长。
- **凯恩斯主义**：需求不足时政府和央行要积极刺激；通胀和失业之间短期存在取舍（**菲利普斯曲线**），但这条曲线是否稳定一直有争论。
- **关于 2021–2022 年通胀**：有人认为主要是供应链和能源冲击（「暂时性」），有人认为财政刺激太大、美联储反应太慢。后来的研究认为两方面都有作用，比例仍在争论。
- **央行该不该独立？** 主流观点认为央行独立于政客能防止为选举而滥发货币；也有人认为这让一群未经选举的人掌握太大权力。

## 常见误解

- **「通胀下降就是东西变便宜了」**：通胀下降只是涨得慢了，价格水平一般不会回到以前。
- **「美联储直接定房贷利率」**：它定的是短期利率；30 年房贷利率更多跟着 10 年期国债走，受市场预期影响。
- **「加息能马上压住物价」**：效果一般要滞后一年左右才明显。
