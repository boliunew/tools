# 中国近代史（二）：民国时代（1912–1949）

## 一句话

**帝制倒了，但新的共和国没能建立有效的中央政府；三十多年里，军阀、国民党、共产党、日本侵略者交织在一起，最终以内战决出胜负。**

## 时间线

| 年份 | 事件 |
|---|---|
| 1912 | 中华民国成立；孙中山让位，**袁世凯**任大总统 |
| 1915–1916 | 袁世凯接受日本「二十一条」大部分要求，又称帝 83 天，在反对声中取消，不久病死 |
| 1916–1928 | **北洋军阀时期**：直系、皖系、奉系等军阀争夺北京政府，南方另有政权，全国四分五裂 |
| 1915 起 | **新文化运动**：陈独秀《新青年》、胡适提倡白话文，口号「民主与科学」 |
| 1919 | **五四运动**：巴黎和会把德国在山东的权益交给日本，北京学生上街，运动扩大到全国 |
| 1921 | 中国共产党在上海成立 |
| 1924 | **第一次国共合作**，在苏联帮助下建黄埔军校 |
| 1926–1928 | **北伐**：国民革命军打败北洋军阀；1927 年蒋介石在上海「清党」，国共分裂；1928 年东北易帜，国民政府名义上统一全国，定都南京 |
| 1927–1937 | **南京十年**：国民政府推动关税自主、币制改革、修铁路公路；同时和共产党、地方军阀作战。共产党在江西等地建立根据地 |
| 1931 | **九一八事变**，日本占领东北，次年建伪「满洲国」 |
| 1934–1936 | 红军**长征**，到达陕北延安；毛泽东在党内地位上升 |
| 1936 | **西安事变**：张学良、杨虎城扣押蒋介石，促成第二次国共合作抗日 |
| 1937–1945 | **全面抗战**：七七事变、淞沪会战、南京大屠杀、武汉会战；国民政府迁都重庆；1941 年太平洋战争爆发后中国与美英结盟；1945 年日本投降 |
| 1945–1949 | **国共内战**：辽沈、淮海、平津三大战役；1949 年 10 月 1 日中华人民共和国成立；国民政府迁往台湾 |

## 关键概念

| 概念 | 意思 |
|---|---|
| **三民主义** | 孙中山的纲领：民族、民权、民生 |
| **军阀** | 拥有私人军队、割据一方的军事首领 |
| **训政** | 国民党主张的「军政—训政—宪政」三阶段，训政期由国民党一党执政 |
| **统一战线** | 共产党联合其他阶级和力量的策略 |
| **土地革命** | 共产党在根据地没收地主土地分给农民，是它赢得农民支持的关键 |

## 抗日战争的分量

- 从 1931 年算起 14 年，从 1937 年算起 8 年。中国军民伤亡数千万（各方估计差异很大，常见说法是死亡一千万到两千万以上，中国官方说法为军民伤亡 3500 万）。
- 抗战拖住了大量日军（中国战场长期有日本陆军的很大部分），是二战亚洲战场的重要部分，西方过去对此重视不够。
- **正面战场和敌后战场**：国民党军队承担了绝大多数大型会战，共产党在华北敌后发展游击战和根据地。两岸对各自作用的叙述长期不同，近年研究趋于承认两者都有贡献。

## 共产党为什么赢了内战

学者们给出的原因通常是几个因素的组合：

- **国民政府的问题**：抗战消耗巨大；战后恶性通货膨胀（法币、金圆券崩溃）让城市中产失去信心；腐败、派系斗争；接收沦陷区时的混乱。
- **共产党的优势**：土地改革赢得农民支持；组织纪律严密；抗战期间力量大增（党员从几万发展到百万以上）；战略灵活。
- **外部因素**：苏联在东北移交日军武器和地盘；美国调停失败后减少了对国民政府的援助。
- **军事**：东北和华北战场的关键决战，以及大量国民党部队的起义或投降。

## 不同的解释

- **大陆主流叙述**：近代以来中国人民在共产党领导下反帝反封建，取得新民主主义革命胜利，是历史的选择。
- **台湾和部分西方学者**：强调国民政府的现代化建设（「黄金十年」）和抗战主力作用，认为日本侵略打断了国家建设，给了共产党发展的机会。
- **近年不少历史学者**（如方德万、拉纳·米特）：更多关注战争对国家和社会的整体冲击，减少用胜负倒推「必然性」。
- **五四运动的评价**：有人认为它带来了思想解放和现代化；也有人批评它「全盘反传统」走得太远，或认为它为激进革命铺了路。

## 常见误解

- **「民国就是一个统一的国家」**：大部分时间里中央政府控制力有限，地方军阀、日本占领区、共产党根据地并存。
- **「民国是文化上的黄金时代」**：民国时期确实名家辈出（鲁迅、胡适、陈寅恪、梁思成……），但多数普通人生活在战乱和贫困中。两面都是真实的。
- **「蒋介石不抗日」**：国民政府主力部队打了大部分正面会战，代价巨大；但「攘外必先安内」政策在 1930 年代初确实引起很大争议。
