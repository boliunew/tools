# 吃什么、背什么

徒步和露营里很多「出事」，追根溯源是很朴素的原因：**水不够、吃不够、衣服湿了、鞋磨脚、包太重**。这篇把这些基础的东西一次讲清楚。必带的安全装备（头灯、急救包、导航等）见 [十大必备与行程计划](ten-essentials-trip-plan.md)，这里不重复。

## 水：带多少

最简单的估法：**每小时运动约 0.5 升，热天、爬升大时 1 升**。

| 行程 | 建议带水（约） |
|---|---|
| 1–2 小时，凉快天 | 1 升 |
| 半天，中等爬升 | 2–3 升 |
| 一整天（Cucamonga Peak、Baldy） | 3–4 升，夏天更多 |
| 沙漠里徒步（Joshua Tree 等） | 按上面再加，**每人每天至少 4 升**是公园常给的底线 |
| 车载露营（喝 + 做饭 + 洗） | 每人每天 4 升以上，车上多放 |

- **大量出汗只喝白水也会出问题**（低钠）。带**电解质粉或盐丸**，配上咸的零食。
- **回程的水留够**——很多人是在下山路上缺水的。规则：**水喝掉一半就该考虑往回走**。
- 车上放一大桶，回到车上就有喝的。
- 路上能不能补水、溪水怎么处理，见 [水与净水](water-in-the-wild.md)。

## 热量：吃多少

### 一天徒步

徒步时身体一直在烧能量，**饿了再吃已经晚了**，体力会突然掉下来（俗称「撞墙」，英文 bonk）。

- 出发前吃一顿正经早饭。
- 路上**少量多次**：大约**每小时吃 200–300 千卡**的零食，每次休息都吃几口。
- 一天的强度徒步，除了早饭和晚饭，路上带 **800–1,500 千卡**的零食比较稳妥。吃不完带回来，总比不够好。
- 多带一份**应急食物**（一两根能量棒），万一被困过夜用。

### 两天一夜露营 / 背包过夜

- 常见的估法：**每人每天约 0.7–1.1 公斤（1.5–2.5 磅）食物**，大约 **2,500–4,500 千卡**，看体重、强度和天气（冷天多吃）。
- 背包过夜要看**热量密度**：争取平均**每克 4 千卡以上**（每盎司 100–125 千卡）。**脂肪每克约 9 千卡**，碳水和蛋白质约 4 千卡，所以坚果、花生酱、橄榄油、芝士是背包客的好朋友。
- 车载露营不用计较重量，带冷藏箱随便吃。

## 好带的食物：高热量、不怕热

南加州夏天车里和背包里都很热，**巧克力会化、三明治里的蛋黄酱会坏**。挑下面这些：

| 类别 | 例子 | 说明 |
|---|---|---|
| **坚果和种子** | 杏仁、腰果、混合坚果（trail mix） | 热量密度最高之一，不怕热 |
| **坚果酱** | 单独小包装的花生酱、杏仁酱 | 抹在饼上、直接挤着吃 |
| **饼和面包** | **墨西哥卷饼皮（tortilla）**、贝果、饼干 | Tortilla 不怕压、不怕热，比面包好带太多 |
| **肉和蛋白** | 牛肉干、真空包装的**金枪鱼/三文鱼/鸡肉软包**、意大利硬香肠（salami） | 软包比罐头轻，不用开罐器 |
| **芝士** | 硬质芝士（帕玛森、陈年切达）、独立包装的小芝士 | 硬芝士在常温下放一两天没问题 |
| **干果** | 枣、杏干、芒果干、葡萄干 | 快速糖分 |
| **能量食品** | 能量棒、能量胶、能量软糖 | 爬坡时吃，吸收快 |
| **咸的** | 薯片、椒盐脆饼、海苔 | 补钠；薯片压碎了也是热量 |
| **热食（要炉头）** | 速食面、速食饭、土豆泥粉、燕麦片、脱水的露营套餐 | 加热水就行 |
| **饮料** | 电解质粉、速溶咖啡、热可可粉 | 冷天晚上一杯热可可很顶用 |

**怕热的**：巧克力（换成 M&M 那种有糖衣的）、软芝士、含蛋黄酱的东西、新鲜肉。车载露营带冷藏箱可以放，**生肉放在冷藏箱最底下**并用袋子装好。

### 示例：两天一夜（一个人）

| 餐 | 吃什么 |
|---|---|
| 第一天午饭（路上） | Tortilla 卷金枪鱼软包 + 硬芝士 |
| 下午零食 | 混合坚果、能量棒、电解质水 |
| 晚饭 | 速食面加一包鸡肉或一把牛肉干，加一勺橄榄油；热可可 |
| 第二天早饭 | 燕麦片加坚果和干果、速溶咖啡 |
| 第二天路上 | Tortilla 抹花生酱、干果、薯片、能量胶 |
| 应急 | 一根能量棒，不到万不得已不吃 |

## 炉头和燃料

| 类型 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| **气罐炉**（异丁烷/丙烷混合气罐） | 轻、方便、火力可调、有开关阀 | **冷天（接近冰点）火力明显下降**；罐子不好判断剩多少 | 南加州大部分季节的首选 |
| **一体式快速烧水系统**（如 Jetboil 类） | 烧水很快，省气，防风好 | 不太适合炒菜 | 只烧水泡面的人 |
| **双头卡式炉 / 营地炉**（绿色 1 磅丙烷小罐） | 稳、火大、像在家做饭 | 重 | 车载露营 |
| **液体燃料炉**（白汽油） | **冷天、高海拔表现好**，燃料好买 | 要打气、要维护，偏重 | 冬天、雪山 |
| **酒精炉、固体燃料块** | 极轻、便宜 | **没有开关阀**，加州**火灾限制期间经常被禁止** | 慎用 |

**冷天点不着、火很小**：气罐里的气体在低温下汽化变慢。晚上把气罐**放进睡袋或贴身口袋**保温，用的时候放在**防潮垫的泡沫块上**隔开冷地面，选标着「冬季配方 / 异丁烷含量高」的罐子。

**带多少气**：一个人一天烧 1–1.5 升水（两顿热饭 + 热饮），**一罐 100 克的小罐**通常够两天一夜，有富余。出发前**称一下罐子重量**，减去罐子本身的空重（印在罐上）就知道剩多少。

**加州的规定**：在国家森林等联邦土地上、**开发好的营地以外**使用炉头，需要（免费的）**California Campfire Permit**；火灾风险高的时期，很多地方**只允许带开关阀的气罐炉/液体燃料炉**，篝火、木炭、酒精炉一律禁止。详见 [火与篝火规定](fire-and-campfire-rules.md)。

**安全**：不在帐篷里用炉头（着火、一氧化碳中毒）；炉头放在平稳的地面上，周围清掉干草；锅柄别朝外。

## 背包：多重算合适

REI 给的大致参考：

| 行程 | 装满后的背包重量 | 举例（体重 70 公斤） |
|---|---|---|
| **一天徒步** | 约**体重的 10%** | 约 7 公斤 |
| **过夜背包** | 约**体重的 20%** | 约 14 公斤 |

- 这只是参考，**水是最重的**（1 升 = 1 公斤），沙漠里背 4–5 升水很正常。
- **基础重量（base weight）** = 背包总重减去食物、水、燃料这些消耗品。背包客常按这个分：**10 磅（约 4.5 公斤）以下**算超轻，**20 磅（约 9 公斤）以下**算轻量。
- 新手最常见的问题是**带了太多「以防万一」的东西**，而不是带少了必需品。每次回来，把**没用上的东西**（除了急救包和安全装备）列出来，下次考虑不带。

**选背包**：一天徒步 **15–30 升**；过夜 **40–60 升**。最重要的是**背负长度（torso length）合适**——量的是脖子后面最突出的那节颈椎到髂骨上缘的距离，不是身高。去户外店让店员量、背着沙袋试。

## 背包怎么装：重的贴背

按 REI 的分区：

| 位置 | 放什么 |
|---|---|
| **底部** | 到营地才用的蓬松东西：**睡袋、睡衣**、营地鞋 |
| **中间、贴着背**（核心区） | **最重最密的东西**：食物袋、水袋、炉头和锅、熊罐 |
| **中间外侧** | 帐篷、衣服等轻一点的东西，塞紧空隙 |
| **顶部** | 路上可能要用的：**保暖层、雨衣**、急救包、净水器、厕所用品 |
| **顶包和侧袋、腰包** | 随时拿的：地图、手机、防晒霜、头灯、零食、车钥匙 |
| **外挂** | 尽量少：登山杖、冰镐、泡沫垫。挂多了会勾树枝、晃来晃去 |

**原则**：重的东西**贴近背、在肩胛骨之间的高度**，左右平衡；**一层一层横着装**，别竖着塞一列；**压缩带拉紧**，走起来不晃。

**背法**：先松开所有带子 → **腰带**系在髂骨上（大部分重量应该落在髋上，而不是肩上）→ 收紧肩带 → 拉一下顶部的调节带 → 扣上胸带。走一段觉得肩膀疼，多半是腰带没系对位置。

## 分层穿衣：三层法

山里一天之内会经历**出汗的爬坡、山顶的冷风、阴凉峡谷里的湿冷**。办法不是穿一件厚衣服，而是**几层薄的，随时加减**。

| 层 | 作用 | 选什么 | 不选什么 |
|---|---|---|---|
| **排汗层（贴身层）** | 把汗从皮肤上带走 | **美利奴羊毛**或**合成纤维**（涤纶、尼龙）的 T 恤、长袖 | **棉** |
| **保暖层（中间层）** | 留住体温 | **抓绒**、**羽绒服**或**合成棉服**（「Primaloft」之类的化纤棉） | 棉卫衣 |
| **防风防雨层（外层）** | 挡风、挡雨 | **防水透气的冲锋衣**，或轻的防风衣 | 一次性雨衣（一刮就破） |

**用法**：

- **出发时稍微冷一点**，走 10 分钟就会热起来。热了就脱，别等衣服湿透。
- **停下来休息、到了山顶，马上加衣服**，不要等觉得冷了再穿。
- 羽绒湿了就不保暖，下雨、潮湿的天气（海边、冬天）化纤保暖层更可靠。
- 夏天的南加州：浅色、宽松的**防晒长袖**和宽边帽，比短袖更凉快，也省防晒霜。

### 「棉衣致命」（Cotton kills）

这句话是户外圈的老口号，意思很具体：**棉一旦湿了（汗或雨），会吸住大量水分，干得极慢，几乎不保暖，还会把体温不断带走**。在凉风里穿一件湿透的棉 T 恤，是失温的经典开头。

- 南加州炎热、干燥的短途徒步穿棉 T 恤问题不大。
- 但**去山上、冬天、可能下雨、会出很多汗然后吹风**的行程，**贴身和保暖层都别穿棉**，包括**牛仔裤和棉袜**。
- 失温怎么认、怎么处理，见 [失温与中暑](hypothermia-heat-illness.md)。

**另外别忘了**：帽子（保暖的毛线帽 + 遮阳的宽边帽）、薄手套、太阳镜、魔术头巾（防晒防风防尘）。

## 鞋和袜子

**鞋**

| 类型 | 优点 | 缺点 | 适合 |
|---|---|---|---|
| **越野跑鞋（trail runner）** | 轻、透气、不用磨合、干得快 | 支撑和保护少一些 | 南加州大部分步道、干燥天气 |
| **低帮徒步鞋** | 鞋底更硬、更耐磨 | 稍重 | 碎石多的山路 |
| **中高帮徒步靴** | 脚踝保护和支撑好，防刺 | 重、热、要磨合 | 背重包、雪地（配冰爪）、乱石坡 |

- 不管选哪种，鞋底要有**深的花纹**。南加州山路的碎石（「滚珠」一样的花岗岩砂）很滑。
- **下午去买鞋**（脚会肿），穿着徒步袜试，**大半码**，下坡时脚趾不能顶到前面。
- 新鞋**先在城里走几次**再上长路线。
- 防水鞋（Gore-Tex 等）在南加州的夏天**很闷、汗湿以后干不了**，大部分时候不需要。

**袜子**

- **美利奴羊毛或合成纤维的徒步袜**，**不穿棉袜**——棉袜湿了是水泡的主要原因之一。
- 长线多带一双，中途换干的。
- 脚趾甲剪短。出现发热、摩擦就停下来贴胶带，见 [野外急救基础](wilderness-first-aid.md)。

## 垃圾：全部带走

Leave No Trace 的第三条（见 [露营入门](camping-basics.md)）：**带进来什么，就带出去什么。**

- **全部的包装纸、能量棒包装的撕下来的小角**——小碎片是步道上最常见的垃圾。
- **果皮、瓜子壳、苹果核**也要带走。它们在干燥的南加州分解得很慢，而且会让野生动物习惯来人这边找吃的。
- 用过的**卫生纸、湿巾、卫生用品**：用不透明的袋子装好带走。
- 背包里固定放一个**密封袋专门装垃圾**，回到车上一起扔。
- 看到别人留下的小垃圾，顺手捡走。

## 出门前的小清单（吃、喝、穿、背）

- [ ] 水：按时长和天气算好，**车上另放一大瓶**
- [ ] 电解质粉 / 盐丸
- [ ] 零食：每小时 200–300 千卡的量 + 一份应急
- [ ] 过夜：每人每天 0.7–1.1 公斤食物；炉头、气罐（**称过重量**）、打火机两个、锅
- [ ] 排汗层（**不是棉**）+ 保暖层 + 防风/防雨层
- [ ] 帽子、太阳镜、薄手套
- [ ] 合脚、磨合过的鞋 + 羊毛/化纤袜，长线多一双
- [ ] 背包：重的贴背、腰带系在髋上
- [ ] 垃圾袋
- [ ] 必备安全装备，见 [十大必备与行程计划](ten-essentials-trip-plan.md)
