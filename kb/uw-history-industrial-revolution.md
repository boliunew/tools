# 工业革命：世界为什么突然变富了

## 一句话

**工业革命让人类第一次实现了「人均」收入持续增长——在那之前，生产多了，人口就跟着多，平均下来还是穷。**

## 来龙去脉

### 之前：马尔萨斯陷阱

1800 年以前的几千年里，世界上大多数人的生活水平差不多：一个罗马农民和一个 1700 年的英国农民吃得差不多。原因是经济学家马尔萨斯说的：**粮食多了 → 人口增加 → 人均又回到温饱线**。技术有进步，但被人口增长吃掉了。

### 发生了什么（约 1760–1840，英国）

- **纺织**：珍妮纺纱机（1760 年代）、水力纺纱机、走锭纺纱机，一个工人能纺的纱成百倍增加。工厂（factory）出现，工人集中在一起按钟点上班。
- **蒸汽机**：瓦特在 1760–1770 年代大幅改进了蒸汽机，让它能带动机器，工厂不必建在河边。
- **煤和铁**：用煤代替木炭炼铁，铁产量大增；煤成了新能源。
- **交通**：运河、后来的铁路（1830 年利物浦—曼彻斯特铁路）、蒸汽船，让货物和人流动得更快更便宜。

之后传到比利时、法国、德国、美国、日本（第二次工业革命约 1870–1914：电、钢、化工、内燃机、电报电话）。

### 为什么是英国？

学者提了很多原因，大多认为是几样东西**同时**具备：

| 因素 | 说法 |
|---|---|
| 煤 | 英国有大量容易开采的煤，正好在需要的地方 |
| 工资高、能源便宜 | 劳动力贵、煤便宜，所以用机器代替人划算（罗伯特·艾伦的观点） |
| 制度 | 1688 年光荣革命后议会限制王权，财产权和专利比较有保障，金融市场发达 |
| 市场和贸易 | 国内市场统一，海外贸易和殖民地带来原料和市场 |
| 科学和工匠文化 | 很多发明来自懂手艺、爱钻研的工匠和小企业主，有交流知识的社团 |
| 农业进步 | 农业效率提高，释放出劳动力进城 |

### 代价

- **工厂条件恶劣**：一天工作十四五个小时、童工普遍、城市拥挤、霍乱流行。狄更斯的小说和恩格斯《英国工人阶级状况》描写了这些。
- **贫富分化**：资本家和工人之间的差距拉大，催生了工会、社会主义思想（马克思的理论就是对工业资本主义的分析和批判）。
- **污染**：伦敦的煤烟雾。
- **殖民扩张**：工业国家需要原料和市场，也有了更强的武器和轮船，加速了对亚非的殖民。
- **「大分流」**：原本中国江南、印度等地和西欧发展水平相差不大，工业革命后西方和其他地区的差距迅速拉开。

### 长期结果

- 人类寿命、收入、人口都开始持续增长。1800 年世界人口约 10 亿，今天超过 80 亿。
- 社会从农村为主变成城市为主，家庭、教育、时间观念都变了。
- 也是今天气候变化的起点：大规模燃烧化石燃料。

## 关键概念

| 概念 | 意思 |
|---|---|
| 马尔萨斯陷阱 | 生产增长被人口增长抵消，人均收入停滞 |
| 生产率 | 一个人一小时能生产多少东西，是长期富裕的根本 |
| 工厂制度 | 工人集中劳动、按时间计酬、分工细化 |
| 大分流（Great Divergence） | 1800 年后西欧、北美和世界其他地区经济差距迅速拉开 |
| 第二次工业革命 | 1870 年后的电、钢、化工、内燃机 |

## 不同的解释

- **制度派**（如阿西莫格鲁、罗宾逊《国家为什么会失败》）：关键是包容性的政治和经济制度，保护产权、鼓励创新。
- **资源和价格派**（如罗伯特·艾伦、彭慕兰《大分流》）：关键是英国的煤正好在合适的地方，加上殖民地带来的资源，有很多运气成分；彭慕兰认为 1750 年前后中国江南和英格兰的发展水平相当。
- **文化和思想派**（如乔尔·莫基尔、迪尔德丽·麦克洛斯基）：关键是启蒙运动后重视实用知识、尊重商人和发明家的文化。
- **马克思主义的解释**：资本主义生产方式和资本积累（包括殖民掠夺）推动了工业化，同时制造了阶级对立。
- **工人是变好了还是变坏了？** 「乐观派」认为长期看工人工资持续上涨；「悲观派」认为最初几十年工人生活其实变差了。现在多数研究认为大约 1820–1840 年以后实际工资才明显上升。

## 常见误解

- **「工业革命是一夜之间的事」**：其实是几十年、上百年慢慢积累的，早期增长速度并不快。
- **「是几个天才发明家的功劳」**：发明很多是工匠一点点改进出来的，而且需要市场、资本和制度配合才推广开来。
- **「机器让人失业，所以总体变穷」**：短期确实有人失业（卢德分子砸机器），但长期出现了大量新工作，总体生活水平上升。不过这个转换过程对当时的人可能很痛苦。
