# 中国近代史（一）：从鸦片战争到辛亥革命（1840–1912）

## 一句话

**一个庞大、自信、以农业为本的帝国，撞上了刚完成工业革命的西方和学得飞快的日本；七十年里试过修补、试过改良，最终整个王朝体制被推翻。**

## 起点：1800 年前后的清朝

- 乾隆时期（1736–1795）人口突破 3 亿，疆域达到最大，经济总量在世界上名列前茅。
- 对外贸易限定在广州一口（「一口通商」），由十三行商人经营；乾隆给英国马戛尔尼使团（1793）的回信说「天朝物产丰盈，无所不有」。
- 隐患在积累：人口压力、土地紧张、吏治腐败、白莲教起义（1796–1804）、财政吃紧。而同一时期英国正在发生工业革命（见《工业革命》一篇）。

## 时间线

| 年份 | 事件 | 结果 |
|---|---|---|
| 1839–1842 | **第一次鸦片战争**：林则徐虎门销烟，英国出兵 | 《南京条约》：割香港岛，开五口通商，赔款，协定关税 |
| 1851–1864 | **太平天国**：洪秀全建立政权，定都南京 | 死亡人数估计两千万以上，是 19 世纪最惨烈的战争之一；曾国藩、李鸿章的湘军、淮军平定，地方汉族督抚崛起 |
| 1856–1860 | **第二次鸦片战争**：英法联军攻入北京，火烧圆明园 | 《天津条约》《北京条约》；俄国趁机取得东北大片领土 |
| 1861–1895 | **洋务运动**：「中学为体，西学为用」，办军工厂、造船厂、北洋水师、派留学生 | 学了技术，没改制度 |
| 1894–1895 | **甲午战争**：北洋水师覆没 | 《马关条约》：割台湾、澎湖，赔款两亿两白银；震动全国，因为败给了「学生」日本 |
| 1898 | **戊戌变法**：光绪帝和康有为、梁启超推动改革 | 103 天后慈禧发动政变，谭嗣同等六君子被杀 |
| 1899–1901 | **义和团运动、八国联军**：「扶清灭洋」，清廷向列强宣战 | 《辛丑条约》：赔款 4.5 亿两白银，外国在北京驻兵 |
| 1901–1911 | **清末新政**：废科举（1905）、编练新军、预备立宪 | 改革来得太晚，「皇族内阁」（1911）让立宪派失望 |
| 1911 | **辛亥革命**：武昌起义，各省独立 | 1912 年中华民国成立，孙中山任临时大总统；清帝退位，帝制结束 |

## 关键概念

| 概念 | 意思 |
|---|---|
| **不平等条约** | 割地、赔款、开放通商口岸、协定关税（中国不能自主定关税）、**领事裁判权**（外国人在中国犯罪由本国领事审判）、最惠国待遇（给一国的特权其他国家自动享有） |
| **朝贡体系** | 传统东亚秩序：周边国家向中国皇帝朝贡，换取册封和贸易。它和西方「主权平等」的国际体系是两套逻辑，冲突是必然的 |
| **租界** | 外国人在通商口岸管理的区域，上海公共租界最有名 |
| **中体西用** | 洋务派口号，只学技术不动根本制度 |
| **「三千年未有之大变局」** | 李鸿章语，形容当时中国面对的处境 |

## 为什么清朝没能像日本那样改革成功

这是近代史最常被问的问题，答案有多种：

- **制度和社会结构**：日本是封建制，各藩有较强的地方力量，明治维新由下级武士推动，能迅速推翻幕府；清朝是高度中央集权的官僚帝国，士大夫阶层的利益和科举、儒家体制绑在一起。
- **满汉矛盾**：清廷作为少数民族统治者，担心改革削弱皇权和满人地位，迟迟不肯放权。
- **规模**：中国太大，人口太多，改革牵一发动全身；日本小而相对同质。
- **时机和运气**：日本 1868 年开始维新时，西方列强的注意力主要在中国；而中国被太平天国等内乱拖累了十几年。
- **领导者**：慈禧太后长期掌权，在关键时刻多次选择保守。也有史学家认为慈禧晚年推动的新政其实相当激进，对她的评价近年有所改变。

## 不同的解释

- **「冲击—回应」模式**（费正清等美国学者，20 世纪中期）：近代中国的变化主要是对西方冲击的回应。
- **「中国中心观」**（柯文《在中国发现历史》）：批评前者，认为要从中国内部找变化的动力，比如人口压力、地方社会、清朝自身的改革。
- **革命史观**：强调帝国主义侵略和封建统治的双重压迫，近代史是一部屈辱史和反抗史，最终走向革命。
- **现代化史观**：把近代史看作中国艰难走向现代化的历程，对洋务运动、清末新政、立宪派等改良力量评价更高。
- **鸦片战争的原因**：一种看法强调鸦片贸易的罪恶；另一种强调两种国际秩序和贸易观念的冲突，鸦片是导火索。两者并不矛盾。

## 常见误解

- **「清朝一直很落后」**：18 世纪的清朝在很多方面相当繁荣，差距主要是 19 世纪工业革命后迅速拉开的。
- **「义和团是单纯的爱国运动」或「单纯的愚昧暴乱」**：它既有反抗列强的一面，也有大量杀害传教士、中国基督徒和破坏铁路电线的行为，评价至今有争议。
- **「辛亥革命是孙中山一个人领导的」**：武昌起义爆发时孙中山在美国；革命是同盟会、各地新军、立宪派和地方士绅共同作用的结果。
