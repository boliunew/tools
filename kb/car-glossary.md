## 描述故障

| 英文 | 中文 |
|---|---|
| The check engine light is on. | 发动机故障灯亮了。 |
| It's making a squeaking / grinding / clicking noise. | 有吱吱 / 磨擦 / 咔哒的声音。 |
| It pulls to the left / right. | 车往左 / 右跑偏。 |
| The steering wheel shakes when I brake. | 刹车时方向盘抖。 |
| It won't start. | 启动不了。 |
| The battery is dead. | 电池没电了。 |
| I have a flat tire. | 我爆胎了 / 轮胎瘪了。 |
| There's a leak under the car. | 车底下在漏东西。 |
| The A/C isn't blowing cold air. | 空调不出冷风。 |
| It only happens when the car is cold / at high speed. | 只在冷车 / 高速时出现。 |

## 打电话照着说

- 预约保养：*"Hi, I'd like to schedule a maintenance appointment for my 2025 Camry Hybrid. It has about ___ miles."*
- 问报价：*"Can you give me a written estimate before doing any work?"*
- 不想要额外项目：*"Just the oil change and tire rotation for today, please. I'll think about the other items."*
- 确认机油：*"Please make sure you use 0W-8 oil, as the owner's manual requires."*
- 叫道路救援：*"My car broke down on the I-10 eastbound near ___ exit. I need a tow / a jump start / a tire change."*
- 报保险：*"I'd like to file a claim. I was in an accident today at ___. Nobody was injured."*
