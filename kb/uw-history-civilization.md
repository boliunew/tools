# 文明从哪里来：农业革命和最早的国家

## 一句话

**农业让人能囤积粮食，囤积带来了剩余、分工和争夺，国家就是为了管理（和抢夺）这些剩余而出现的。**

## 来龙去脉

### 漫长的采集狩猎时代

现代人（智人）大约在 30 万年前出现在非洲，之后几万年里走遍了各大洲。这段时间的绝大部分，人类以几十人的小群体生活，靠采集和打猎为生，跟着季节和猎物移动。没有国王，也很少有大规模的贫富差距——东西太多带不走。

### 农业革命（约公元前 10000 年起）

最后一次冰期结束后，气候变得温暖稳定。几个地方的人**各自独立地**开始种植和驯养：

| 地区 | 大约时间 | 主要作物 / 动物 |
|---|---|---|
| 西亚「新月沃地」（今伊拉克、叙利亚一带） | 公元前 9500 年起 | 小麦、大麦、羊、牛 |
| 中国黄河、长江流域 | 公元前 7000 年起 | 小米、水稻、猪 |
| 中美洲（今墨西哥） | 公元前 7000 年起 | 玉米、豆、南瓜 |
| 南美安第斯山 | 公元前 6000 年起 | 土豆、羊驼 |
| 新几内亚、非洲萨赫勒等 | 各不相同 | 芋头、高粱等 |

农业的意思是：一块地能养活的人变多了很多，但人必须**定居**下来守着地。

### 剩余、分工和城市

能存粮之后：

- 不是每个人都要种地了，出现了工匠、祭司、战士、商人。
- 粮食需要记账、仓库需要管理 → **文字**最早就是记账工具（两河流域的楔形文字最早的泥板大多是账本）。
- 存粮会被抢 → 要修城墙、养军队。
- 水利（灌溉渠、防洪）需要组织大批人干活 → 需要有人发号施令。

于是在大河流域出现了最早的城市和国家：

- **两河流域（美索不达米亚）**：苏美尔城邦，约公元前 3500–3000 年，乌鲁克等城市，楔形文字。
- **埃及**：约公元前 3100 年统一，法老、金字塔、象形文字。
- **印度河流域**：哈拉帕、摩亨佐-达罗，约公元前 2600 年，城市规划整齐，文字至今没破译。
- **中国**：黄河流域，二里头文化（约公元前 1900 年起，常被认为与夏有关），商朝（约公元前 1600 年起）有甲骨文。
- **中美洲、安第斯**：奥尔梅克、后来的玛雅、印加等，独立发展。

### 国家是什么时候出现的

早期国家的共同点：**有固定的统治者、有征税、有常备的武力、有文字记录、有城市。** 统治者往往用宗教来说明自己统治的正当性（法老是神、商王通过占卜和祖先沟通）。

## 关键概念

| 概念 | 意思 |
|---|---|
| 新石器革命 | 从采集狩猎转向农业、定居的变化 |
| 剩余（surplus） | 生产出的、超过生存需要的那部分，是分工和国家的基础 |
| 城邦 | 一个城市加周围土地组成的独立政权 |
| 楔形文字 / 甲骨文 | 最早的文字系统之一，最初多用于记账、占卜 |
| 「大河文明」 | 几个最早的文明都靠大河灌溉和运输 |

## 不同的解释

- **农业是进步吗？** 传统看法：农业让人类走向文明。也有学者（如贾雷德·戴蒙德称之为「人类历史上最大的错误」，尤瓦尔·赫拉利在《人类简史》里也有类似观点）指出：早期农民比采集者更矮、营养更差、更多疾病、劳动更累，而且出现了贫富差距和奴役。农业养活了更多的**人**，不一定让每个**人**活得更好。
- **国家是怎么来的？** 一种说法是**契约/功能论**：为了组织水利、维护秩序，人们需要国家。另一种是**冲突/掠夺论**：国家起源于征服和抢夺剩余（如詹姆斯·斯科特《反谷》认为早期国家靠谷物税收和强迫劳动维持，很多人其实想逃离国家）。两种说法可能都对一部分。
- **为什么是这些地方先走出来？** 戴蒙德《枪炮、病菌与钢铁》强调地理：可驯化的动植物多、大陆东西向延伸利于作物传播。批评者认为他低估了文化、制度和偶然性。

## 常见误解

- **「文明是从一个地方传出去的」**：不对，几个地方是各自独立发明了农业和文字。
- **「原始人生活很惨，一直在挨饿」**：不一定，很多采集者每天劳动时间比早期农民短，饮食更多样。
- **「古代社会都差不多」**：两河是很多城邦互相竞争，埃及是一个大一统王国，差别很大。

## 留给你想的问题

- 如果农业让很多人过得更辛苦，为什么还是扩散到了全世界？
- 「剩余」带来分工，也带来争夺。今天的社会还是这样吗？
- 一个国家靠什么让人们接受它的统治——武力、宗教、还是带来的好处？
