# 美国史（一）：从殖民地到建国（1607–1800）

## 一句话

**一群远离英国、早已习惯自治的殖民地，因为反对伦敦加税和管控而起义，最后建立了一个以成文宪法和权力制衡为基础的共和国——同时保留了奴隶制这个最深的矛盾。**

## 来龙去脉

| 年份 | 事件 |
|---|---|
| 1492 起 | 欧洲人到达美洲，原住民人口因疾病、战争在之后一两个世纪大幅减少（估计减少了绝大多数） |
| 1607 | **詹姆斯敦**（弗吉尼亚）：英国在北美第一个永久殖民地，靠种植烟草活下来 |
| 1619 | 第一批被贩运的非洲人到达弗吉尼亚；同年弗吉尼亚建立殖民地议会 |
| 1620 | **「五月花号」** 清教徒到达普利茅斯（马萨诸塞），签订《五月花号公约》 |
| 1600–1700 年代 | 13 个殖民地逐步建立：北方新英格兰以小农、商业、清教为主；南方以种植园和奴隶劳动为主；中部（纽约、宾夕法尼亚）多元 |
| 1754–1763 | **法国—印第安战争**（七年战争的北美部分）：英国打败法国拿下北美东部，但背上了巨额债务 |
| 1765 | **《印花税法》**：英国向殖民地征税，殖民地喊出「**无代表不纳税**」 |
| 1770 | 波士顿惨案 |
| 1773 | **波士顿倾茶事件** |
| 1775 | 列克星敦和康科德的枪声，**独立战争**开始；华盛顿任大陆军总司令 |
| 1776.7.4 | **《独立宣言》**（杰斐逊起草）：「人人生而平等」，拥有生命、自由和追求幸福的权利 |
| 1777 | 萨拉托加大捷，促使法国 1778 年参战援助 |
| 1781 | 约克镇战役，英军投降 |
| 1783 | 《巴黎条约》，英国承认美国独立 |
| 1781–1789 | 《邦联条例》时期，中央政府软弱，无权征税；谢斯起义（1786）让精英担心失控 |
| 1787 | **费城制宪会议**，写出宪法；「**五分之三妥协**」（奴隶按五分之三个人计算众议院席位）、大州小州妥协（参议院每州两席） |
| 1789 | 宪法生效，**华盛顿**当选第一任总统 |
| 1791 | 《权利法案》（前十条修正案） |
| 1796 | 华盛顿发表告别演说，警告党派之争和卷入欧洲纠纷，只做两届，树立了先例 |
| 1800 | 杰斐逊击败亚当斯，政权在对立党派间和平交接，被称为「1800 年革命」 |

## 关键人物

| 人物 | 角色 |
|---|---|
| **乔治·华盛顿** | 大陆军总司令、第一任总统 |
| **托马斯·杰斐逊** | 《独立宣言》起草人、第三任总统；主张农业共和国、州权；他自己拥有六百多名奴隶 |
| **约翰·亚当斯** | 第二任总统 |
| **亚历山大·汉密尔顿** | 第一任财政部长，建立国家银行、承担各州债务，主张强大的联邦政府和工商业 |
| **詹姆斯·麦迪逊** | 「宪法之父」，《权利法案》起草人，第四任总统 |
| **本杰明·富兰克林** | 科学家、外交家，争取到法国援助 |

## 第一次党争：汉密尔顿 vs 杰斐逊

| | 联邦党（汉密尔顿） | 民主共和党（杰斐逊） |
|---|---|---|
| 政府 | 强大的联邦政府 | 州权，小政府 |
| 经济 | 工商业、银行、制造业 | 农业，独立自耕农 |
| 宪法 | 宽泛解释 | 严格解释 |
| 外交 | 亲英 | 亲法 |
| 支持者 | 东北部商人 | 南方和西部农民 |

这条「联邦权力 vs 州权」的线索贯穿了整个美国史，今天的很多政治争论仍然是它的延续。

## 不同的解释

- **理想主义的解释**：美国革命是一场为自由和自治原则而战的革命，《独立宣言》和宪法是启蒙思想的实践。
- **经济利益的解释**（查尔斯·比尔德，1913）：制宪者是有产者，宪法保护的是他们的财产和债权。后来的研究认为这种解释过于简单。
- **批判性的解释**：「人人生而平等」不包括奴隶、女性和原住民；比如《1619 项目》（2019）主张把奴隶制放到美国建国叙述的中心，这一说法引起了很多历史学家的支持和批评。
- **「温和革命」**：和法国大革命、俄国革命相比，美国革命没有颠覆原有的社会结构，主要是政治独立，这既被视为它成功的原因，也被视为它的局限。

## 常见误解

- **「美国独立只是为了不交税」**：税是导火索，更深的问题是谁有权统治殖民地。
- **「清教徒来美国是为了宗教自由」**：他们是为了自己的宗教自由，在马萨诸塞并不容忍其他信仰。
- **「开国元勋们意见一致」**：他们之间争吵激烈，汉密尔顿 1804 年死于和副总统伯尔的决斗。
