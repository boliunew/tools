# 编程入门

很多人对编程有种混合了向往和畏惧的想象：觉得那是天才的领域，又听说它能改变职业轨迹。这篇把这件事说回地面：编程本质上是把事情交代清楚的一种手艺，普通人完全能学会入门，关键是选对语言、走对路径、并尽快做出一个自己真正想用的东西。

## 编程到底是什么

编程就是**用精确的语言把解决问题的步骤写给计算机**。计算机不会猜、不会领会精神，它只会一条一条执行你的指令——这既是难点（你必须想清楚每一步），也是优点（它永远按你说的做，错了一定是你写错了，可以查、可以改）。

一个程序通常包含几块基本构件，任何语言都有：

| 构件 | 通俗理解 | 例子 |
|---|---|---|
| 变量 | 贴了标签的盒子，装数据 | 把用户的年龄装进「age」 |
| 判断 | 如果……就……否则…… | 如果下雨，就提醒带伞 |
| 循环 | 把一件事重复做很多遍 | 把通讯录里每个人都发一遍通知 |
| 函数 | 打包好的小工具，随用随取 | 「算总价」函数，传进单价和数量 |
| 数据结构 | 组织数据的架子 | 列表、字典、表格 |

学会编程，就是学会用这几块构件拆解问题。语法（每种语言的具体写法）反而是最表层、最容易查的部分。真正的功夫在「拆解」：把一个模糊的大任务（做个记账工具）拆成一连串计算机能执行的小步骤。这个能力练出来了，换语言只是换套词汇。

## 第一门语言怎么选

选语言的标准只有一个：**你想拿它做什么**。用途决定语言，语言没有高低之分。

| 想做的事 | 推荐起步语言 | 理由 |
|---|---|---|
| 数据处理、自动化办公、量化、AI 入门 | **Python** | 语法最接近自然语言，库多，报错友好，新手默认选择 |
| 做网页、交互页面 | JavaScript（配 HTML/CSS） | 浏览器里唯一原生语言，所见即所得最快 |
| 做手机 App | Kotlin（安卓）/ Swift（苹果）/ 先学一门再说 | 目标明确时直接对口学 |
| 孩子或纯兴趣启蒙 | Scratch → Python | 图形化过渡到真代码 |
| 应付学校课程/考试 | 按 syllabus 学 | 别自选，先过考试 |

没有明确目标、只是想入门和拓展可能性：**直接选 Python**，这是全球共识度最高的答案，不用纠结。它的生态从办公自动化到人工智能都覆盖，学完不浪费；社区大，任何报错都能搜到前人踩过的坑。

不要同时学两门语言，也不要在入门期频繁换语言。各语言的核心概念是相通的，第一门学到能独立写小工具，再学第二门会非常快。

## 自学路径：一条能走通的线

**阶段一：语法打底（2 到 4 周）**

找一门结构完整的入门课或一本入门书（图书馆和网上都有经典选择），跟着把变量、判断、循环、函数、列表字典过一遍。关键要求：**每学一个概念，当场敲代码验证**，不要只看视频点头。这一阶段做的练习可以很无聊（打印九九乘法表、猜数字游戏），目的就是把构件变成手指记忆。

**阶段二：小工具练手（1 到 2 个月）**

开始做「对自己有用」的小东西，这是分水岭。例子按难度递增：批量给文件改名、把 Excel 表格自动汇总、用几十行代码抓取一个网页的价格并记录、做一个简单的记账或记单词程序。在这个阶段你会密集遇到报错——这是正常的，编程的工作日常就是写代码、报错、读报错、改。学会读英文报错信息和搜索问题，是比语法更重要的技能。

**阶段三：补基础概念（持续）**

当你能写出几百行的程序后，补上这些概念会突然打通很多事：文件与数据格式（JSON、CSV）、数据库是干什么的、网络请求（API）怎么回事、版本管理 Git 的基本用法（保存代码的时光机，迟早都要学）、命令行基本操作。

**阶段四：选一个方向深入**

数据分析、网页开发、自动化运维、AI 应用……到这个阶段你已经有判断力了，按兴趣和用途选，用项目牵引学习：想学什么，就做一个需要它的项目。

> 避开两个典型坑：一是「收藏式学习」，囤了二十门课一门没上完——任何一门主流入门课学完，效果都好于十门课各学前三节；二是「永远在打基础」，迟迟不肯做项目——项目里踩的坑，抵得上看三遍教程。

## 你的第一个项目：怎么选题和收尾

第一个项目决定了你会不会继续。选题三原则：**自己真需要、范围小到一两周能做完、做完能用上或能给人看**。

几个被验证过的好选题：

- 个人记账小工具：录入、分类、按月汇总成一句话报告
- 文件整理器：把下载文件夹按类型和日期自动归档
- 价格/库存记录器：定时抓某个商品页面，降价了写一行提醒
- 单词复习器：导入自己的词表，按遗忘曲线出题（原理见[词汇与听说](english-vocab-listening.md)）
- 一页纸小网站：用 HTML/CSS 给家人做一个生日页、旅行计划页

做的过程中遵循一条纪律：**先跑通最简版本，再加功能**。想记账，先做到「能录入、能保存、能看总额」就停一天，第二天再加分类。很多人死在第一版就想做全功能，代码越写越乱然后放弃。跑通的成就感是燃料，小步快跑才能持续供给。

另外两个习惯越早养成越好：一是代码写一点就运行一点，别写两百行才第一次运行，出错时根本定位不了；二是把报错信息整段复制去搜索，百分之九十的问题别人都遇到过并写了解法。

## 关于 AI 编程工具：可以用，但有顺序

现在让 AI 直接生成代码非常容易，入门者也可以用，但顺序很重要：**先自己学到能看懂代码，再让 AI 帮你写**。原因是 AI 的代码也会出错、会用你不懂的写法，你至少要有能力判断「这段在干什么、大概对不对、出错了怎么查」。合理的用法是：让它解释概念、给例子、帮你看报错、做代码评审；不合理的是整段复制自己完全读不懂的代码去交差——那样你没有在学编程，只是在搬运。

学完基础之后，AI 工具会让你的效率翻倍，这正是[人工智能入门](ai-basics.md)里说的「杠杆」的意思。

## 现实预期：多久能学到什么程度

- 每天 1 小时、坚持 3 个月：能独立写处理文件、表格、简单自动化的脚本，解决生活工作中的小麻烦
- 半年到一年系统学习加项目：有机会达到初级岗位或接小活的水平，但这取决于投入强度和方向
- 编程不是一次性技能：语言和工具一直在变，但拆解问题的思维方式学会了就不会过期

最重要的是预期管理：前两周的新鲜感过后会有一段「什么都不顺」的平台期，所有人都有。熬过去的方法就是把目标缩小到「今天再写 20 分钟」，而不是「我必须成为程序员」。
