# 投资里的心理偏差

大多数投资错误不是因为不懂知识，而是**知道该怎么做、到时候做不到**。人脑在处理风险、损失和不确定性时有一些固定的「出厂设置」，在原始环境里有用，放到股市里常常帮倒忙。

这篇列出 18 种常见偏差。每一种都说三件事：一句话定义、在炒股时长什么样、怎么对付。做量化的人别以为写成代码就能避开它们，它们会换个样子出现在回测和系统设计里，所以也单独说一下。

> 本文只解释概念，不构成投资建议。

## 一览

| 偏差 | 一句话 | 最常见的后果 |
|---|---|---|
| 损失厌恶 | 亏 100 比赚 100 的感受强得多 | 大跌时卖出、不敢止损 |
| 处置效应 | 赚的急着卖，亏的死扛 | 截断利润、放任亏损 |
| 确认偏差 | 只看支持自己观点的信息 | 对风险视而不见 |
| 近因偏差 | 把最近的情况当成常态 | 追涨杀跌 |
| 锚定效应 | 被某个无关的数字绑住 | 「回到成本价就卖」 |
| 过度自信 | 高估自己的判断力 | 仓位过重、交易过多 |
| 羊群效应 / FOMO | 怕错过别人都在赚的钱 | 高位追入 |
| 沉没成本 | 因为已经投入了而继续投入 | 越亏越加仓 |
| 后见之明 | 事后觉得「我早就知道」 | 高估预测能力 |
| 心理账户 | 同样的钱分开对待 | 拿「赚来的钱」乱冒险 |
| 赌徒谬误 | 以为连跌之后一定会涨 | 过早抄底 |
| 可得性偏差 | 容易想到的事被高估 | 被新闻牵着走 |
| 禀赋效应 | 自己持有的东西更值钱 | 不愿卖掉表现差的股票 |
| 过度交易 | 动得越多越好的错觉 | 成本和税吃掉收益 |
| 本土偏好 | 只买熟悉的 | 集中度过高 |
| 叙事谬误 | 一个好故事胜过数据 | 为故事付过高的价 |
| 幸存者偏差 | 只看到活下来的 | 高估策略和投资方式的胜率 |
| 结果偏差 | 用结果评价决策 | 从运气里学到错误的教训 |

## 1. 损失厌恶（Loss Aversion）

**定义**：同样金额的损失带来的痛苦，比收益带来的快乐大得多。行为经济学里常见的估计是大约两倍左右，因人而异。

**炒股时**：账户涨了 5 万没什么感觉，跌了 5 万夜里睡不着。2020 年 3 月那样的下跌中，很多人卖出的理由不是分析，而是「受不了了」。反过来，损失厌恶也会让人不愿意止损，因为止损意味着「亏损变成真的」。

**怎么对付**：

- 投资前算「最坏情况会少多少美元」，而不只是百分比。如果那个数字受不了，降低股票比例，而不是寄希望于到时候扛得住。
- 少看账户。查看频率越高，看到亏损的次数越多。定投账户可以一个季度看一次。
- 历史上的大跌和恢复见 [美股历次大跌与恢复](market-crash-history.md)，提前知道会发生什么，能减轻发生时的冲击。

**量化里**：你可能会在系统里加上一堆「保护」——更紧的止损、更多的过滤条件——只是因为看到回测里的回撤不舒服。结果往往是降低回撤的同时砍掉了更多收益。判断标准应该是风险调整后的收益，而不是「看着舒服」。

## 2. 处置效应（Disposition Effect）

**定义**：倾向于过早卖出赚钱的股票，过久持有亏钱的股票。

**炒股时**：赚了 10% 赶紧「落袋为安」，亏了 20% 告诉自己「不卖就不算亏」。结果组合里剩下的都是亏钱的票，赚钱的都卖早了。

**怎么对付**：

- 每只持仓定期问一个问题：**如果现在手里是现金，我会按今天的价格买它吗？**如果不会，持有它的理由就和你的成本价无关。
- 买入前写好退出规则：什么情况下止损、什么情况下止盈或移动止盈。
- 在应税账户里，亏损的仓位卖出还能抵税（tax-loss harvesting），见 [美国投资账户与税的基本概念](us-investment-accounts-tax.md)。

**量化里**：手动「干预」系统信号时最常见。系统说该止损，你想「再等等」；系统说继续持有，你想「先拿点利润」。记录每一次手动干预和它的结果，几个月后统计一下，通常会发现干预总体是负贡献。

## 3. 确认偏差（Confirmation Bias）

**定义**：主动寻找、记住支持自己观点的信息，忽略或贬低反对的信息。

**炒股时**：买了某只股票后，只看看多的文章和帖子，看到利空就说「市场不懂」。论坛和推荐算法会把这种倾向放大。

**怎么对付**：

- 买入前写下「什么情况会证明我错了」，并定期检查。
- 刻意去读最有说服力的看空观点，尝试用自己的话复述它。
- 不在只有同一种声音的群里讨论持仓。

**量化里**：策略回测结果不好时，你会仔细找 bug；结果很好时，你很少去检查。这正是 [回测里最常见的坑](backtest-pitfalls.md) 第一条说的：**结果越好，越要怀疑**。给好结果和坏结果同样的审查力度。

## 4. 近因偏差（Recency Bias）

**定义**：把最近发生的事当作未来的常态。

**炒股时**：连续几年牛市后觉得股票每年都能涨 20%；刚经历暴跌后觉得还会继续跌。某个行业最近一年涨得最多，就觉得它会一直领先。

**怎么对付**：

- 看长期数据。美股有过「失去的十年」，也有过连续多年的大牛市。
- 资产配置按长期计划定，而不是按最近一年谁表现好。
- 定期再平衡，等于强制反近因：卖掉近期涨多的，买入近期落后的。

**量化里**：只用最近几年的数据回测。比如只用 2010 年以后的数据，策略就从没见过 2008 年那样的熊市，也没见过 2022 年那种利率快速上升、股债同跌的环境。至少要覆盖几种不同的市场状态。

## 5. 锚定效应（Anchoring）

**定义**：判断时过度依赖某个最先接触到的数字，即使它和问题无关。

**炒股时**：「等回到我的成本价就卖」「它曾经 200，现在 100，很便宜」。你的成本价和历史高点，对这只股票未来值多少钱没有任何影响。

**怎么对付**：

- 评估持仓时，把成本价那一列隐藏起来，只看现在的价格和基本面。
- 「便宜」要和价值比，而不是和过去的价格比。

**量化里**：参数锚定。你第一次试的均线参数是 20 天，之后所有优化都围着 20 打转，或者觉得 20 是「对的」，别的参数都要证明比它好。还有：用一个历史时期的回测收益当作对实盘的预期，实盘不如它时就觉得「出问题了」。

## 6. 过度自信（Overconfidence）

**定义**：高估自己的知识、判断的准确性和对结果的控制力。

**炒股时**：赚了几次就觉得自己能看懂市场，开始加大仓位、用杠杆、集中买几只股票。很多人觉得自己的投资水平「高于平均」，但不可能人人都高于平均。

**怎么对付**：

- 写交易日志，记录每笔交易的理由和预期，定期回看胜率和盈亏比，用数据代替感觉。
- 和基准比较：一年下来，你的主动操作跑赢 VOO 买入持有了吗？
- 单只股票、单个策略的仓位设上限。

**量化里**：对回测结果过度自信。一条回测曲线只是历史的一种可能路径。可以用蒙特卡洛重排交易顺序、bootstrap 收益率、看参数热力图，估计结果的不确定范围。

## 7. 羊群效应 / FOMO

**定义**：跟随大多数人的行为；害怕错过别人正在赚的钱。

**炒股时**：身边人都在说某个概念股、某个加密货币涨了几倍，自己没买就焦虑，最后在高位冲进去。反过来，大家都在恐慌卖出时，一个人拿着也很难。

**怎么对付**：

- 设一个「冷却期」：想买的东西加进观察列表，等 48 小时或一周再决定。
- 给「玩一玩」的钱设固定上限，比如总资产的 5%，亏完就停，不影响主要计划。
- 注意自己的信息来源：社交媒体上展示的永远是赚钱的截图。

**量化里**：看到别人在网上晒回测曲线，就去抄同样的策略或指标，而不是基于自己的数据和逻辑验证。网上流传的策略也经过了严重的筛选——赚钱的才会被分享。

## 8. 沉没成本谬误（Sunk Cost Fallacy）

**定义**：因为已经投入了时间、金钱或精力，所以继续投入，即使理性上应该停止。

**炒股时**：一只股票亏了 40%，继续往下摊平，因为「已经亏这么多了，现在卖太亏」。研究了一个月的股票，即使发现问题也舍不得放弃。

**怎么对付**：

- 决策只看未来：从现在开始，继续持有或加仓的期望回报是多少？
- 摊平之前问：这是原计划的一部分，还是因为不想承认错误？

**量化里**：一个策略花了几个月开发，样本外表现很差，你还是不断地「修」它——加个过滤、换个参数——而不是放弃。这会不知不觉地让样本外数据变成样本内。事先定好「样本外表现差到什么程度就放弃」。

## 9. 后见之明偏差（Hindsight Bias）

**定义**：事情发生后，觉得自己早就预料到了，结果「显然」会这样。

**炒股时**：「2020 年 3 月明明是最好的买点，我当时怎么没买」「那家公司明显有问题」。事后清楚的东西，当时其实一片模糊。

**怎么对付**：

- 在做决定时写下当时的判断和把握程度。事后对照，才知道自己当时到底「知道」多少。
- 不要用「早该知道」惩罚自己，也不要因此高估自己下一次的预测能力。

**量化里**：「我知道 2008 年会崩盘，所以在策略里加一条：信用利差扩大就清仓」。你是在知道答案之后写的规则。任何为了避开某个已知历史事件而加的规则，都要特别怀疑。

## 10. 心理账户（Mental Accounting）

**定义**：把同样的钱按来源或用途分到不同的「账户」里，区别对待。

**炒股时**：「这是赚来的钱，亏了也无所谓」「这是退税的钱，拿去博一把」。钱就是钱，赚来的 1 万和工资的 1 万购买力一样。另一个常见情况：一边有高息信用卡债务，一边在投资账户里放着钱。

**怎么对付**：

- 看整体净资产和整体配置，而不是一个个账户分别看。
- 心理账户也有正面用法：应急资金单独放、和投资账户分开，正是为了避免它被花掉或投进去。

**量化里**：分别评估每个策略，觉得每个都还行，却没看它们合起来的总风险。几个策略可能都在同时做多大盘科技股，相关性很高，组合回撤会比单个大得多。

## 11. 赌徒谬误（Gambler's Fallacy）

**定义**：以为随机事件之间有「平衡」，连续出现一种结果后，另一种结果就「该来了」。

**炒股时**：「已经连跌五天了，明天该涨了」「连续三笔交易止损，下一笔一定会赚」，于是加大下一笔的仓位。

**怎么对付**：

- 仓位大小按规则定，不随最近几笔的结果变化。
- 认清：短期价格变化接近随机，连跌不保证反弹，连涨也不保证回调。

**量化里**：注意区分赌徒谬误和真实的均值回归。某些品种在某些时间尺度上确实有统计上的短期反转效应，但这需要用数据和样本外验证来证明，而不是凭「跌多了该涨」的直觉。

## 12. 可得性偏差（Availability Bias）

**定义**：越容易想到、越生动的事，越觉得它可能发生。

**炒股时**：刚看了一堆关于崩盘的新闻和视频，就觉得崩盘马上要来；身边有人炒某只股票发了财，就高估这种事的概率。经济数据公布日的新闻标题尤其容易放大情绪，指标本身怎么看见 [经济指标怎么看](economic-indicators.md)。

**怎么对付**：

- 用数据代替印象：问「历史上这种情况发生的频率是多少」。
- 减少接触耸动的财经内容，尤其在市场波动大的时候。

**量化里**：给策略加规则时，往往只想到印象最深的那几次大跌，结果规则对那几次很有效，对其他情况可能有害。用全部历史数据统计规则的效果，而不是挑几个记得的例子。

## 13. 禀赋效应（Endowment Effect）

**定义**：对自己已经拥有的东西估价更高。

**炒股时**：同一只股票，没买之前觉得 50 美元有点贵，买了之后觉得 50 美元太便宜，不舍得卖。继承来的、公司发的股票（RSU）尤其明显，「这是公司给的，不能卖」。

**怎么对付**：

- 用「现金测试」：如果这只股票今天变成了等值现金，你会用这笔钱再把它买回来吗？
- 对公司股票，一些人会在 RSU 归属后按规则卖出一部分，避免工作和资产同时集中在一家公司。

**量化里**：对自己写的指标、自己发现的「规律」偏爱有加，拿它和别人的方法比较时标准更宽松。把自己的策略和最简单的基准（买入持有、简单均线）放在完全相同的条件下比较。

## 14. 过度交易（Overtrading）

**定义**：交易频率高于实际需要，误以为多动多赚。往往是过度自信、无聊和「想做点什么」的结果。

**炒股时**：每天不买卖点什么就觉得浪费了时间；市场横盘时也硬要找机会。零佣金让交易感觉是「免费」的，但点差、滑点和短期资本利得税并不免费。研究个人投资者账户的学术文献（比如 Barber 和 Odean 关于散户交易的研究）普遍发现，交易越频繁的账户，扣除成本后的表现往往越差。

**怎么对付**：

- 规定交易频率上限，比如每周最多开几笔新仓。
- 只在系统给出信号时交易，没有信号就不动。
- 把长期账户和交易账户分开，交易账户的金额限定在一个比例内。

**量化里**：回测里没扣足成本，高频策略看起来很赚钱；或者为了提高「交易次数」以获得统计显著性，把参数调到频繁换仓。每次都要扣交易成本和税后再比较，见 [回测里最常见的坑](backtest-pitfalls.md)。

## 15. 本土偏好（Home Bias）

**定义**：过度投资自己熟悉的市场、行业或公司。

**炒股时**：只买美国股票，或者只买自己工作行业的股票，或者只买每天用的产品的公司。熟悉不等于了解它的投资价值，而且会让风险过于集中。

**怎么对付**：

- 有意识地检查组合的集中度：单一国家、单一行业、单一公司分别占多少。
- 只持有 VOO 就是 100% 美国大盘股，这可以是一个有意识的选择，但应该是选择，而不是默认。

**量化里**：只在自己熟悉的几只股票或 ETF 上开发和测试策略，样本太少、太同质。至少在一组不同风格、不同行业的标的上检验同一套规则。

## 16. 叙事谬误（Narrative Fallacy）

**定义**：喜欢用一个连贯的故事解释事情，故事越动听越容易相信，即使数据不支持。

**炒股时**：「AI 会改变一切，所以这家公司会涨十倍」——行业前景好和这只股票在当前价格上是否值得买，是两件事。每天收盘后的「今日市场为何下跌」报道，也常常是事后为随机波动配上的故事。

**怎么对付**：

- 把故事和价格分开：就算故事是对的，现在的价格已经反映了多少？
- 问一句：「如果这个故事是错的，会出现什么迹象？」

**量化里**：先看到回测结果好，再编一个「为什么有效」的经济学解释。这个顺序反了。更可靠的是先有一个有逻辑的假设，再用数据检验，而且检验之前就写下预期。

## 17. 幸存者偏差（Survivorship Bias）

**定义**：只看到「活下来」的样本，忽略了消失的那些，从而得出过于乐观的结论。

**炒股时**：「长期持有个股一定赚钱，看看苹果、微软」——但同样被长期持有、后来退市或破产的公司你看不到。基金公司会关闭或合并业绩差的基金，所以「现存基金的平均业绩」会被高估。网上晒的交易账户都是赚钱的。

**怎么对付**：

- 看到一个成功案例时问：用同样方法失败的人有多少？我看得到他们吗？
- 宽基指数基金能部分避开这个问题，因为指数会自动替换掉衰落的公司。

**量化里**：用今天的标普 500 成分股名单回测过去十年，等于只挑了活下来、还表现足够好的公司。yfinance 一般拿不到已退市公司的数据。解决方法和更多细节见 [回测里最常见的坑](backtest-pitfalls.md) 第 2 节。

## 18. 结果偏差（Outcome Bias）

**定义**：用结果的好坏判断决策的好坏，而忽略做决定时的信息和过程。

**炒股时**：满仓押一只股票赚了，就觉得这个决策很英明；按计划止损后股票反弹了，就觉得止损是错的。好决策可能有坏结果，坏决策也可能有好结果，单次结果里运气成分很大。

**怎么对付**：

- 复盘时分开评估两件事：决策过程是否合理（有没有按计划、信息是否充分、仓位是否合适），以及结果是好是坏。
- 只有在足够多次的重复后，结果才能说明过程的好坏。

**量化里**：策略上线第一个月赚了就加仓，亏了就停掉。一个月的实盘结果在统计上几乎什么都说明不了。事先决定「实盘多长时间、多少笔交易后再评估」，期间只检查执行是否和回测一致。

## 偏差在量化系统里的位置

写成代码并不能消除偏差，它们只是从「下单那一刻」转移到了「设计系统那一刻」：

| 系统设计环节 | 容易混进来的偏差 | 对应的习惯 |
|---|---|---|
| 选标的和数据区间 | 幸存者偏差、近因偏差、本土偏好 | 用 point-in-time 成分股或 ETF，覆盖多种市场环境 |
| 提出假设 | 叙事谬误、后见之明 | 先写假设和预期，再跑回测 |
| 调参 | 锚定、确认偏差、过度自信 | 看参数热力图，留出样本外，记录总共试了多少版本 |
| 评估结果 | 确认偏差、结果偏差 | 好结果和坏结果同样审查；和买入持有基准比 |
| 实盘执行 | 处置效应、损失厌恶、过度交易 | 不手动干预，干预必须记录 |
| 评估实盘 | 结果偏差、沉没成本 | 事先定好评估周期和放弃条件 |

## 交易前自查清单

下单前花一分钟过一遍：

- [ ] 这笔交易在我的计划或系统信号里吗？还是临时起意？
- [ ] 买入理由能用一两句话写下来吗？什么情况会证明我错了？
- [ ] 止损、止盈或退出条件写好了吗？
- [ ] 仓位大小是按规则算的，还是因为「这次很有把握」或「上次亏了要赢回来」？
- [ ] 我是不是因为最近涨了很多（FOMO）或跌了很多（恐慌）才想动？
- [ ] 我看过反方观点吗？
- [ ] 我现在情绪如何？累、生气、刚亏过钱、刚赚了很多，都不是好的下单状态。
- [ ] 如果这笔亏了，我能接受这个金额吗？
- [ ] 这笔交易扣掉成本和税以后还值得做吗？
- [ ] 对长期定投账户：我是不是想因为新闻或数据改变原定计划？如果是，等一周再说。

## 小结

- 心理偏差人人都有，知道它们的名字不会让你免疫，但能帮你识别「这是那种感觉」。
- 最有效的对付方法不是靠意志力，而是**规则和习惯**：事先写计划、自动化定投、少看账户、记交易日志、固定仓位规则。
- 做量化的人要特别注意：偏差会从下单环节转移到系统设计环节，回测结果越好越要怀疑。
- 定投 VOO 本身就是一种对抗心理偏差的设计：自动、分散、不需要判断时机。它最大的敌人是你在大跌时想打破它。
