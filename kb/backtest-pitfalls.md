# 回测里最常见的坑

回测就是拿历史数据模拟「如果当时按这个规则交易，会怎么样」。它很有用，但也很会骗人：写错一行代码、少算一项成本，年化收益就能凭空多出好几个百分点。**回测结果越好看，越应该先怀疑代码有问题。**

下面这些坑按「最常见、最致命」大致排序。代码假设有一个日线 DataFrame `df`，含 `Close` 列，指标的算法见 [常用技术指标用 Python 怎么算](python-quant-indicators.md)。

## 一览

| 坑 | 后果 | 一句话检查 |
|---|---|---|
| 未来函数 | 收益虚高，往往高得离谱 | 信号是否 `shift(1)` 后才用 |
| 幸存者偏差 | 收益虚高 | 股票池里有没有已退市的公司 |
| 过拟合 / 参数挖掘 | 样本内很好，实盘失效 | 参数稍微改一点，结果还好吗 |
| 交易成本和滑点 | 高频策略收益被吃光 | 每笔扣了多少 |
| 复权数据 | 假跳空、假信号 | 用的是不是复权价 |
| 没有样本外验证 | 无法判断是否只是巧合 | 有没有留一段数据完全不碰 |
| 多重检验 | 试了 100 次总有一次「显著」 | 一共试了多少个版本 |
| 没有基准 | 不知道是否比躺平强 | 比 VOO 买入持有好吗 |
| 指标太多 | 规则复杂、自由度高 | 能用一句话说清规则吗 |

## 1. 未来函数（look-ahead bias）

指在某个时间点用到了**当时还不知道的信息**。最典型的情况：用今天收盘价算出信号，又假设按今天收盘价成交，并且吃到了今天的涨跌。

实际上今天的收盘价要等收盘那一刻才确定，信号最早只能在**明天**执行。

**错误写法**：

```python
df["ret"] = df["Close"].pct_change()          # 今天的涨跌幅
df["sma20"] = df["Close"].rolling(20).mean()
df["signal"] = (df["Close"] > df["sma20"]).astype(int)

# 错：用今天收盘才知道的信号，去吃今天的涨跌
df["strat_wrong"] = df["signal"] * df["ret"]
```

这样写，相当于「只要今天会涨到均线上方，就提前持有今天」。今天涨得多的日子更容易让收盘价站上均线，所以收益被系统性地放大。

**正确写法**：

```python
# 对：今天收盘出信号，明天才持仓，吃的是明天的涨跌
df["position"] = df["signal"].shift(1)
df["strat"] = df["position"] * df["ret"]

equity_wrong = (1 + df["strat_wrong"].fillna(0)).cumprod()
equity       = (1 + df["strat"].fillna(0)).cumprod()
print(equity_wrong.iloc[-1], equity.iloc[-1])   # 前者通常大得不合理
```

`shift(1)` 把整列往后挪一天：今天这一行拿到的是**昨天**的信号。

其他隐蔽的未来函数：

- **用全样本统计量做标准化**：比如 `(x - x.mean()) / x.std()`，均值和标准差用到了未来的数据。应该用 `rolling` 或 `expanding`。
- **`bfill()` 向后填充**：就是拿未来的值补过去。
- **基本面数据按报告期对齐**：一季度财报 3 月 31 日截止，但要到 4 月底甚至 5 月才公布。应该按**公布日期**对齐。
- **用最高价、最低价当成交价**：「跌破某价位就按当天最低价买入」，现实中你不可能刚好买在最低点。
- **当天开盘就用当天收盘的信号**：如果打算开盘执行，信号只能用**前一天**及以前的数据。

## 2. 幸存者偏差

如果股票池是「现在的标普 500 成分股」，回测十年，就等于只挑了**活到今天并且表现足够好、被选进指数**的公司。那些期间破产、被收购、被踢出指数的公司都不在里面。结果自然偏乐观。

缓解办法：

- 用**当时**的成分股名单（point-in-time 成分股），这类数据通常要付费。
- 用 ETF 本身（VOO、QQQ 等）做回测对象，指数调仓已经包含在价格里。
- 至少意识到这个偏差，把个股回测结果打个折扣。

yfinance 拿不到已退市股票的数据，所以用它做个股选股回测时，幸存者偏差几乎是一定存在的。

## 3. 过拟合与参数挖掘

把均线参数从 5 试到 200，RSI 阈值从 20 试到 40，止损从 1% 试到 10%……总能找到一组在历史上表现很好的组合。但这组参数很可能只是**恰好贴合了那段历史的噪音**。

判断是否过拟合的几个信号：

- **参数敏感**：最优参数是 47 天，但 45 天和 50 天结果差很多。真正有效的规律附近应该是一片「高原」，而不是一根针。
- **交易次数太少**：十年只交易了 8 次，任何结论都没有统计意义。
- **规则里有很多特殊条件**：「周二不交易」「RSI 在 31.5 到 33 之间」之类，基本都是在拟合噪音。
- **只在某段时间特别好**：收益主要来自某一两次行情。

可以画一张「参数 vs 收益」的热力图，看看最优点周围是否平稳。

## 4. 交易成本与滑点

美股券商普遍零佣金，但交易仍然有成本：

| 成本 | 说明 |
|---|---|
| 买卖价差 | VOO 这类大 ETF 很小，冷门个股可能很大 |
| 滑点 | 下单价和实际成交价的差，市价单、开盘收盘、波动大时更明显 |
| 监管费 | 卖出时有很小的 SEC 费和 FINRA 费 |
| 税 | 应税账户里频繁买卖产生短期资本利得，税率远高于长期 |

简单做法是每次换仓扣一个固定比例：

```python
cost = 0.0005    # 单边 0.05%，按自己的品种调整
trades = df["position"].diff().abs().fillna(0)   # 仓位变化量，0→1 或 1→0 记 1
df["strat_net"] = df["strat"] - trades * cost
```

一个每周换仓的策略，一年约 100 次单边交易，每次 0.05% 就是一年 5%。很多回测年化 15% 的短线策略，扣完成本和税就不如买入持有了。税的影响见 [美国投资账户与税的基本概念](us-investment-accounts-tax.md)。

## 5. 复权数据

股票拆股（比如 1 拆 4）后价格会突然变成原来的四分之一。不复权的数据里，这一天看起来像暴跌 75%，会触发各种止损和信号。分红除息日价格也会小幅下跌。

- yfinance 用 `auto_adjust=True` 得到复权价（同时调整了拆股和分红）。
- 复权价适合算收益率和指标。
- 但复权价的**绝对数值**不是当时真实的成交价。如果规则里有「股价低于 5 美元不买」之类的条件，要用不复权价判断。
- 复权会随着新的分红不断改写历史价格，今天下载的十年前价格和一年前下载的可能不一样，不要把复权价当成固定不变的数据存档后再拼接。

## 6. 样本外与走动式验证（walk-forward）

所有参数都在同一段数据上调出来、又在同一段数据上评估，结果没有意义。至少要做到：

- **留出样本外**：比如 2010–2019 年用来开发，2020 年至今**完全不碰**，最后只测一次。测完再改参数，这段数据就不再是样本外了。
- **走动式验证**：滚动地「用过去 N 年调参，测接下来 1 年」，再往前滑。这样每一段测试结果都是用当时可得的信息做出的。

```python
years = sorted(df.index.year.unique())
for test_year in years[5:]:
    train = df[(df.index.year >= test_year - 5) & (df.index.year < test_year)]
    test  = df[df.index.year == test_year]
    # best_param = optimize(train)
    # result = run(test, best_param)
```

把每一年的测试结果拼起来，才是比较接近实盘的表现。如果走动式结果远差于全样本优化的结果，说明之前的好成绩大多来自过拟合。

## 7. 多重检验

试 20 个毫无用处的策略，按 5% 的显著性标准，平均也会有 1 个看起来「显著有效」。问题在于我们通常只记得那一个成功的，忘了另外 19 个。

应对：

- 记录**一共试了多少个版本**，包括放弃的。
- 试的版本越多，对结果的要求就应该越高（比如 Bonferroni 校正：试了 20 个，显著性门槛从 5% 降到 0.25%）。
- 有一个事前能讲清楚的理由，比事后在数据里找规律更可靠。

## 8. 基准对比：比 VOO 买入持有好吗

一个策略年化 9%，听起来不错。但如果同期 VOO 买入持有年化 12%，这个策略其实是在亏钱——机会成本。每次回测都应该和**同期买入持有**放在一起比：

```python
bench = (1 + df["ret"].fillna(0)).cumprod()
strat = (1 + df["strat_net"].fillna(0)).cumprod()

def summary(eq):
    yrs = (eq.index[-1] - eq.index[0]).days / 365.25
    cagr = eq.iloc[-1] ** (1 / yrs) - 1
    mdd = (eq / eq.cummax() - 1).min()
    return f"年化 {cagr:.1%}  最大回撤 {mdd:.1%}"

print("买入持有", summary(bench))
print("策略    ", summary(strat))
```

比较时看几样东西：年化收益、最大回撤、回撤持续时间、交易次数、税后结果。很多择时策略的真实价值是**回撤更小**而不是收益更高——如果回撤小一半、收益只少一点，对某些人也是值得的，但要说清楚是在用收益换回撤。

还要注意：策略空仓时现金在现实中可以拿到货币基金利息，回测里如果按 0 计算，会低估策略；反过来，用了杠杆或融资却没扣利息，会高估。

## 9. 指标太多

规则里叠了均线、RSI、MACD、布林带、成交量五个条件，每个还有两三个参数，就有十几个自由度。自由度越多，越容易拟合出漂亮的历史曲线，也越难在未来重现。

而且这些指标大多来自同一份收盘价，彼此高度相关，加在一起并没有增加多少新信息。

经验法则：

- 规则能用一两句话说清楚。
- 每加一个条件，都应该有独立的理由，并且在样本外仍然改善结果。
- 交易次数要足够多，至少几十次以上，结论才有点参考价值。

## 回测前的检查清单

1. 所有信号都 `shift(1)` 了吗？有没有用到全样本统计量？
2. 股票池是当时的，还是今天的？
3. 扣了交易成本吗？应税账户考虑税了吗？
4. 用的是复权价吗？价格过滤条件用的是什么价？
5. 留了样本外数据吗？做了走动式验证吗？
6. 一共试了多少个版本？
7. 和 VOO 买入持有比过吗？
8. 参数稍微变一下，结果还稳定吗？

全部过关的策略，实盘表现通常也会比回测差一些。把回测当作「排除坏主意」的工具，而不是「证明好主意」的工具，心态会健康很多。长期来看，大多数人很难稳定跑赢低成本指数基金，见 [指数基金与定投](index-fund-dca.md)。
