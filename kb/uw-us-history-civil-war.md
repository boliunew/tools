# 美国史（二）：西进、奴隶制与南北战争（1800–1877）

## 一句话

**美国一边向西扩张到太平洋，一边被「新土地上要不要有奴隶」这个问题撕裂，最终打了一场让美国人死得最多的战争。**

## 西进扩张

| 年份 | 事件 |
|---|---|
| 1803 | **路易斯安那购地**：杰斐逊从拿破仑手里以 1500 万美元买下密西西比河以西的大片土地，国土面积翻倍 |
| 1804–1806 | 刘易斯与克拉克探险到达太平洋 |
| 1812–1815 | **1812 年战争**：和英国再打一仗，白宫被烧，国歌《星条旗》由此而来 |
| 1819 | 从西班牙手里得到佛罗里达 |
| 1823 | **门罗主义**：欧洲不得再干涉美洲 |
| 1830 | **《印第安人迁移法》**：杰克逊总统把东南部的切罗基等部落强制迁往西部，途中数千人死亡，称为**「血泪之路」** |
| 1845 | 兼并德克萨斯；「**昭昭天命**」（Manifest Destiny）：认为美国注定要扩张到整个大陆 |
| 1846–1848 | **美墨战争**：美国获得加州、内华达、犹他、亚利桑那、新墨西哥等地 |
| 1848–1855 | **加州淘金热**，1850 年加州成为第 31 个州 |
| 1862 | 《宅地法》：在西部定居五年就可免费得到 160 英亩土地 |
| 1869 | **横贯大陆铁路**在犹他州接通（西段大量华工参与修建） |

## 奴隶制：越来越尖锐的分裂

- 到 1860 年，南方约有 **400 万奴隶**，棉花是美国最大的出口商品，奴隶的「资本价值」超过全国铁路和工厂的总和。
- 北方逐步废除了奴隶制，工业化、移民涌入；南方依赖种植园经济。
- 每当新领土要建州，就要争论它是**蓄奴州还是自由州**，这关系到参议院里南北的力量平衡：

| 年份 | 事件 |
|---|---|
| 1820 | **密苏里妥协**：北纬 36°30′ 以北（密苏里除外）禁止奴隶制 |
| 1850 | **1850 年妥协**：加州作为自由州加入，同时通过严厉的《逃亡奴隶法》，北方人必须协助抓捕逃奴 |
| 1852 | 斯托夫人《汤姆叔叔的小屋》出版，在北方引起巨大反响 |
| 1854 | 《堪萨斯—内布拉斯加法》让当地居民自己决定，引发「流血的堪萨斯」；反奴隶制的**共和党**成立 |
| 1857 | **德雷德·斯科特案**：最高法院裁定黑人不是公民，国会无权在领土上禁止奴隶制 |
| 1859 | 约翰·布朗袭击哈珀斯费里军火库，想发动奴隶起义 |
| 1860 | **林肯**当选总统，他反对奴隶制扩张。南卡罗来纳等州随即宣布脱离联邦 |

## 南北战争（1861–1865）

- 1861 年 4 月南军炮击萨姆特堡，战争爆发。南方 11 个州组成「**美利坚联盟国**」，杰斐逊·戴维斯任总统。
- 北方人口、工业、铁路远超南方；南方有优秀的将领（罗伯特·李）和防守的优势。
- **1863 年**：
  - 1 月 1 日林肯发布**《解放奴隶宣言》**，宣布叛乱州的奴隶获得自由，黑人可以参加北军（最终约 18 万黑人士兵参战）；
  - 7 月**葛底斯堡战役**是转折点；
  - 11 月林肯发表**葛底斯堡演说**：「民有、民治、民享的政府不会从地球上消失」。
- 1864 年谢尔曼「向大海进军」，焦土战术。
- **1865 年 4 月**李将军在阿波马托克斯投降；几天后林肯被刺杀。
- 死亡人数约 **60 万到 75 万**，超过美国在其他所有战争中死亡人数的总和（按人口比例更是如此）。

## 重建时期（1865–1877）

- 三条修正案：
  - **第 13 修正案**（1865）废除奴隶制；
  - **第 14 修正案**（1868）出生公民权和平等保护；
  - **第 15 修正案**（1870）不得因种族剥夺投票权。
- 联邦军队驻扎南方，黑人第一次参与政治，有人当选国会议员。
- 同时**三K党**兴起，对黑人和支持重建的人施加暴力。
- **1877 年妥协**：为解决有争议的总统选举，共和党同意从南方撤军，重建结束。
- 之后南方各州通过**「吉姆·克劳法」**：种族隔离、人头税和识字测试剥夺黑人投票权，私刑泛滥，这种状况一直持续到 1960 年代民权运动。

## 不同的解释

- **战争的原因**：历史学界主流认为核心原因是**奴隶制**，南方各州的脱离声明里明确写着。战后南方流行的「**败局命定**」（Lost Cause）叙事则说战争是为了「州权」和南方生活方式，弱化奴隶制，这一说法被大多数历史学家否定，但影响了很多纪念碑和教科书。
- **林肯的形象**：他是「伟大的解放者」，还是首先为了维护联邦、后来才把废奴当作目标？两者都有依据，他的立场在战争中逐渐变化。
- **重建为什么失败**：北方厌战、经济危机（1873）、种族偏见、南方白人的暴力抵抗，以及联邦政府不愿长期驻军。杜波依斯《黑人的重建》（1935）最早系统地为重建的成就正名。

## 常见误解

- **「北方人都是废奴主义者」**：北方很多人反对奴隶制扩张，但也歧视黑人，纽约 1863 年还发生了反征兵、攻击黑人的暴动。
- **「《解放奴隶宣言》一下子解放了所有奴隶」**：它只适用于叛乱州，边境蓄奴州不包括在内；真正废奴靠的是第 13 修正案。
- **「美国是一点一点和平地扩张的」**：每一步都伴随着对原住民的战争、驱逐和对墨西哥的战争。

- 如果一个国家的经济建立在一种不道德的制度上，它能和平地放弃吗？
- 1850 年加州作为自由州加入联邦，为什么会是全国的大事？
- 战争打赢了，但重建失败了。打赢一场战争和赢得和平，哪个更难？
