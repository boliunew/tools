# 美国史（五）：21 世纪的美国（2000–2026）

## 一句话

**冷战胜利后的自信被一连串冲击打碎：恐袭、战争、金融危机、疫情；与此同时科技公司让美国更富，社会和政治却越来越分裂。**

> 越接近现在，历史学家越难给出定论。这一篇以事实为主，评价部分把主要的不同看法都列出来。最新动态看 [📰 新闻](../news.html)。

## 时间线

|---|---|

| 2001.9.11 | **「9·11」恐怖袭击**：基地组织劫持客机撞击世贸中心和五角大楼，近 3000 人死亡 |

| 2013 | 斯诺登揭露国安局大规模监控 |

| 2016 | **特朗普**当选，赢得选举人团但普选票较少 |
| 2017 | 减税法案（TCJA）；退出巴黎气候协定 |
| 2018–2019 | 中美贸易战；特朗普第一次被弹劾（参议院未定罪） |
| 2020 | **新冠疫情**：到 2023 年美国约 110 多万人死亡；失业率一度升到约 15%；数万亿美元的纾困；乔治·弗洛伊德之死引发全国抗议 |
| 2020 | **拜登**当选；特朗普拒绝承认败选 |
| 2021.1.6 | **国会山事件**：特朗普的支持者冲进国会大厦，试图阻止认证选举结果；特朗普第二次被弹劾（参议院未定罪） |

| 2022 | 最高法院推翻罗诉韦德案，堕胎问题交回各州；俄乌战争爆发，美国大规模援助乌克兰；ChatGPT 发布，AI 热潮开始 |
| 2023 | 硅谷银行倒闭 |
| 2024 | 特朗普在宾州竞选集会上遭枪击受伤；拜登退选，副总统哈里斯接替；**特朗普再次当选**，并赢得普选票 |
| 2025 | 特朗普第二任期：洛杉矶山火（1 月）；「政府效率部」大规模削减联邦机构；对多国大幅加征关税（4 月「解放日」关税）；大规模移民执法，6 月洛杉矶抗议和国民警卫队部署；《大而美法案》（7 月）；空袭伊朗核设施（6 月）；10–11 月联邦政府关门 43 天，是历史上最长的一次 |
| 2026 | 最高法院裁定总统不能依据《国际紧急经济权力法》征收关税（2 月），政府改用其他法律继续征收部分关税；美以对伊朗开战（2 月起，见中东篇）；最高法院维持出生公民权（6 月）；美国建国 250 周年（7 月 4 日）；11 月中期选举 |

## 几条主线

1. **反恐战争的代价**：阿富汗和伊拉克战争花费数万亿美元，美军死亡七千多人，当地死亡人数远多于此；战争的结果让很多美国人对海外干预失去信心，这种情绪左右两边都有。
2. **金融危机的长期影响**：救银行不救房主的愤怒，同时催生了左翼的「占领华尔街」和右翼的「茶党」运动，是民粹政治兴起的重要背景。
3. **科技和不平等**：苹果、微软、谷歌、亚马逊、Meta、英伟达成为全球市值最高的公司；硅谷和沿海城市繁荣，部分内陆制造业地区衰退（「中国冲击」，见[《国际贸易》](uw-econ-trade.md)）。
4. **政治极化**：两党选民在价值观、住地、媒体来源上越来越分化（见[《美国政治》](uw-politics-us-system.md)）；社交媒体放大了这一趋势。
5. **对华关系**：从「接触」（2001 年支持中国入世）转向「竞争」，两党在这一点上基本一致，在方法上有分歧。
6. **人口和社会**：老龄化、移民、少数族裔比例上升（预计 2040 年代白人将不再占多数）、阿片类药物危机（每年死亡数万人）、住房负担能力（加州尤其严重）。

## 不同的解释

- **特朗普现象**：
  - 一种解释强调经济原因：全球化和制造业衰退中被抛下的人；
  - 一种解释强调文化原因：对移民、社会变化和精英的反感；
  - 支持者认为他代表了被忽视的普通人，挑战了失败的建制派；
  - 批评者认为他削弱了民主规范和法治。
  - 研究者大多认为经济和文化因素都起作用，比例有争论。
- **美国在衰落吗？**
  - 「衰落论」：相对实力下降、政治失能、债务高企；
  - 「韧性论」：美国在科技、大学、资本市场、人口结构、地理安全上仍有巨大优势，过去几十年「衰落论」已经出现过好几次。
- **政府角色的钟摆**：
  - 2008 年和 2020 年两次危机后，政府干预大幅增加；
  - 2025 年后又转向削减联邦机构，同时加强关税和产业干预；
  - 「大政府 vs 小政府」的旧划分不太能描述新的政治格局。

## 常见误解

- **「美国一直是两党温和竞争的」**：今天的极化程度在 20 世纪中后期是少见的，但在 19 世纪末和内战前，美国政治也曾极度分裂。
- **「经济好不好主要看总统」**：美联储、国会、全球经济、技术周期的影响往往更大。
- **「这些事都是新闻，不是历史」**：今天的新闻就是明天的历史，学会把新闻放进长时段里看，是读历史最大的用处。
