# FBA 箱子、标签和托盘

亚马逊仓收货是流水线作业：扫码、分拣、上架都靠机器和条码。所以规矩定得很死。一个箱标贴错位置、一个托盘超高，就可能被拒收或者被罚款。

> 下面是美国站的主要要求，来自亚马逊给卖家的发货指南。规则偶尔会调整，以卖家后台的最新说明为准。

## 箱子

| 要求 | 数字 |
|---|---|
| 单箱重量（装多件标准尺寸商品） | **不超过 50 磅**（约 22.7 公斤） |
| 单箱尺寸（装多件标准尺寸商品） | **任何一边不超过 25 英寸**（约 63.5 厘米） |
| 珠宝、手表箱 | 不超过 40 磅 |
| 单件大件商品超过 50 磅 | 箱子顶上和侧面贴 **Team Lift**（两人搬）标签 |
| 单件大件商品超过 100 磅 | 箱子顶上和侧面贴 **Mech Lift**（要叉车）标签 |

**其他要点**：

- 用结实、六面完整、盖子能封好的纸箱。旧箱子上原来的条码、面单要全部撕掉或盖住。
- 箱里要塞满，摇晃时不能有东西在里面滑动。
  - **可以用的填充物**：气泡膜、整张的纸、充气袋、泡沫板。
  - **不能用的**：各种泡沫颗粒（packing peanuts）、碎纸、皱纹填充纸、泡沫塑料块。
- 混装箱（一箱好几种 SKU）可以，但要在后台准确填写**箱内信息**（每箱装了什么、几件）。不填或填错，亚马逊会按件收人工处理费。

## 商品标签：FNSKU

- **每一件商品**都要有一个能扫的条码，一般就是 FNSKU 标签。只有品牌所有者符合条件的商品，才能用原厂条码。2026 年起亚马逊不再代贴，必须到仓前贴好。
- **一件商品上只能露出一个能扫的条码**。贴了 FNSKU，就把原来的 UPC、EAN 条码盖住，不然扫出来对不上。
- 标签要平整、不卷边，别贴在弯曲的边角或接缝上。
- **套装**（几样东西一起卖）要标明「Sold as set」或「Do not separate」，免得被拆开当成几件。
- **塑料袋包装**：
  - 袋子要够厚（至少 1.5 mil）；
  - 开口 5 英寸以上的，要印窒息警告。
- **有保质期的商品**：单件和外箱都要清楚标出到期日，格式和字号有规定。

## 箱标：FBA 箱号标签

- 每个货件生成一套**箱标**，**每箱一张、每张都不一样**（货件号 + 箱号）。**千万不能把同一张复印贴在好几箱上**。一复印，系统就认不出哪箱是哪箱，丢箱也查不清。
- 贴在箱子的**侧面**，不要贴在封箱胶带的接缝上，因为开箱时会被割坏。
- 快递派的箱子：箱标离箱子边缘至少 1.25 英寸。快递面单和 FBA 箱标都要露出来，**谁也别盖住谁**。
- 用过的旧箱子，旧箱标和旧面单要全部去掉。

## 托盘（卡派）

| 要求 | 数字 |
|---|---|
| 托盘尺寸 | **40 × 48 英寸**，四面都能进叉车的木托盘 |
| 总高度（含托盘本身） | **不超过 72 英寸**（约 1.83 米） |
| 总重量 | **不超过 1,500 磅**（约 680 公斤） |
| 货物超出托盘边缘 | 不超过 1 英寸 |
| 托盘标签 | **每个托盘 4 张，四个侧面各一张**，贴在侧面上方居中 |

**打托的要点**：

- **重箱在下、轻箱在上**，箱子码整齐、交错压缝，顶面尽量平。
- 用缠绕膜裹紧。最好用**透明的**膜，箱标要能看得见。外面贴上「Do not break stretch wrap / Do not break down」（请勿拆膜）的提示。
- 托盘本身要完好：断板、缺块的托盘会被拒。
- 一个托盘尽量只放同一个货件的箱子。混放的话，拆托分货时容易出错。

## 出库前检查清单

- [ ] 每件商品都有 FNSKU，其他条码都盖住了
- [ ] 每箱一张**不同**的箱标，贴在侧面、没贴在接缝上
- [ ] 箱数、每箱件数和后台填的箱内信息一致
- [ ] 每箱不超过 50 磅、边长不超过 25 英寸（超了贴 Team Lift / Mech Lift）
- [ ] 托盘 40×48、高不过 72 英寸、重不过 1,500 磅
- [ ] 每个托盘四面都贴了托盘标，缠绕膜裹紧
- [ ] BOL 上写好 PRO 号、托盘数、箱数、预约号（ISA），整车的还要写铅封号
- [ ] 拍照留证：每个托盘四面、箱标特写、装车后的车厢、铅封
