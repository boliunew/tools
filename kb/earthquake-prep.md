# 地震准备：南加州版

住在 Upland，北边就是 San Gabriel 山，脚下和周围有好几条断层。大地震什么时候来没人能预测，但「来了以后能不能少受伤、少慌乱、几天内自己撑得住」，是现在就能准备的。这篇按「之前 → 摇的时候 → 之后」的顺序讲。

> 下面是一般性的准备建议。官方信息看 **加州地震预警（earthquake.ca.gov）**、**San Bernardino County 应急办公室（oes.sbcounty.gov）**，燃气、保险的具体做法以 SoCalGas 和 CEA（加州地震局）官网为准。

## Upland 周围的断层

| 断层 | 大概位置 | 为什么跟你有关 |
|---|---|---|
| **Cucamonga 断层** | 沿 San Gabriel 山南麓，经过 Claremont、Upland、Rancho Cucamonga 北边，长约 30 公里 | 就在家门口。属于逆冲断层，Caltech 南加州地震数据中心（SCEDC）估计可能发生 **6.0–7.0 级** 地震 |
| **Red Hill（Etiwanda Avenue）断层** | Etiwanda、Alta Loma、Upland 一带，长约 25 公里 | 同样是逆冲断层，SCEDC 估计可能 6.0–7.0 级 |
| **San Jacinto 断层带** | 从 San Bernardino、Loma Linda 往东南延伸到 Hemet、Anza，全长约 210 公里 | 南加州最活跃的断层之一，可能 6.5–7.5 级 |
| **San Andreas 断层** | 经过 Cajon Pass（15 号公路上山那段），离 Upland 几十公里 | 最出名的一条。南段一旦大破裂，整个 Inland Empire 都会剧烈摇晃，长时间断路、断水、断电 |

本地也不是没震过：**1990 年 2 月的 Upland 地震**（约 5.5 级，震中在 Upland 西北、Claremont 附近）就让这一带不少房子受损，1988 年还有一次稍小的。

一句话：**住在这里，大地震是「迟早」的问题，而且离断层近的地方几乎来不及收到预警**。所以准备重点是「动作反射」和「物资储备」，而不是指望预警。

## 摇的时候：Drop, Cover, Hold On

这是加州官方一直在推的动作，每年 10 月的 **Great California ShakeOut** 全州演练就是练这个（2026 年是 **10 月 15 日上午 10:15**）。

1. **Drop（趴下）**：立刻趴到地上，手和膝盖着地。站着很可能被晃倒。
2. **Cover（掩护）**：钻到结实的桌子底下；附近没有桌子，就靠着内墙、远离窗户，用手臂护住头和脖子。
3. **Hold On（抓牢）**：抓住桌腿，桌子移动你也跟着移动，**直到摇晃停止**。

几个常见误区：

- **不要往外跑**。很多伤是在跑的路上被掉下来的玻璃、外墙、招牌砸到的。
- **不要躲门框下**。现在的房子门框并不比别处结实，门还会来回撞。
- 在床上：**留在床上**，用枕头护住头，比摸黑下床踩到碎玻璃安全。
- 在厨房：远离炉子、冰箱、挂柜。

### 在车里

- 打双闪，**慢慢减速靠边停**，避开**立交桥、天桥、高架、电线杆和电线、大树、建筑物**。
- 拉手刹，**留在车里**，系着安全带等摇完。车身能挡住一部分掉落物。
- 摇完以后再慢慢开，注意路面裂缝、掉落物和塌陷的匝道。高速上要特别小心桥和高架。

### 在堆场 / 仓库上班的时候

在物流堆场工作，周围危险物比一般办公室多：

- **远离集装箱堆垛、货架（racking）、托盘堆、高处的照明灯杆**。堆两三层的空箱、没扣好的货架，晃起来都可能倒或者掉东西。
- 在开阔场地：**往没有堆垛、没有电线、没有建筑物的空地走几步，然后蹲低护头**，别往堆垛之间的通道里钻。
- 正在开**场内拖车（yard truck / hostler）或叉车**：停车、拉手刹，叉车把货叉放到地面，人留在驾驶室里护头，等摇完。
- 在仓库里面：远离货架，躲到结实的工作台下或者内墙边。
- 摇完以后，**按公司的应急程序去集合点**报到，别自己跑去看货。堆垛、货架在余震时可能二次倒塌。
- 平时留意公司的应急集合点在哪、灭火器和急救箱在哪。不清楚就问主管。

## 摇完以后

**先检查自己和身边的人**，有人受伤先止血、别乱搬动伤者。然后：

- **穿上鞋**。地上很可能有碎玻璃。床边放一双旧鞋和手电，是最便宜有效的准备。
- **闻有没有燃气味**（像臭鸡蛋），听有没有「嘶嘶」漏气声：
  - **只有闻到气味、听到漏气声、或看到其他漏气迹象，并且自己安全时**，才去关燃气总阀。SoCalGas 的做法是：用一把 **12 英寸或更大的活动扳手**，把表前阀门转 **1/4 圈**，让阀门方向和管子**垂直**（横过来）。
  - **没有漏气就不要关**。关了以后**不能自己再打开**，要等 SoCalGas 派人来开阀、检查、重新点火，大地震后可能要等很多天，期间没热水、不能做饭。
  - 闻到燃气时：别开关电灯、别打火、别用手机（到屋外远处再打电话），赶紧出去。
  - 平时就先找好表在哪、阀门是哪个，把扳手**绑在表旁边或放在固定位置**。
- **注意余震**。大地震后几分钟到几天甚至更久都会有余震，有的也很大。每次余震照样 Drop, Cover, Hold On。
- **看房子结构**：墙有大裂缝、房子歪了、烟囱塌了，先别进去。
- **电线断了的地方离远点**。停电时用手电，**不要用蜡烛**（燃气泄漏 + 明火很危险）。
- **少打电话、多发短信**。通信网会被挤爆，短信更容易发出去。
- **听官方消息**：手机警报、电台、San Bernardino County 和 Upland 市的官方账号。

## 手机地震预警：MyShake 和 Wireless Emergency Alerts

加州的地震预警系统叫 **ShakeAlert**（由 USGS 运营）。地震开始后，地面传感器先探测到，系统算出大概震级和哪些地方会摇，赶在强烈摇晃到达之前把警报推到手机上。

| 途径 | 怎么收到 | 什么情况下会响 |
|---|---|---|
| **MyShake App**（加州官方，iPhone / Android 都有，免费） | 下载 App，**位置权限设成「始终允许」** | 大约 **4.5 级以上**、你所在地点预计有**轻微（MMI III）及以上**震感 |
| **Android 系统自带地震警报** | 安卓手机自带，无需下载，打开定位即可 | 用同一套 ShakeAlert 数据 |
| **Wireless Emergency Alerts（WEA，无线紧急警报）** | 手机系统自带，不用装任何东西 | 门槛更高，大约 **5.0 级以上**的地震才会发给受影响区域 |

要知道的局限：

- **离震中很近时几乎没有预警时间**。Cucamonga 断层要是在家门口破裂，警报可能和摇晃同时到，甚至更晚。预警是「多几秒」，不是「提前几分钟」。
- 收到警报不用想，**直接 Drop, Cover, Hold On**。开车的人慢慢减速靠边。
- iPhone 用户可以去「设置 → 通知 → 政府警报」确认紧急警报是开着的。

## 应急物资：72 小时是底线，两周更稳

大地震后，水管、道路、商店可能好几天甚至更久不能恢复。官方一般建议至少准备 **3 天**，能做到 **2 周**更好。

### 合租屋（全屋共用）

和室友住的话，最好**开一次小会**：谁出什么、放在哪、钱怎么分。共用的大件放在门口附近容易拿的地方。

- [ ] **水**：每人每天约 **1 加仑**（饮用 + 简单清洁）。4 个人 2 周就是 56 加仑，不现实的话至少先备 3 天，再加净水片或过滤器
- [ ] **不用做饭的食物**：罐头（带拉环，或备手动开罐器）、能量棒、坚果、饼干、即食米饭；**宠物的粮和水**也算上
- [ ] **手电筒 + 头灯**，每人一个，加备用电池
- [ ] **充电宝**（定期充满）、车载充电线、有条件的话小型太阳能板或便携电源
- [ ] **电池或手摇收音机**（停电断网时听广播）
- [ ] **急救包**、各人自己的常用药（至少一两周量）、备用眼镜
- [ ] **工作手套、口罩（N95）**、垃圾袋、胶带、扎带
- [ ] **燃气扳手**（放在表旁边）、灭火器
- [ ] 卫生用品：湿巾、卫生纸、免洗洗手液；**马桶不能冲时**的应急方案（大垃圾袋套马桶 + 猫砂或除臭剂）
- [ ] **现金**（小面额）：停电时刷卡机、ATM 都可能不能用
- [ ] 重要证件复印件或加密备份：身份证件、保险单、租房合同、银行卡联系方式

### 车里

上下班在车里的时间长，地震时可能被困在路上或公司：

- [ ] 1–2 加仑水、几根能量棒
- [ ] 一双**舒服的步行鞋**和一件外套（可能要走回家）
- [ ] 手电、充电线、小急救包
- [ ] 纸质地图或离线地图（手机没网时）
- [ ] 油箱**尽量不低于一半**：大地震后加油站可能排长队或没电加不了

### 工作柜子 / 储物柜

- [ ] 一瓶水、几根能量棒
- [ ] 常用药、备用眼镜
- [ ] 手电、充电宝
- [ ] 一张写着家人和室友电话的纸卡（手机没电时用）

> 物资不是买一次就完事。**每年定个日子**（比如每年 10 月 ShakeOut 演练那天）检查一遍：换掉过期的水和食物、给充电宝充电、换电池。

## 家里能做的固定工作

很多地震伤害不是房子塌了，而是**东西倒了、掉了**。

- **高的家具**（书柜、衣柜、电视柜）用防倾倒绑带或 L 型支架**固定到墙里的木龙骨（stud）上**。
- **电视**用绑带固定，或者挂墙。
- **床头上方**不要挂相框、镜子、重的架子。
- 重的东西放**低处**，玻璃和易碎品放下层或带门的柜子，柜门可以装儿童安全扣防止甩开。
- **热水器**：加州要求热水器做抗震固定，通常是**上下两道金属绑带**固定到墙体结构上，防止倒下扯断燃气管和水管。租房的话，看一眼你家热水器有没有绑带，没有就告诉房东。大地震后，热水器里那几十加仑水也是应急水源。
- 知道**水总阀**、**电闸箱**、**燃气表**在哪。
- 租房住的：钻墙之前先问房东，很多防倾倒支架只需要很小的螺丝孔。

## 家人和室友的联络计划

大地震后，你很可能在上班，家人在别的地方，电话打不通。提前定好：

1. **一个外州联系人**：本地电话网拥堵时，打长途或发短信到外州反而容易通。大家都向这个人报平安。在国内的家人也可以当这个角色，约好用微信或短信报平安。
2. **两个集合点**：一个在家附近（比如街角某个空地），一个在社区外（比如某个亲友家）。
3. **每个人手机里**存好彼此电话，同时**写在纸上**放在钱包和工作柜子里。
4. 合租的话，至少交换一下**紧急联系人**，知道谁有什么常用药、谁有宠物。

## 地震险：普通房屋险 / 租客险一般不管地震

很多人以为买了 renters insurance（租客险）或 homeowners insurance（房屋险）就够了，其实**标准保单一般不赔地震造成的损失**。地震险要另外买。

在加州，地震险主要通过 **CEA（California Earthquake Authority，加州地震局）** 提供，由合作的保险公司代卖，联系你现在的房屋险或租客险公司 / 经纪人就能加。

**CEA 租客地震险**（以 CEA 官网当前说明为准）：

| 项目 | 内容 |
|---|---|
| 个人财物（Coverage C） | 可选 **$5,000 或 $25,000** |
| 财物自付额 | 财物保额的 **5%–25%** 可选（比例越高，保费越低） |
| 额外居住费用（Loss of Use，房子不能住时的临时住宿等） | 多档可选，**这一项没有自付额** |
| 价格 | CEA 称**最低每年几十美元起**，具体看地址和所选自付额 |

几点要明白：

- 地震险的自付额是**按百分比**算的，小地震造成的小损失往往到不了自付额。它主要是防「大震后东西全毁、几个月没地方住」这种情况。
- 对租客来说，**Loss of Use 那一项可能最有用**：房子被判不能住时，临时住宿的钱可以从这里出。
- **房子本身的结构损坏是房东的事**，租客买的地震险只管你自己的东西和临时住宿。
- 汽车的地震损坏一般走车险里的**综合险（comprehensive）**，不是地震险，看你自己的车险条款。见 [在加州开车要知道的](california-driving-basics.md)。

想算算价格，可以用 CEA 官网的保费计算器。

## 一张检查清单

- [ ] 手机装好 MyShake，位置设为「始终允许」；确认手机紧急警报开着
- [ ] 床边放鞋和手电
- [ ] 找到燃气表、阀门、扳手；找到水总阀和电闸
- [ ] 全屋应急水和食物至少 3 天，目标 2 周
- [ ] 车里、工作柜子各一份小应急包
- [ ] 高家具、电视固定；确认热水器有绑带
- [ ] 定好外州联系人和集合点，纸上也写一份
- [ ] 问清公司的地震应急程序和集合点
- [ ] 想清楚要不要加 CEA 地震险
- [ ] 每年 ShakeOut 那天检查一遍物资
