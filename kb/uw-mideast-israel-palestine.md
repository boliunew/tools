# 中东（二）：以色列和巴勒斯坦——两个民族、一块土地

## 一句话

**两个民族都把这块土地视为自己的家园，都有深刻的历史创伤和安全恐惧；百年来战争、占领、恐袭和失败的和谈层层叠加，使它成为世界上最难解的冲突之一。**

## 来龙去脉

| 时间 | 事件 |
|---|---|
| 19 世纪末 | 欧洲反犹浪潮中兴起**犹太复国主义**（锡安主义），赫茨尔主张在古代以色列之地建立犹太国家；当时这里是奥斯曼帝国的一部分，居民以阿拉伯人为主 |
| 1917 | 英国《贝尔福宣言》支持在巴勒斯坦建立「犹太民族家园」，同时承诺不损害非犹太社群的权利 |
| 1920–1948 | **英国托管巴勒斯坦**；犹太移民增加，尤其是纳粹上台后；阿拉伯人起义（1936–1939），双方冲突不断 |
| 1939–1945 | 纳粹**大屠杀**杀害约六百万犹太人，强化了建立犹太国家的国际支持 |
| 1947 | 联合国**分治决议**（181 号）：分成犹太国和阿拉伯国，耶路撒冷国际共管。犹太人接受，阿拉伯国家和巴勒斯坦领导层拒绝 |
| 1948 | **以色列建国**，周边阿拉伯国家出兵，以色列获胜并控制了比分治方案更多的土地。约七十万巴勒斯坦人逃离或被驱逐，巴勒斯坦人称为**「纳克巴」（大灾难）**。之后数十万犹太人从阿拉伯国家离开或被驱逐，多数移居以色列 |
| 1964 | **巴勒斯坦解放组织（巴解）** 成立，后由阿拉法特领导 |
| 1967 | **六日战争**：以色列占领**约旦河西岸、东耶路撒冷、加沙地带**、戈兰高地和西奈半岛。联合国 242 号决议提出「以土地换和平」 |
| 1973 | 第四次中东战争（赎罪日战争） |
| 1978–1979 | **戴维营协议**，埃及和以色列建交，以色列归还西奈 |
| 1987 | 第一次巴勒斯坦**大起义**；同年**哈马斯**成立 |
| 1993–1995 | **奥斯陆协议**：以色列和巴解互相承认，建立巴勒斯坦权力机构，在西岸和加沙部分地区自治 |
| 1995 | 以色列总理拉宾被以色列极端分子刺杀 |
| 2000 | 戴维营谈判破裂；第二次大起义，大量自杀式爆炸和军事打击 |
| 2005 | 以色列从加沙撤出定居点和军队 |
| 2007 | 哈马斯在内斗中控制**加沙**，法塔赫控制西岸；以色列和埃及对加沙实施封锁 |
| 2008–2021 | 加沙和以色列之间多轮战争 |
| 2020 | **亚伯拉罕协议**：阿联酋、巴林、摩洛哥、苏丹与以色列关系正常化 |
| 2023.10.7 | 哈马斯突袭以色列南部，约 1200 人被杀（多为平民），约 250 人被劫为人质，是以色列建国以来单日死亡最多的一天 |
| 2023–2025 | **加沙战争**：以色列大规模轰炸和地面进攻。加沙卫生部门统计的死亡人数到 2026 年中超过七万，大部分人口流离失所，出现严重人道危机；国际法院受理了南非对以色列的种族灭绝指控，国际刑事法院 2024 年 11 月对以色列总理内塔尼亚胡、前防长加兰特和哈马斯军事领导人戴夫发出逮捕令。冲突外溢到黎巴嫩、也门、伊朗 |
| 2025.10 | 在美国推动下加沙**停火**生效，人质和被关押者陆续交换。但到 2026 年，以色列仍控制加沙相当大的区域，暴力事件不断，重建和加沙未来的治理安排进展有限，人道组织批评停火「名存实亡」 |

> 2023 年以后的数字和事态还在变化，最新情况看 [🌍 国际局势](../news.html#world)。

## 核心争议

1. **边界**：以 1967 年战前的停火线为基础吗？
2. **定居点**：以色列在西岸建了大量犹太定居点，住着约五十万人（不含东耶路撒冷）。国际上多数国家和联合国认为它们违反国际法，以色列政府有不同看法。
3. **耶路撒冷**：双方都想以它为首都。2017 年美国承认耶路撒冷为以色列首都。
4. **难民回归**：数百万巴勒斯坦难民及其后代是否有权回到以色列境内的故土。
5. **安全**：以色列要求巴勒斯坦国非军事化、控制边境；巴勒斯坦人认为这等于没有主权。
6. **相互承认**：哈马斯宪章（2017 年修改过）长期不承认以色列；以色列现任政府中也有人公开反对巴勒斯坦建国。

## 主要方案

- **两国方案**：以色列和巴勒斯坦国并存。国际主流立场，但近年双方民众支持度下降，定居点扩大让它越来越难。
- **一国方案**：一个国家里所有人平等，但对「犹太国家」和「民主国家」的定义冲突。
- **维持现状**：被批评为无限期的占领和冲突。

## 不同的叙述

| 以色列方面常强调的 | 巴勒斯坦方面常强调的 |
|---|---|
| 犹太人在这片土地上有三千年的历史和联系 | 巴勒斯坦人世代居住在此，1948 年失去家园 |
| 大屠杀之后需要一个能自我保护的国家 | 欧洲的罪行不应由巴勒斯坦人来承担 |
| 阿拉伯国家多次发动战争要消灭以色列 | 1967 年后的占领、定居点、检查站和封锁是日常的压迫 |
| 自杀式袭击、火箭弹、10·7 屠杀说明安全威胁是真实的 | 加沙的大量平民死亡和人道灾难是不成比例的集体惩罚 |
| 以色列多次提出和平方案被拒绝 | 提出的方案并不能构成一个真正有主权的国家 |

此外，以色列国内有和平派也有右翼，巴勒斯坦内部有法塔赫和哈马斯的分裂，阿拉伯国家也各有算盘。以「正义一方对邪恶一方」看这场冲突，往往会错过很多事实。

## 常见误解

- **「这是几千年的宗教战争」**：现代冲突主要是 19 世纪末以来的民族和土地冲突，宗教是重要身份但不是唯一原因。
- **「哈马斯代表所有巴勒斯坦人」**：巴勒斯坦权力机构由法塔赫主导，两者长期对立；加沙民众的态度也很复杂。
- **「批评以色列政府就是反犹」「支持以色列就是不在乎巴勒斯坦人」**：政策批评、民族仇恨、人道关切是不同的事，要分开来看。

## 延伸阅读

- 本尼·莫里斯《正义的受害者》（以色列「新历史学家」之一）
- 拉希德·哈立迪《巴勒斯坦百年战争》（巴勒斯坦学者视角）
- 阿莫斯·奥兹《爱与黑暗的故事》（以色列作家的自传体小说）
- 丹尼斯·罗斯《失落的和平》（美国谈判代表回忆）
- 两本放在一起读，比只读一本更接近真实
