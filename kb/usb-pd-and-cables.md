# USB-C 充电头和线怎么选

USB-C 只是**接口的形状**。同样长这个样子，里面能跑多大功率、多快的数据、能不能出视频，差别非常大。分清楚三件事就够用了：**充电协议**、**线能扛多大电流**、**线能跑多快的数据**。

## 充电协议：PD 和 PPS

**USB PD**（Power Delivery）是现在的通用快充标准。手机、笔记本、iPad、Switch 都用它。充电头和设备先「商量」，再从固定的几档电压里选一档：

| 电压 | 最大电流 | 最大功率 | 典型用途 |
|---|---|---|---|
| 5V | 3A | 15W | 所有设备的起步档 |
| 9V | 3A | 27W | 手机快充 |
| 15V | 3A | 45W | 平板、小笔记本 |
| 20V | 3A / 5A | 60W / 100W | 笔记本 |
| 28V / 36V / 48V | 5A | 140W / 180W / 240W | 大功率笔记本（PD 3.1 新增，叫 EPR） |

**PPS**（可编程电源）是 PD 3.0 里的一个可选功能：电压不再是固定几档，可以按 20 毫伏一小步微调。电压贴着电池需要的走，手机里发热少，所以充得更稳、更快。

**三星的「超级快充」就是 PPS：**

| 三星的叫法 | 功率 | 需要什么 |
|---|---|---|
| 快速充电（Adaptive Fast Charging） | 15W | 老式三星头就行 |
| 超级快充（Super Fast Charging） | 25W | 支持 **PD + PPS** 的充电头，普通 3A 的 C-to-C 线 |
| 超级快充 2.0 | 45W | 支持 **PPS 且能出 5A** 的充电头 + **5A 的线** |

S23 Ultra 支持 45W。只要充电头或线有一样不达标，就会退回 25W 甚至 15W。手机充电时屏幕上会显示「超级快充」或「超级快充 2.0」，可以用来确认。

> 其实 25W 和 45W 在日常使用里差别没有数字上那么大：从低电量充到一半，两者只差几分钟。电池越热充得越慢，夏天在车里尤其明显。

**Quick Charge（QC）** 是高通的私有协议。旧安卓手机和很多车充用它。三星新机型主要认 PD 和 PPS，买充电头认准这两个就对了。

## 线：e-marker 决定能不能过 5A

- 普通 C-to-C 线最多过 **3A**，配 20V 就是 **60W**。手机完全够用。
- 要过 **5A**（100W，或者 240W 的 EPR），线里必须有一颗 **e-marker 芯片**，告诉充电头「我扛得住」。没有这颗芯片，充电头最多只给 3A。
- 新的认证线会直接在包装或插头上标 **60W / 240W**，最好认。
- 一头 USB-A、一头 USB-C 的老式线**走不了 PD**。想要快充，就用两头都是 C 的线。

## 线：数据速度和视频

同一根线，充电和传数据是两回事。很多便宜的「充电线」里只有 USB 2.0 的数据线路。

| 标识 | 速度 | 能做什么 |
|---|---|---|
| USB 2.0 | 480 Mbps | 充电、传少量文件。**不能出视频** |
| USB 5Gbps（USB 3.2 Gen 1） | 5 Gbps | 外接硬盘、拓展坞 |
| USB 10Gbps（USB 3.2 Gen 2） | 10 Gbps | 快速移动固态硬盘 |
| USB 20 / 40Gbps（USB4） | 20 / 40 Gbps | 高速硬盘盒、显卡坞、一线连显示器 |
| Thunderbolt 3 / 4 | 40 Gbps | 同上，插头上有 ⚡ 标志 |

**要点：**

- **投屏、接显示器**（比如三星 DeX 有线接显示器）需要 USB 3.x 以上的线，还要设备支持「DP 视频输出」（DisplayPort Alt Mode）。用手机自带的充电线接显示器没反应，多半就是这个原因。
- **高速线一般都短。** 10Gbps 的普通线一般在 1 米左右，40Gbps 的在 0.8 米左右。要更长的话，得买带芯片的主动线（active cable）。
- 只用来充电的话，买 1–2 米的 USB 2.0 + 60W（或 240W）线最省事，便宜还耐用。

## 实际怎么配

**手机（S23 Ultra）**
- 一个支持 PD + PPS、单口 45W 以上的充电头，配一根 5A 的线。
- 只想要 25W 的话，任何支持 PPS 的 25W 以上充电头加普通 3A 线就行。
- 平时开着「保护电池」（只充到 80%），见技巧页的[保护电池](../tips.html#phone08)。

**笔记本电脑**
- 看电脑原装充电器的功率，比如 65W 或 100W，买**不低于这个功率**的 PD 充电头。
- 100W 以上要配 5A 线。
- 用小功率充电头也能充，只是慢；如果电脑正在高负荷运行，电量可能还会往下掉。

**迷你主机**
- 大多数用圆口 DC 电源，用原装的就好。
- 少数机型支持 USB-C PD 供电，看说明书写的是 65W 还是 100W。
- 机身上的 USB-C 口能不能接显示器，看旁边有没有 DP 标志或 ⚡ 标志。

**多口充电头**
- 标的总功率会被几个口**分着用**。比如 65W 三口，插两台设备时，每个口可能只剩 45W 和 20W。
- 中途再插一台设备，充电头会重新分配功率，正在充的设备可能断开一两秒，这是正常的。

**车充**
- 选标着 PD + PPS 的。
- 单口 45W 以上才能让 S23 Ultra 跑满超级快充；夏天车里热，实际很难跑满。

## 用得久、用得安全

- 认准正规品牌，别买杂牌的「100W 线」：有的标称 5A，里面根本没有 e-marker，或者线芯很细，大电流下会发烫。
- 插头发烫、外皮破了、接口松动，就别再用了。
- 想知道到底充了多少瓦，可以买一个 USB-C 功率计（十几美元），插在充电头和线中间，能看到电压、电流和协议。
- **氮化镓（GaN）**充电头同样功率个头更小、发热更少，现在价格也不贵，值得买。
