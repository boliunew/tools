# 路上出状况怎么办：爆胎、没电、过热、事故

车出问题时最重要的是**先保证人安全，再管车**。这篇按情况一步一步写。

## 第一步永远是这几件事

1. **打双闪**，慢慢减速，往**右边**路肩、出口或停车场靠。
2. 高速上停车后，**人从右边（远离车流的一侧）下车，站到护栏外面**，不要站在车前后。
3. 天黑或视线差时放三角警示牌（后方 100 英尺以上）。
4. 有人受伤、车停在车道里挪不走、着火：打 **911**。
5. 其他情况叫道路救援。

## 道路救援去哪找

- **ToyotaCare**：新车前 2 年 / 25,000 英里包 24 小时道路救援（车主手册、钥匙扣、Toyota App 里有电话）。
- **车险**里加的道路救援（Roadside Assistance），一年几块钱，很划算。
- **AAA 会员**：拖车、搭电、送油、开锁、换胎。
- 一些**信用卡**也有按次付费的道路救援。
- 加州很多高速在高峰时段有免费的 **Freeway Service Patrol** 巡逻车，帮忙搭电、换胎、加一点油、把车拖到安全的地方。

## 爆胎

1. 握紧方向盘，**别猛踩刹车**，松油门让车慢下来，靠边停。
2. 平地、远离车流才自己换胎；高速路肩上最好等救援。
3. 换胎步骤：拉手刹、挂 P → 后备箱拿出备胎和千斤顶 → 先**在车还着地时**把轮胎螺丝拧松半圈 → 千斤顶顶在车底标记的位置把车顶起 → 拧下螺丝换上备胎 → 对角拧紧 → 放下车再对角拧紧一次。
4. 临时备胎限速 50 mph，尽快去补胎或换胎。

## 12V 电池没电，开不了机

症状：按启动键没反应、灯很暗、只有「咔哒」声。

- **最简单**：叫道路救援，或用**便携式搭电宝**（Jump starter，一百美元左右，推荐车里放一个）。
- **用别的车搭电（跳线）的顺序**：
  1. 两车都熄火。
  2. 红夹子 → 没电车的正极（+）；另一端红夹子 → 好车的正极（+）。
  3. 黑夹子 → 好车的负极（−）；最后一个黑夹子 → 没电车的**没上漆的金属部位**（发动机支架等），不是负极桩头。
  4. 好车启动跑几分钟，再启动没电的车。
  5. 按相反顺序拆夹子。
- **丰田混动车**：按车主手册，一般接在**引擎盖下保险丝盒里的跳线正极端子**上；**不要碰橙色的高压线**。搭上后按 POWER，看到 READY 就好，然后开至少半小时充电。
- 电池三年以上又没电，大概率该换了，AutoZone、O'Reilly 能免费测电池。

## 发动机过热

水温灯亮或水温表接近 H：

1. 关掉空调，**把暖风开到最大**（把发动机的热量往车里散），尽快靠边停车熄火。
2. 打开引擎盖散热，**绝对别打开冷却液盖**（滚烫的液体会喷出来）。
3. 等至少 30 分钟凉了再看冷却液罐液面，少了可以临时加冷却液（或清水应急），然后去修。
4. 地上有绿色、粉色液体就是漏了，叫拖车。

南加州夏天爬山（I-15 Cajon 山口、去大熊湖的山路）最容易过热，看着水温。

## 没油了

- 叫道路救援送油（一般送 1–3 加仑）。
- 混动车油用完后可能还能靠电跑一小段，但别指望。
- 预防：油表剩四分之一就加。去沙漠、大苏尔这种加油站少的地方，出发前加满。

## 钥匙锁在车里 / 钥匙没电

- 叫道路救援开锁（别用衣架硬撬，会弄坏门和电线）。
- Toyota App 开通了远程功能的话，可以用手机开锁。
- 遥控钥匙没电：钥匙里抽出机械钥匙开门；把钥匙贴在启动键上按，一般还能启动。

## 刹车异常

- **刹车踩下去软、能踩到底**：马上低挡位慢慢减速，用手刹辅助，靠边停，别再开。
- **刹车时吱吱响**：可能是刹车片磨损提示片在响，尽快检查。
- **刹车时方向盘抖**：可能刹车盘变形，尽快检查。
- 下长坡别一直踩刹车，用低挡或 B 挡（混动车）帮忙。

## 出了交通事故

1. 停车、打双闪，看人有没有受伤，有人受伤打 911。
2. 车能动就挪到路边，避免二次事故。
3. 跟对方交换：姓名、电话、驾照号、车牌、**保险公司和保单号**。
4. 拍照：两车损伤、车牌、现场、路口路牌、对方驾照和保险卡。
5. **别当场承认责任**，别私下给钱了事不留记录。
6. 尽快打电话或用 App 通知自己的保险公司。
7. 有人受伤或损失超过 1,000 美元，**10 天内向 DMV 交 SR-1 表**。

详见 [车险、理赔和买卖车](car-insurance-buying.md) 和 [在加州开车要知道的](california-driving-basics.md)。

## 车被拖走了

- 在私人停车场被拖：看停车场的告示牌，上面有拖车公司电话。
- 在路边被拖：打当地警察局的非紧急电话，问车被拖到哪个场。
- 取车要带驾照、注册卡，费用按天涨，越早取越好。

## 车里该常备的东西

| 东西 | 为什么 |
|---|---|
| 便携式搭电宝 | 电池没电自己就能解决 |
| 车载充气泵 + 胎压计 | 慢漏气时救急 |
| 三角警示牌或 LED 警示灯 | 夜里停路边 |
| 手电筒、手套 | |
| 急救包 | |
| 几瓶水、一点能量棒 | 南加州夏天尤其要带水 |
| 手机车充、数据线 | |
| 毯子或外套 | 山里夜里冷 |
| 雪链（冬天上山） | Baldy、大熊湖下雪时常要求带 |
| 纸笔、保险卡复印件 | 事故时记信息 |
