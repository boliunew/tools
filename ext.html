🧩 浏览器插件

两个油猴脚本，把工具箱带到别的网站上用。

🐒 先装篡改猴（只装一次）：电脑上的 Chrome / Edge 装 Tampermonkey 篡改猴，然后在扩展详情里打开「允许用户脚本」。安卓手机可以用 Firefox 装。
点下面的「安装」，篡改猴会弹出安装页面；没弹出的话：篡改猴「管理面板」→「实用工具」→「从 URL 安装」，粘贴安装链接。

🧭 工具箱随身

⏳ 检查中…
  • 🎞️ YouTube：右下角「SubLingo 精读」，把视频字幕送进 SubLingo 逐句学（先打开 CC 英文字幕）
  • 📖 任何英文网页：选中一句 →「讲讲这句」，AI 讲意思、主干、时态、短语；选中一个单词 →「⭐ 存进词库」，连例句一起进语境词库；还能整篇送进 SubLingo
  • 📈 Yahoo Finance / TradingView / Finviz：右下角显示这只股票在你股票池里的情况（候选、跟踪、RSI、强度、均线、信号），一键设提醒
  • 📥 推特 X：每条带图 / 视频的帖子多一个 📥，一点就下到 torrent_hub（「X推特」文件夹）；Instagram 帖子右下角一键交给「📥 媒体」
⬇ 安装 讲解要用工具箱的密码：在同一个浏览器打开过首页并勾「记住我」就行

🧰 工具箱助手

⏳ 检查中…
  • ⚡ 在「☁️ 夸克网盘搜索」里直接读夸克分享、勾选文件下到电脑、字幕送 SubLingo、边下边学
  • 只在工具箱页面和夸克网页上运行
⬇ 安装 ☁️ 去夸克网盘搜索
🔒 这两个脚本都是我们自己写的，代码就在工具箱的仓库里。「工具箱随身」会在所有网页上运行（为了划词讲解），但只在你选中英文、点按钮的时候才联网；除了你的工具箱后端、本机的 torrent_hub 和推特下载接口，不往别处发东西。
